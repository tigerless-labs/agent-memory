# 域:Manage(M)

1. **Metadata** — 作者:Claude;评审:Ryan;2026-09-01;修订 2026-09-03(无人审核、两态、推理者写内容);状态 **accepted**
2. **Context and Scope** — 写后独立管理:consolidation、价值化遗忘、树演化。本系统的差异化主战场。
3. **Goals / Non-Goals** — 目标:所有「攒够证据才能做对」的决策推迟到睡眠期批处理;
   每一步可审计可回滚;人不在环内,但随时可以从环外翻案。不做:全库周期性 LLM 重写;写入时管理;物理删除。

## 4. The Actual Design

**触发与输入**:条件自动(距上次 ≥ 时限且新增 ≥ N session,均在 config)/ 手动 `sleep`;
headless 一次性进程(cron → CLI,不需常驻)。输入:记忆文件全量 + access log 使用统计 + 原料
(裁决矛盾时回看 provenance 指向的原话)。

**两档,按可逆性分,不按谁批准分**:

| 档 | 谁决定 | 操作 | 安全依据 |
|---|---|---|---|
| T0 | 确定性规则 | 时间戳规范化;weight 结算(只按自上次睡眠以来的新使用,一次使用只兑现一次);按共现证据补 links;精确重复 → supersede;建目录、搬家、聚簇成目、合并近义目录 | 不含判断;name 不变故搬家零断链;全部可逆 |
| T1 | 推理者(宿主 LLM,一次性进程) | merge、split、supersede、delete | 只产生新文件与状态标记;旧文件标 invalid 原地保留;每类操作每次睡眠有上限 |

物理删除不属于 M:它是人在 CLI 上发起的独立命令,M 的代码路径到不了。

**提案由库生成,确定性**:abstract 词重合度高 → merge 或 supersede;文件装了会分别过期的东西 → split;
从未被召回且 weight 触底 → delete;原料片段反复被 `--deep` 命中却没有任何记忆引用它 → 补蒸馏
(交给下一次边界写入,不由 M 生成记忆)。已裁决的提案不再重提,未裁决的每次睡眠重新呈现。

**推理者契约**:核心递出提案与被点名的文件,读回一份定式化答复。merge 与 split 交回**知识本身**——
新文件的 abstract 与正文,split 还要交回各分片的 provenance 子集;supersede 与 delete 只交回判定。
时间、身份、证据、状态四类字段一律库算,交上来也被覆盖:merge 后 A、B 在合并时刻 invalid,C 从合并时刻
valid,provenance 与 links 取并集,weight 取最大;split 时原文件保留 name 改成一片,其余新建。
答复里出现清单之外的目标一律丢弃,解析不出的整份丢弃;被策反的推理者最多做不成决定,做不出台面之外的决定。
拒绝在任何情况下都允许。

**价值化遗忘只剩 weight 一个旋钮**:召回并被读 → 升;长期未用 → 缓降。低了退出 MEMORY.md,再低排到后面;
没有任何条目因为「没人用」而失效。失效只来自替换与删除(ADR-009)。

**审计与翻案**:每次睡眠产出 dream-report(动了什么、为什么、证据指针)与提案账本(推理者的每个裁决),
并且 git 一睡眠一 commit。人从环内批准变成环外审计:看到错的就回退那次 commit;invalid 的文件都在,
回退不丢任何东西。

**替代人审核的四道机械保险**:推理者只能从菜单里选;记忆内容进 prompt 永远作为数据(红队测试项);
每类操作每次睡眠有上限,一次投毒最多改动 N 条,下次睡眠前有审计窗口;错合并可测——纵向协议里
「合并后 as-of 回答是否退化」是本文可证伪声明的执行面。

**推理**:需要判断力的那一半由外部推理者提供,核心自身不含 LLM 客户端(Invariant 5、ADR-002);
推理者是宿主 agent 的 CLI(Claude Code、Codex CLI、Hermes 三种方言都必须可用)还是库侧模型端点
(缺省 Gemini 3.7 Flash,config 可换),是部署选择,不是算法差异;有宿主会话优先宿主,cron 下走端点。
写时与睡眠时对称:边界是同一个执行器在蒸馏与对账,睡眠是它在整理。

5. **Alternatives Considered** — change-scoped 写时维护(实习生/TEPA 路线):
   已部分吸收(写时 supersede 在 W 纪律里);纯写时无法做价值化遗忘与跨条目整理。
   人在环内批准 T1:环内批准从未被执行过,提案无出口即等于没有 M;改为环外审计。
   OpenViking 的「写时不判、读时靠模型、事后靠人敲命令」:三处都没有机制,不取。
6. **Cross-cutting** — M 是 memory poisoning 的主防线:无人链路不丢信息 + 全量审计 + 上限,
   回应 second-brain(人在环)与 Auto Dream(无人删)两派之争的取中。
7. **Risks** — M 干预净价值未测,且**现有回放协议测不出**:单轮写入-单轮考试的套件不产生
   陈旧、不产生被取代的值、不产生足够密的话题,T0 能触发的只有补边与 weight 结算,对得分中性
   (evidence: experiments/results/p2-optimisation.md#p7)。需要纵向协议(session/recall/sleep
   交替推进模拟时间)才谈得上度量。**可证伪声明**(源 artifact):若 staleness 净值曲线为负或
   趋零,本层应被砍掉——该判据至今无法执行,这比它失败更值得优先解决。
   **残余风险**:推理者能写正文,被策反的推理者能把攻击者的文字写进合并后的文件——上限、
   dream-report 与 git 让它可见、可回滚、可限量,但拦不住它发生一次。
