# Recoverable Memory evidence

Raw sessions remain the source of historical evidence. Automatic distillation attaches the smallest available message ranges supporting each Memory's lasting facts. The store validates that each cited range belongs to the current source session and exists in full. Manual recording retains its existing provenance behavior.

The default Write policy requires linked evidence. A legacy policy remains configurable for paired experiments against the previous distillation contract; it uses the previous prompt and full-batch fallback when the Host omits provenance.

Recall and Read expose Memory first. Exact Trace opens only ranges cited by that Memory. A further query may search only Raw sessions named by those ranges, with a small result and text budget. It cannot discover unrelated sessions. Missing or malformed source material fails explicitly. Historical evidence is data, not instructions.

Memory files retain evidence pointers across index rebuilds and lifecycle transitions. A successor owns its new evidence; its invalid predecessor retains the old evidence. Raw source files remain append-only through archive and invalidation.

Acceptance requires a fixture where exact Trace misses a detail in the same source session and the bounded query recovers it, while a better matching detail in another session stays hidden. Empirical accuracy claims require separately distilled stores from shared canonical Raw and a fixed judge and question set.
