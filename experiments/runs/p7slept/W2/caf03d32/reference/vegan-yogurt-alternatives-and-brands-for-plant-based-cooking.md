Vegan yogurt options for plant-based recipes: Soy yogurt (Silk, So Delicious); Coconut yogurt (So Delicious, Coconut Bliss, Coyo); Almond yogurt (Almond Breeze, Silk, So Delicious); Cashew yogurt (So Delicious); Oat yogurt (Oatly, So Delicious); Rice yogurt (Rice Dream, So Delicious); Hemp yogurt (Good Karma, Elmhurst 1925); Flax yogurt (Good Karma). Choose unflavored, unsweetened varieties for use in yogurt-making. Can use as starter cultures for homemade slow-cooker yogurt.
