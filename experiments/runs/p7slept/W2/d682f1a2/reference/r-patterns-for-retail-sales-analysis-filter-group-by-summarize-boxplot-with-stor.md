R code patterns for analyzing Supermarketdata: (1) Filter data by year/store using filter(). (2) Group by department and calculate totals using group_by() and summarize(). (3) Arrange results descending by sales figure. (4) Create box plots with boxplot(Weekly_Sales ~ Store) to show distribution across stores. (5) Use abline(v=store_number, col='red') to highlight specific stores in plots. Used for comparing Store 10 performance vs. other stores and visualizing 2012 sales distribution.
