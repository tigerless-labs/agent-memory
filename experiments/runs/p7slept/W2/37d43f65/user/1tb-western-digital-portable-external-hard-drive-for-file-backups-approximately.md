Portable external backup drive: Western Digital, 1TB capacity.

Purchased from Best Buy for approximately 50 dollars.

Usage:
- Using for regular file backups
- Provides peace of mind knowing files are safe
- Working great reliably

Backup strategy:
- Using 3-2-1 backup approach:
  - 3 copies of data (original plus external drive plus cloud or other device)
  - 2 different media types (hard drive plus cloud storage)
  - 1 offsite copy (cloud or different location)
- Regularly testing backups for completeness and recoverability
