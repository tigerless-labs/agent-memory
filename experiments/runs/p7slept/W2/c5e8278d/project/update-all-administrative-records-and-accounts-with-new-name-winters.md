After name change from Johnson to Winters, need to update:

1. **Health Insurance Provider** - Call customer service; processing time 1-3 business days for phone update
2. **DMV / Driver's License** - Provide proof of name change (marriage certificate, etc.); varies by state
3. **Social Media**
   - Facebook: Settings → Account Settings → Edit Name → verify identity → Save
   - Instagram: Edit Profile → Name field
   - Twitter: Edit Profile → Name field
   - LinkedIn: Me icon → View Profile → Edit Public Profile & URL
4. **Credit Reports** - Update with all three bureaus:
   - Experian: (866) 200-6020 or mail to P.O. Box 2104, Allen, TX 75013-2104
   - TransUnion: (800) 680-7289 or mail to P.O. Box 2000, Chester, PA 19016-2000
   - Equifax: (800) 685-1111 or mail to P.O. Box 740256, Atlanta, GA 30374-0256
   - Need proof of name change (certified marriage certificate, court order, or government ID)
5. **Credit Cards** - Contact issuer; may need to request new cards with updated name
6. **Other Financial Institutions** - Banks, loan providers, creditors
7. **Vehicle Registration & Title** - If applicable

**Timeline:** Phone/online updates process in 1-3 business days; mail updates take 5-7 business days. Credit bureaus may take longer; monitor credit report after updating.

**Documents Needed:** Certified copy of marriage certificate or court order for name change verification
