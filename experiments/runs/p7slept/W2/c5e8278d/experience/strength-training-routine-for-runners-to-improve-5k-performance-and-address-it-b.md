Why strength training for runners:
- Improves running economy and efficiency
- Reduces injury risk (shin splints, plantar fasciitis, IT band syndrome)
- Enhances power and speed

Program structure:
- 2-3 sessions per week on non-consecutive days
- Focus on compound exercises working multiple muscle groups
- Include core and glute strengthening
- Start with lighter weights, progress gradually
- Add plyometrics (jump squats, box jumps) for power

Monday - Lower Body and Core:
- Squats: 3 sets x 8-12 reps
- Lunges: 3 sets x 8-12 reps per leg
- Deadlifts: 3 sets x 8-12 reps
- Calf raises: 3 sets x 12-15 reps
- Plank: 3 sets x 30-60 seconds
- Russian twists: 3 sets x 12-15 reps

Wednesday - Glutes and Hip Flexors:
- Side lunges: 3 sets x 8-12 reps per leg
- Step-ups: 3 sets x 8-12 reps per leg
- Clamshells: 3 sets x 12-15 reps
- Leg press: 3 sets x 8-12 reps
- Pigeon pose: 3 sets x 30-60 seconds per leg
- Leg swings: 3 sets x 12-15 reps

For IT band/hip flexor issues:
- Glute medius work: side lunges, clamshells, side leg lifts
- Hip flexor strength: step-ups, lunges, leg press
- Hip mobility: leg swings, hip circles, pigeon poses
- Core stability: planks, side planks, Russian twists
