Chose Adobe Lightroom for managing, organizing, and editing photos because already comfortable with the Adobe ecosystem. Uses Lightroom's collections feature to categorize photos by type (Landscapes, Wildlife, Flora, etc.) and Smart Collections for date range and location-based filtering. Focuses on Develop module for basic adjustments like exposure, contrast, and shadow recovery.
