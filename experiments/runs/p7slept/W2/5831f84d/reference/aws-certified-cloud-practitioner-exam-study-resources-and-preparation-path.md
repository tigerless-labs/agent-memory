Study plan spans 10 weeks: fundamentals in weeks 3-4 (AWS Free Tier, services overview); key services in weeks 5-6 (S3, EC2, Lambda, API Gateway, IAM, security); practice exams and quizzes in weeks 7-8. Recommended official resources: AWS Certified Cloud Practitioner Study Guide by Ben Piper, practice exams from Whizlabs and Tutorials Dojo. Free options: AWS Well-Architected Framework, AWS Tutorial Center, AWS Cloud Practitioner Essentials course, AWS re/Start program. Platforms: Udemy, Coursera, edX, Pluralsight, Cloud Academy. Communities: AWS re/Start, AWS subreddit, AWS forums.
