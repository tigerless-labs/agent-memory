Recommended resources for NLP learning:

**Courses:**
- Stanford Natural Language Processing with Deep Learning Specialization (Coursera)
- edX Natural Language Processing (Microsoft)
- DataCamp Natural Language Processing with Python

**Frameworks for NLP:**
- PyTorch (recommended for flexibility and rapid prototyping)
- TensorFlow (Google's framework, wide community)
- Keras (high-level interface, simplicity)
- Hugging Face Transformers (unified interface for transformer-based models)

**Models for text classification:**
- BERT (bert-base-uncased)
- RoBERTa (roberta-base)
- DistilBERT (distilbert-base-uncased) - efficient, smaller model
- XLNet (xlnet-base-uncased)
- ALBERT (albert-base-v2)

**Key resources:**
- 'Attention Is All You Need' paper (Vaswani et al.)
- The Illustrated Transformer (Jay Alammar blog post)
- spaCy documentation
- NLTK Book
