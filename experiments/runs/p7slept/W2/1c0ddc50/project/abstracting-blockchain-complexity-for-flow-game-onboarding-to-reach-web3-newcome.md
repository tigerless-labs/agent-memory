User interested in making educational game accessible to non-technical Web3 newcomers through abstraction. Key onboarding strategies for Flow apps:

1. **Email/social signup**: Allow registration via email or social identity instead of requiring wallet setup
2. **Credit card NFT purchases**: Enable direct NFT purchases with credit card (abstract away need to buy crypto first)
3. **Hide blockchain details**: Abstract transaction confirmation times, gas fees, public/private keys
4. **Familiar UX**: Design experience resembling traditional web apps rather than technical blockchain interfaces

Goal: Attract wider audience to blockchain games, increase Web3 adoption among non-technical users
