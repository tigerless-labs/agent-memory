Common music production programming languages:

- **Sonic Pi**: Free, open-source live coding environment with simple syntax and real-time feedback. Recommended for beginners.
- **ChucK**: Free, open-source language designed specifically for music programming. Simple syntax with powerful audio synthesis tools.
- **Max/MSP**: Visual programming language for creating custom software instruments and effects using virtual patch cables.
- **Pure Data (PD)**: Free, open-source platform similar to Max/MSP. Used for interactive music and multimedia installations.
- **SuperCollider**: Language and platform for real-time audio synthesis and algorithmic composition. Popular for experimental music and sound art.
- **Csound**: Software synthesis system (30+ years in use). Allows creation of custom sound generators and effects.
- **Python**: General-purpose language with community tools for music production.
- **Swift**: Apple's programming language; increasingly popular for creating music apps for iOS/macOS.

Beginner recommendations: Sonic Pi, ChucK, or Python for their ease of learning and good documentation.
