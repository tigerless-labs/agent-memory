Established combat rules for ongoing post-apocalyptic survival game (session 2023/05/20):

- **Stop and alert for combat**: If a quest involves combat, stop the narrative and explicitly state it involves combat
- **Combat resolution system**: Use mechanics to determine success/failure (not automatic success)
- **Loss consequences**: Losing combat results in losing items from inventory or death
- **HP tracking**: Track hit points and notify if HP decreases during quests

The game involves completing quests from a settlement base in a post-apocalyptic wasteland. Combat is a significant risk that should affect inventory and potentially end the game.
