Australian tax requirements for international students (non-residents):

**Tax-free threshold:** 18,201 AUD annually (2022-2023 financial year)

**Non-resident tax rates (2022-2023):**
- 32.5% on income 0-90,000 AUD
- 37% on income 90,001-180,000 AUD
- 45% on income above 180,000 AUD

**Filing requirements:**
- File tax return NAT 2541 by October 31st each year if income exceeds threshold
- Apply for Tax File Number TFN using form NAT 1432 if needed
- Use PAYG system for quarterly instalment payments if self-employed (freelance, tutoring)

**Key note:** International students must pay taxes on Australian-sourced income (part-time work, freelancing, tutoring). Recommend consulting tax professional familiar with international student obligations.

Sources: Australian Taxation Office (ATO) website
