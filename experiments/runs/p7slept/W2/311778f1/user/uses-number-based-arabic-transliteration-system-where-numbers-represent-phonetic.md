Uses a number-based transliteration system when writing Arabic in English contexts:

- `3` = ع (ayin sound)
- `5` = خ (kh sound)

Examples:
- `3anjad` = anjad
- `zene5` = zenekh  
- `m5alal` = mkhalal
- `3inko janzeer bill beit` = "You have a monkey in the house" (عنكو جنزير بل بيت)

This is their preferred method for writing Arabic within English text.
