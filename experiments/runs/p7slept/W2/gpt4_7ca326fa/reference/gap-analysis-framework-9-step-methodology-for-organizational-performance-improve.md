Gap analysis methodology with nine key steps for driving organizational improvement:

1. Identify organizational goals and KPIs
2. Analyze current state (processes, systems, metrics)
3. Identify gaps between current and desired state
4. Prioritize gaps by severity and impact
5. Develop specific recommendations with resource requirements
6. Create action plan with assignments, timelines, metrics
7. Monitor and measure progress against KPIs
8. Communicate results to stakeholders
9. Continuously improve through regular reassessment

**Key principle**: Be specific about gap sizes, impacts, actions required, resource needs, and expected outcomes.
