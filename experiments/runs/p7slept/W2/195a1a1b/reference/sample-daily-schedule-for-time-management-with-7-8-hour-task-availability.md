Morning: 8:00-8:30 exercise, 8:30-9:00 shower/prep, 9:00-9:30 breakfast/relax.

Core work (7 hours): 9:30-10:00 email check, 10:00-12:00 project work (most productive time), 12:00-1:00 lunch, 1:00-2:00 email management, 2:00-3:00 meetings, 3:00-4:00 project work, 4:00-4:30 break, 4:30-6:00 project work.

Wrap-up: 6:00-6:30 review progress and plan next day.

Evening wind-down: Start 60-90 minutes before 9:30 pm bedtime. Include relaxation technique (meditation, reading, deep breathing), avoid screens 30+ min before bed, prepare sleep environment, prepare for bed.

Tools: Use digital calendar (Google Calendar or Outlook) and task management tool (Trello or Asana). Use timer for 90-120 min focus blocks with breaks.
