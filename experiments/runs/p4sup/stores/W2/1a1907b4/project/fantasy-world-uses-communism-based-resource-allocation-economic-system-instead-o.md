Designing an economic system for a fantasy world. Decided against a monetary system in favor of a communism-based resource-allocation model. Key design question: balancing resource allocation for basic needs with sufficient incentives for work and innovation. Concerned about how a pure resource-allocation system might stifle innovation and economic growth compared to markets. Using manual ledger and/or digital tracking systems for resource allocation. Different resource levels based on factors like age, health, occupation, and work output/contributions.
