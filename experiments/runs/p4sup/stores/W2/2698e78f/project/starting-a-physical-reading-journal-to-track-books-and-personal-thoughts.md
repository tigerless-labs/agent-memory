Beginning a reading journal using a generic notebook, customized to track reading progress and record thoughts. Previously used Notes app on phone as temporary solution but prefers hand-writing for a more intimate, personal feel. Likes being able to flip back through pages to see progress. Plans to include a consistent format/template with elements like: book title/author/dates, ratings, favorite quotes, personal reflections, and how books relate to own life. Wants to make it personal and evolving over time.
