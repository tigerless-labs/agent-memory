**5K Charity Run Training**

Started: 2023-05-22

**Current Routine:**
- 3-mile jogs on Tuesday and Thursday mornings
- Running pace: working on cadence of 160-170 steps/min with midfoot footstrike

**Planned Improvements:**
- Increase weekly mileage
- Add hill repeats (1-3 min hills, 3-5 repeats)
- Incorporate strength training 2-3x/week targeting glutes, hamstrings, quads
- Focus on proper warm-up/cool-down with dynamic and static stretches
- Hydration: 16-20 oz before runs, 4-6 oz every 10-15 min during long runs (30+ min), 16-20 oz post-run

**Injury Prevention Focus:**
- Preventing shin splints through gradual progression, proper footwear, ankle strengthening
- Maintaining good running form (upright posture, core engagement, relaxed shoulders)
