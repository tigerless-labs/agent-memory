Performance issues reported on 2023-03-17:
- Programs taking a long time to launch
- System freezes when multiple browser tabs (10-15) open in Chrome
- No error messages observed when freezing

Contributing factors identified:
- Chrome's resource usage with many tabs open
- Resource-intensive video editing software in use
- Possible CPU bottleneck (Intel Core i5)

Troubleshooting planned:
- Restart in Safe Mode to rule out software/driver issues
- Disable unnecessary startup programs
- Monitor system resources (CPU, RAM, Disk, Network) with Task Manager or Activity Monitor
- Close unnecessary programs during heavy workloads
- Lower video editing software settings/resolution
- Consider adding RAM upgrade (currently 8GB)

Note: 512GB SSD and 8GB RAM are adequate for most tasks, but video editing is resource-intensive.
