Browser Management: Close unnecessary tabs to reduce Chrome resource usage. Consider Microsoft Edge or Firefox. Use tab management extensions like OneTab or Tab Manager.

Background Programs: Check Task Manager or Activity Monitor for resource-intensive processes. Disable unnecessary startup programs. Close unnecessary programs when running resource-intensive tasks.

System Optimization: Keep OS, Chrome, and software updated. Update laptop drivers. Run full antivirus scan. Monitor disk usage patterns.

Video Editing: Lower resolution or quality settings. Close unnecessary programs when editing. Reduce project complexity.

Hardware Upgrades: Adding more RAM (currently 8GB) improves multitasking and resource-intensive tasks. Check RAM specifications for compatibility before upgrading. Consult professional or manufacturer for safe installation.

Troubleshooting Sequence: (1) Restart in Safe Mode to determine if issue is software/driver related. (2) Monitor system resources while experiencing slowdowns. (3) Identify bottleneck resource (CPU/RAM/Disk/Network). (4) Apply relevant optimization based on findings.
