## AllTrails
- Filter trails by: difficulty (Easy, Easy-Moderate, Moderate, Moderate-Difficult, Difficult), distance (Under 1 mi, 1-3 mi, 3-5 mi, 5-10 mi, 10+ mi), elevation gain, rating, features (waterfalls, scenic views, lakes), trail type (loop, out-and-back, point-to-point), accessibility
- Available on web and mobile app

## Meetup for Hiking
- Filter groups by activity level: Casual, Moderate, Active, Very Active, Extremely Active
- Filter by difficulty: Easy, Moderate, Challenging, Strenuous
- Features: member profiles, direct private messaging between members, group discussions/comments, event RSVP
- Best for in-person connections and group hikes

## Other Resources
- Facebook Groups: local and national hiking groups
- Instagram: hashtags #hiking #backpacking #outdoorlovers #naturephotography
- Apps: Hiking Project, Gaia GPS (community features)
- Online: Reddit r/hiking, Whiteblaze, Hiking Forum, Backpacking.net
- Local: outdoor gear stores, outdoor clubs (Sierra Club, Appalachian Mountain Club, NOLS chapters)
