Guild.xyz is a platform for creating private, tokenized communities or 'guilds' across different communication platforms, management tools, and games.

## Key Features
- **Automated membership management** — manage communities across existing platforms
- **Token-enabled membership** — create exclusive levels using blockchain assets
- **Cross-chain token gating** — support for 1M+ tokens, 100K+ NFT projects, 10+ chains
- **Web3 captcha** — filter bad-actor bots and protect against Discord scams
- **Real-time query engine** — owns its own indexer for token/NFT data
- **Composable membership requirements** — built-in integrations and external APIs with logic gates
- **Gasless guild creation** — free to set up

## Values
- Dedicated support — helps you start, secure and scale communities
- Open-source — frontend and platform connectors available
- API/SDK — access control strategies for developers
- Accessible — no-code tool with smooth UX

## Context
Large Web3 communities use Guild: ZetaChain (243K members), Arbitrum (227K), Galxe (91K), and many DAO ecosystems. Platform has 600+ guilds, 10,000+ users, 1,929 GitHub commits.
