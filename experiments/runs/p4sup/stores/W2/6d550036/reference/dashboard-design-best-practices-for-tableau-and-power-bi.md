General: know your audience and their needs, keep designs simple and focused on key information, use clear structure with sections/tabs, choose charts that match data type (bar for categorical, line for time-series, scatter for correlations), use color effectively to draw attention and differentiate categories. Tableau-specific: use dashboards to combine worksheets, leverage interactivity with filters and parameters, use size and color to encode data, avoid 3D charts, use Data Stories feature for narrative. Power BI-specific: use Power BI Service for cloud-based publishing and sharing, leverage Q&A feature for natural language queries, use analytics pane for advanced capabilities, use gauges and KPIs to track metrics, customize themes for consistency.
