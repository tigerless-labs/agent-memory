When conducting data analysis projects:\n\n- Uses multiple evaluation methods rather than relying on a single metric (e.g., combining elbow method + silhouette analysis)\n- Emphasizes data visualization as a tool for both exploration and communication\n- Considers audience needs when creating reports and presentations\n- Pays attention to visualization best practices: consistent color schemes, accessibility (color blindness), avoiding over-encoding\n- Values clear interpretation and storytelling with data over purely aesthetic presentations\n- Interested in dimensionality reduction techniques for exploring high-dimensional data
