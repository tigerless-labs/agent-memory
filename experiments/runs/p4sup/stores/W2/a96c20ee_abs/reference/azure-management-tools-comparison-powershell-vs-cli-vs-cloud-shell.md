Three main tools for managing Azure resources:

**Azure PowerShell**
- Module that adds Azure-specific commands to PowerShell
- Requires PowerShell to function
- Available on Windows PowerShell and PowerShell Core
- Provides way to connect to Azure subscriptions and manage resources

**Azure CLI**
- Command-line program for executing administrative commands on Azure resources
- Cross-platform: runs on Linux, macOS, and Windows
- Installed locally on computers
- Provides cross-platform command-line tools for managing Azure resources

**Azure Cloud Shell**
- Interactive, browser-accessible shell for managing Azure resources
- Browser-based command-line experience built for Azure management tasks
- Runs on temporary host provided per-session, per-user basis
- Requires resource group, storage account, and Azure File share
- No local installation needed
