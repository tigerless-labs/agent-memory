CSV file used for retail sales analysis in R Studio with columns: Store (store number), Dept (department number), year (date/time period), Weekly_Sales (sales figures). Common analyses include: filtering by store/year, grouping by department, calculating means and sums, creating box plots and comparisons across stores.
