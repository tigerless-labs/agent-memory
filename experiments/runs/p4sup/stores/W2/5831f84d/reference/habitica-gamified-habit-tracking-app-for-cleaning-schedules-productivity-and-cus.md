Habitica is a habit-tracking app that gamifies task completion and habit formation. Features include:\n- Customizable habits, daily tasks, and to-do lists\n- Gamified rewards system to motivate habit completion\n- Ability to create custom habits (e.g., one-touch rule)\n- Tracks daily routines and weekly tasks\n- User chose this for tracking cleaning routine and one-touch rule habits with milestone-based rewards
