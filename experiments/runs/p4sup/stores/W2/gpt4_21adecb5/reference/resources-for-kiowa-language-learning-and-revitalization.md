1. **Kiowa Language Program** - Kiowa Tribe of Oklahoma official program. Website contains language classes, materials, and resources for learners.

2. **Kiowa Conversations podcast** - Created by Kiowa Tribe Language Department. Features fluent Kiowa speakers having conversations in Kiowa about various topics. Good for listening practice.

3. **Dictionary of the Kiowa Language** by Jack Gladstone - Available on Amazon. Contains over 7,000 entries, created to help preserve the Kiowa language.

4. **Native American Language Preservation and Maintenance** website - Resource providing information about language revitalization efforts across North America and Indigenous languages generally.
