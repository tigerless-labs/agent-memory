Transformer Architecture: Attention Is All You Need (Vaswani et al., 2017) - Original transformer paper for machine translation.

Language Models: BERT (Devlin et al., 2019), RoBERTa (Liu et al., 2019), XLNet (Yang et al., 2020), DistilBERT (Sanh et al., 2019), Transformer-XL (Dai et al., 2019), T5 (Raffel et al., 2020), BART (Lewis et al., 2020).

Computer Vision: Vision Transformers/ViT (Dosovitskij et al., 2020), Swin Transformer (Liu et al., 2021), DETR (Carion et al., 2020), Deformable DETR (Zhu et al., 2020), TransGAN (Jiang et al., 2020), StyleSwin (Chen et al., 2021).

Applications: Image Recognition at Scale (Dosovitskij et al., 2020), Dialogue Systems (Chen et al., 2020), Machine Translation applications (Lample et al., 2019), Aspect-Based Sentiment Analysis (2020), Long-Range Arena (Tay et al., 2020).
