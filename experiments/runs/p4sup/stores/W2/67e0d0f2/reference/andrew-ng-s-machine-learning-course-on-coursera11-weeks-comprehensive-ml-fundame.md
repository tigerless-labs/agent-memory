**Course:** Machine Learning  
**Instructor:** Andrew Ng  
**Platform:** Coursera  
**Duration:** 11 weeks (approx 3–4 months)  
**Time commitment:** 2–3 hours/week  
**Level:** Beginner-friendly with programming experience recommended

**Topics:**
- Week 1: Introduction to Machine Learning (supervised/unsupervised learning)
- Week 2–3: Linear Regression (simple, multiple, cost function, gradient descent, overfitting)
- Week 4–5: Logistic Regression & Regularization (L1/L2, dropout, early stopping)
- Week 6–7: Neural Networks (multiclass classification, backpropagation)
- Week 8: Support Vector Machines (hard/soft margin, kernels)
- Week 9–10: Clustering & Dimensionality Reduction (K-means, hierarchical clustering, PCA, t-SNE, autoencoders)
- Week 11: Large Scale Machine Learning (distributed computing, MapReduce)

**Assignments:** 11 programming assignments in Python/Octave/MATLAB, including:
- Linear regression for housing price prediction
- Image classification on MNIST dataset
- Spam detection using SVMs

**Prerequisites:** Programming experience (Python/R/MATLAB), basic linear algebra, calculus

**Notes:** Highly acclaimed, accessible instructor, practical hands-on experience with real-world problems.
