## Strength Training Plan

**Core Exercises (2-3x/week):**
- Plank: 30-60 sec holds, 3-5 sets
- Russian twists: 3 sets x 10-15 reps
- Leg raises: 3 sets x 10-15 reps
- Bicycle crunches: 3 sets x 10-15 reps

**Leg Exercises (2-3x/week):**
- Squats: 3 sets x 10-15 reps
- Lunges: 3 sets x 10-15 reps per leg
- Calf raises: 3 sets x 10-15 reps (2x/week)
- Deadlifts: 3 sets x 10-15 reps (1-2x/week)

**Key Principles:**
- Start with lighter weights, progress gradually (2.5-5lbs every 2-3 weeks)
- Focus on proper form over weight amount
- Target multiple muscle groups (squats, deadlifts, lunges)
- Allow 48-72 hours recovery between strength sessions
- Balance with cardio (running, tennis) and flexibility (stretching, yoga)
- Listen to body, take rest days as needed

**Goals:** Improve overall performance in tennis and running
