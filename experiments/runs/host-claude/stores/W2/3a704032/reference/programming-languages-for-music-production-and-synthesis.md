Languages commonly used in music production:\n- Max/MSP: visual programming for custom instruments and effects\n- Pure Data (PD): free/open-source, similar to Max, used for interactive music\n- SuperCollider: real-time audio synthesis and algorithmic composition\n- Csound: software synthesis system, 30+ years in use\n- Swift: for iOS/macOS music apps\n- ChucK: designed for real-time audio and music programming\n- Sonic Pi: beginner-friendly live coding environment\n\nBest for beginners: Sonic Pi, ChucK (simpler syntax, good documentation)
