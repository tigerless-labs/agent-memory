All2Trade is the user's proposed web application. It is intended to condense users' opinions about future cryptocurrency trends into automated trading decisions. Participation is free; the business trades using those opinions, pays contributing users a small percentage of payouts, and retains the difference. Intended users are anyone who wants to help the system make decisions and receive a portion of revenue.
