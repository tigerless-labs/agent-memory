Genius Voucher was described as an all-in-one hardware and software platform for NGO voucher-based humanitarian projects. It uses POS machines issued to authorized vendors, smart cards used by beneficiaries to receive items or cash, and a project portal for creating and monitoring distributions and generating accountability reports in real time.
