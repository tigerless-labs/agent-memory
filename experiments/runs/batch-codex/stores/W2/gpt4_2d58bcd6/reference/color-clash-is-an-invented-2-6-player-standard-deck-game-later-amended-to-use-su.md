Assistant-created game from 2023-05-30. **Color Clash** uses a standard 52-card deck for 2-6 players, with 7 cards dealt to each player. The initial rules mistakenly referred to four card colors; the user correctly noted that a standard deck has two colors, so the intended categories are the four suits: clubs, diamonds, hearts, and spades. The added meld rule defines a meld as three or more cards of the same rank, permits adding matching-rank cards to opponents' melds, and ends play when someone runs out of cards or the draw pile is depleted and no more melds can be made.
