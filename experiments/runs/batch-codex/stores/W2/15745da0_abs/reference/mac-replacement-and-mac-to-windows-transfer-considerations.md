Before migration, make a current backup using Time Machine, iCloud, or an external drive. Mac-to-Mac options include Migration Assistant and Target Disk Mode where supported. Mac-to-Windows options include an external drive or iCloud, Google Drive, Dropbox, or Microsoft OneDrive. Check APFS/NTFS and external-drive format compatibility, export Pages and Numbers documents to Windows-compatible formats, verify application compatibility, and transfer passwords, bookmarks, and settings.
