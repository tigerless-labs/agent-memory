The user wants to explore identity, memory, empathy, connection, and collective memory through interactive and immersive installations. One concept recreates a forest memory using sound, light, texture, birds chirping, leaves rustling, and the scent of damp earth. Another would combine found objects, images, and sounds from different cultures and time periods to evoke shared human experience.
