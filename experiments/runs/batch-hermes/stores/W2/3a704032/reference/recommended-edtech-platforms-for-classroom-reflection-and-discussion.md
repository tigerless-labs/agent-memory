Recommended tools for facilitating student discussion and reflection:
- Padlet: collaborative virtual wall
- Nearpod: interactive polls and open-ended questions
- Flipgrid: video response discussions
- Google Jamboard: visual collaborative whiteboard
Also recommended using the CRAAP Test (Currency, Relevance, Authority, Accuracy, Purpose) for evaluating online sources.
