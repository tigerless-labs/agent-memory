Languages for music production:
- Sonic Pi: beginner-friendly live coding environment
- ChucK: strongly-timed language for music programming and synthesis (zero-indexed arrays, fixed size, .cap() method)
- Python: general-purpose with music libraries
- Max/MSP: visual programming language for modular audio synthesis
- Pure Data (PD): free open-source visual programming language
- SuperCollider: real-time synthesis and algorithmic composition
- Csound: C-like software synthesis language
- Swift: used for iOS/macOS audio applications
