## Guild.xyz Overview

**What it does:**
- Platform for creating private, gated communities called "guilds"
- Tokenized membership with blockchain assets
- Platform-agnostic: integrates with Discord, other communication platforms, management tools, and games

**Key features:**
- Automated membership management
- Token-enabled exclusive membership levels
- Web3 phishing protection (captcha to filter bot scams)
- Real-time query engine: 1M+ tokens, 100K+ NFT projects, 10+ chains
- Composable membership requirements (logic gates, cross-chain)
- Allowlists and guest passes
- Cross-chain token gating

**Design philosophy:**
- Accessible: no-code, easy user experience
- Open-source (frontend and platform connectors)
- API/SDK available for developers
- Dedicated support
- Free to create guilds

**Traction (May 2023):**
- 10,000+ web3 users
- 600+ guilds created
- 1,929 commits on Github
- Notable guilds: ZetaChain (243K), Arbitrum (227K), Galxe (91K), Sui Ecosystem (67K)

**Use cases:** DAO management, Discord moderation, community organization
