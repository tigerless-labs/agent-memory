User wants compact and reliable portable SSD to expand new laptop storage and carry files on the go.

**Compact Options:**
- **Samsung T5 Portable SSD** — up to 2TB, 51g, sleek and compact
- **WD My Passport SSD** — up to 2TB, small and lightweight
- **SanDisk Extreme Portable SSD** — up to 1TB, rugged, built for durability and speed

**Reliable Brands:**
- **Samsung** — high-performance, reliable, wide range of portable options
- **WD (Western Digital)** — trusted brand, password protection features
- **SanDisk** — rugged, reliable, fast transfer speeds

**High-Capacity Options:**
- **Seagate Backup Plus Portable SSD** — up to 5TB, for large files and backups
- **G-Technology G-Drive Mobile SSD** — up to 4TB, built for creative professionals
- **LaCie Rugged SSD** — up to 2TB, extreme durability, security features

**Key considerations:** capacity, speed (USB 3.2 Gen 2, Thunderbolt 3), durability (water/dust resistance), security (password protection, encryption), operating system compatibility
