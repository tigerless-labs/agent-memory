## Data Visualization Learning Project (May 2023)

**Current Goal**: Learn data visualization in Python for a data analysis project.

**Background**:
- Participated in "Data Analysis using Python" webinar two months ago (approximately March 24, 2023), organized by an online learning platform
- Already has some experience with Python and data analysis
- Familiar with various data visualization resources

**Learning Path Decision**:
- **Chose Seaborn** to start with creating statistical graphics
- Reasoning: High-level interface, focus on statistical graphics, easier to learn, integrates with Matplotlib
- Plan to explore Matplotlib's low-level API for customization after becoming comfortable with Seaborn

**Dashboard Project**:
- Creating a dashboard to track key metrics for their project
- Evaluating tools: Tableau vs Power BI free trials
- Preference: Ease of use and customization options over data connection/integration
- Plan: Use Python to connect to data source, then create dashboard in Tableau or Power BI
- Next step: Try both Tableau and Power BI free trials, explore their Python APIs and documentation

**Communication Focus**:
- Interested in effectively communicating data insights to non-technical stakeholders
- Learned key principles: know audience, focus on story, keep it simple, use visual hierarchy, provide context, highlight key insights, avoid overload, use interactive visualizations when appropriate, provide recommendations
