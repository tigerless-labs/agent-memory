## Module 4: User Interface Design (UI) — Practical Exercises

### 1. Design a Landing Page
- Choose a product or service and design a landing page
- Determine layout and hierarchy of elements
- Choose typography, colors, and images aligned with brand
- Incorporate design elements (buttons, forms, icons)
- Optimize for conversion and engagement

### 2. Create a UI Kit
- Use design tool (Sketch, Figma, or Adobe XD)
- Create UI kit with basic design elements (buttons, forms, icons)
- Determine typography and color scheme
- Organize into categories for easy reuse
- Continuously update to reflect latest design trends

### 3. Redesign an Existing Product or App
- Choose existing product or app and analyze current UI design
- Identify areas for improvement
- Create redesign concept and sketch wireframes
- Create high-fidelity prototypes
- Conduct usability testing and iterate based on feedback
- Ensure alignment with business goals and user needs

### 4. Design a Mobile App
- Choose a type of mobile app (social media, fitness, etc.)
- Determine user flow and layout of app screens
- Choose typography, colors, and images aligned with app brand
- Incorporate design elements (buttons, forms, icons)
- Create high-fidelity prototype and conduct usability testing

### 5. Create a Design System
- Use design tool (Sketch, Figma)
- Determine typography, color scheme, and design elements
- Create style guide outlining components and usage guidelines
- Organize into categories for easy reuse
- Continuously update to reflect latest design trends

**Goal**: Learner applies UI design principles, gains hands-on experience with design tools, and builds ability to create visually appealing and user-friendly digital products.
