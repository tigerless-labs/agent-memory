## Garmin Bike Computer Setup Guide

**Initial Setup:**
- Ensure device fully charged
- Update to latest software via Garmin Express (download from Garmin website)
- Connect to computer with USB cable for calibration

**Bike Settings Configuration:**
- Enter wheel size in millimeters or inches (find in bike manual or online)
- Set bike type: road, mountain, etc.
- Configure other relevant bike-specific settings

**GPS & Location Accuracy:**
- Enable GPS and GLONASS (if available on model)
- GLONASS is Russian system complementing American GPS
- Dual system provides more accurate location data

**Ride Mode:**
- Select appropriate mode: Ride, Bike, Cycling, or specific type (mountain biking, indoor cycling)
- Ensures device tracks correct data type

**Data Screens:**
- Customize 3-5 data screens depending on device
- Common displays: speed, distance, heart rate, cadence, elevation
- Choose metrics most important for your riding style

**Unit Preferences:**
- Set distance units: miles or kilometers
- Set speed units: mph or kph
- Configure other metric preferences

**Auto Features:**
- Auto-pause: automatically pauses when stopped (at red lights, stops)
- Auto-lap: automatically marks splits/laps (e.g., every 5 miles)
- Both improve data accuracy and workout tracking

**Speed & Cadence Sensors (if equipped):**
- Follow manufacturer pairing instructions
- Ensure sensors properly paired with device
- Calibrate according to manufacturer guidelines

**Verification:**
- Start test ride and verify data tracking accuracy
- Review data during and after ride
- Confirm everything working before longer rides
