## Andrew Ng Machine Learning Course (Coursera)

**Enrollment Details:**
- Platform: Coursera
- Instructor: Andrew Ng
- Duration: 11 weeks (approximately 3-4 months)
- Time commitment: 2-3 hours per week
- Level: Beginner-friendly; programming experience recommended
- Certificate available upon completion

**Prerequisites:**
- Programming experience in Python, R, or MATLAB
- Basic linear algebra and calculus

**Topics Covered:**
- Week 1–3: Linear regression, cost functions, gradient descent, overfitting
- Week 4–5: Logistic regression, regularization (L1/L2, dropout, early stopping)
- Week 6–7: Neural networks, multiclass classification, backpropagation
- Week 8: Support Vector Machines
- Week 9: K-means clustering, hierarchical clustering, PCA
- Week 10: Dimensionality reduction (PCA, t-SNE, autoencoders)
- Week 11: Large-scale ML, MapReduce

**Assignments & Assessments:**
- 11 programming assignments + quizzes
- Implement algorithms from scratch
- Real-world examples: housing prices, MNIST digit classification, spam email classification
