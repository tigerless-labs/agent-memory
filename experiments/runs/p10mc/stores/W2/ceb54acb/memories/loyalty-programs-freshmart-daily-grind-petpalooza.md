- **FreshMart** — points-based system
- **The Daily Grind** — stamp-based system requiring 14 stamps for free drink; user has 12/14 stamps (needs 2 more)
- **PetPalooza** — points-based system

**Implementation strategy:**
1. Spreadsheet tracker with columns: Program Name, Currency Type, Current Balance, Needed for Reward, Expiration Date, Notes
2. Phone reminders set for specific locations/times to use loyalty apps or cards
3. Build habit by linking loyalty card use to daily routine activities (morning coffee, grocery shopping)
4. Stay informed about promotions and new offers through:
   - Newsletter registrations
   - Social media follows
   - Mobile app downloads with push notifications
   - Text message opt-ins
   - In-store promotion monitoring
   - Asking employees at frequent locations
   - Google Alerts for each program
   - Loyalty program aggregators (Stocard, AwardWallet)
