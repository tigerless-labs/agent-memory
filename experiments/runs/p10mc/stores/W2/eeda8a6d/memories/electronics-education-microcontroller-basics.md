## Session Overview
User requested PhD-level electronics teaching on modern technologies and asked fundamental questions about microcontroller architecture and how it differs from microprocessors.

## Microcontroller Fundamentals
- Complete system-on-chip (SoC): processor + memory + I/O peripherals
- Typical processors: ARM, PIC (low-power)
- Memory types: RAM (volatile), flash (non-volatile)
- Key peripherals: ADCs, DACs, timers, counters, UART, SPI, I2C
- Applications: automotive, aerospace, medical, consumer electronics, industrial automation

## Microcontroller vs Microprocessor
**Microcontroller (MCU)**
- Complete integrated system on single chip
- Includes CPU, on-chip memory, I/O peripherals
- Self-contained; designed to control external devices
- Lower power consumption

**Microprocessor (MPU)**
- Standalone CPU only
- Requires external memory and I/O components
- Used in PCs, servers, high-performance computing
- Higher processing power, more flexible
