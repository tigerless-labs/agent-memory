## Strike: Lightning Network Remittance App

**Overview**: Mobile application that enables instant, nearly-free international remittances using Bitcoin's Lightning Network infrastructure.

**Key features**:
- Users connect conventional bank accounts (don't need to own/understand Bitcoin)
- Automatically converts fiat currency to Bitcoin on Lightning Network
- Routes payment through LN to recipient
- Converts back to recipient's local currency
- Reduces cross-border remittance costs to near-zero

**Technology**: Uses Bitcoin Lightning Network as transport layer, not as asset for end-users.

**Value proposition**: 
- Instant international transfers
- Eliminates traditional remittance fees (Western Union, Money Gram model)
- Drives cost of cross-border payments toward zero
- Paves future for remittance industry

**Zizuh context**: Zizuh is planned as a competitive alternative using same Lightning Network approach.
