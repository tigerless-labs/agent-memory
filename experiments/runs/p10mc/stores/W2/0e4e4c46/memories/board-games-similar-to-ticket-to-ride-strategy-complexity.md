## Games Similar to Ticket to Ride

User requested board game recommendations with similar strategy and complexity to Ticket to Ride for hosting game nights.

**Suggested games:**
1. **El Grande** - Area control and strategy; build territories and collect victory points
2. **Carcassonne** - Tile-laying game; build medieval landscape with cities, roads, and fields
3. **Pandemic** - Cooperative game; work together to stop disease spread
4. **7 Wonders** - Card-drafting; build civilization by collecting structures, technologies, military units
5. **Azul** - Tile-laying and resource management; create decorative mosaics
6. **Scythe** - Worker placement game; build empires, manage resources in alternate 1920s (user's top choice)
7. **Castles of Burgundy** - Resource management and tile-laying; build estates and trade goods

All offer similar complexity and strategic depth while providing different gameplay mechanics and themes.
