## Algorithmic Approaches for Musical Pattern Generation
- **Markov chains**: generate note sequences based on transition probabilities from existing music datasets
- **Genetic algorithms**: evolve populations of musical phrases through selection, mutation, and crossover
- **Neural networks**: trained on music datasets to generate new melodies, chord progressions, drum patterns
- **Cellular automata**: generate note patterns from simple rules governing cell interactions
- **L-systems**: generate fractal patterns of notes from recursive rules
- **Spectral analysis**: analyze harmonic content of audio and generate new sounds

## Fractals in Generative Music
- Use fractal algorithms to create patterns as composition basis
- Create repeating but non-identical patterns (constantly evolving compositions)
- Apply fractal algorithms to synthesizer parameters for new sounds
- Use fractal patterns to control synthesizer parameters for visual-audio generation

## Math Applications in Music Production
- Karplus-Strong algorithm: synthesis for unique sounds
- Wave equation: sound design and manipulation
- Software implementations: Reason, Ableton Live, Logic Pro use mathematical formulas and algorithms
- Rhythm and melody: representable mathematically through algorithms
