## Name Change Record Update Checklists

### Physical Records (High Priority)

**Social Security Card:**
- Form SS-5 (available at SSA website or 1-800-772-1213)
- Required: certified copy of name change decree/divorce decree, proof of citizenship (birth certificate/passport), proof of identity, proof of name change
- Submit to local SSA office

**Passport:**
- Form DS-11
- Required: proof of citizenship, proof of identity, proof of name change (certified copy of decree), one passport photo
- Submit to passport acceptance facility

**Driver's License/State ID:**
- Check state DMV requirements (vary by state)
- Required: certified copy of name change decree, proof of identity, proof of residency
- Submit to local DMV

**Other Physical Records:**
- Voter registration
- Vehicle registration
- Property deeds
- Birth certificate (if needed)

### Online Accounts

**Financial/Banking:**
- Bank(s)
- Credit cards
- PayPal, Amazon, eBay

**Subscriptions:**
- Netflix, Hulu, Spotify, Apple Music, etc.

**Professional/Social:**
- LinkedIn (update name, education, experience, skills)
- Facebook, Twitter, Instagram, YouTube, TikTok, Pinterest
- Gmail/email signature
- Other social media and online communities

**Cloud Storage:**
- Google Drive, Dropbox, OneDrive, iCloud

**Other:**
- Gaming platforms (Xbox, PlayStation, Steam)
- Travel/loyalty programs (airlines, hotels)
- Health insurance, telemedicine services
- Alma mater/alumni association

### Tips

- Use consistent name format across all platforms
- Break updates into smaller chunks to avoid overwhelm
- Have documentation (certified decree) ready
- Allow several weeks for processing
- Update emergency contacts and beneficiary information
- Consider posting explanation on social media if desired
- Review and remove unused accounts
- Use password manager to track updates
