## Finding an appraiser

- **Professional Numismatists Guild (PNG)** — for currency/numismatic appraisers
- **International Association of Paper Money Dealers (IAPMD)** — for currency appraisers
- **Specialized experts** — reputable experts in specific collectible category (watches, comics, guitars, etc.)

## Appraisal process steps

1. **Research** — find reputable numismatic expert or professional appraiser specializing in item type
2. **Submit item** — send collectible to appraiser with relevant documentation (provenance, historical context)
3. **Examination** — appraiser carefully examines item checking condition, authenticity, rarity
4. **Research and verification** — appraiser researches item verifying existence, rarity, market demand

## Documentation received

### Appraisal report includes
- Description of item (denomination, series, condition for currency; model, serial, condition for watches, etc.)
- Appraiser's opinion on authenticity and rarity
- Estimated value based on current market conditions
- Relevant historical or provenance information

### Certificate of Authenticity
- Some appraisers provide separate certificate
- Verifies item's genuineness
- Used to prove authenticity to potential buyers

## Types of appraisals

- **Verbal appraisal** — casual, informal assessment; gives general value idea
- **Written appraisal** — more detailed, formal assessment with comprehensive report
- **Formal appraisal report** — detailed, extensive document with thorough analysis

## Best practices

- Choose reputable appraiser with expertise in specific collectible category
- Provide accurate, transparent information about history, condition, provenance
- Keep appraisal report and supporting documentation safe (useful for insurance, selling)
- Get multiple appraisals from different experts for more accurate value estimate
