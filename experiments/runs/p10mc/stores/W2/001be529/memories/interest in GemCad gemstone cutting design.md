The user is interested in gemstone cutting design using GemCad (gemstone cutting design software). They specifically referenced Dalan Hargrave's Fantasy Cut and wanted to understand the GemCad format/template structure rather than simply copying existing cut designs.

GemCad format structure:
- Header lines with version, index count, angle, facet count, refractive index
- Pavilion and crown angle specs
- Facet definition lines ("a" prefix) with: angle, height ratio, indexes, facet name, adjacent facet indexes, symmetry group
- Notes section ("F" prefix) for additional details

User prefers learning the template/format over receiving pre-made examples.
