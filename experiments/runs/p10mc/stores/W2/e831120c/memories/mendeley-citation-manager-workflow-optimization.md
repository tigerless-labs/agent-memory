## Citation Manager: Mendeley

### Key Features Discussed
1. **Library Organization** — Folders/subfolders hierarchically by topic/project/author; tags and keywords with auto-suggest
2. **PDF Management** — PDF importer extracts metadata; PDF annotation with highlighting/notes/sticky notes
3. **Citation Styles** — Supports 8,000+ citation styles (APA, MLA, Chicago); Word/LibreOffice plugin for in-text citations
4. **Collaboration** — Create private/public groups; shared folders with collaborators
5. **Search & Discovery** — Boolean operators and filters; recommendation engine based on library contents
6. **Integration** — Web importer from Google Scholar, PubMed, Web of Science; cloud syncing across devices
7. **Analytics** — Paper statistics, co-author network visualization

### Optimization Strategies
- Use web clipper to save papers directly to library
- Designate "watch folders" for automatic paper importing
- Create custom citation styles with citation style editor
- Use Mendeley's recommendation engine for related papers
- Regularly backup citation manager database

### Workflow for Organizing Research Papers by Relevance
1. Create top-level thesis folder as centralized hub
2. Create subfolders by chapter
3. Assign tags by theme/methodology/key topics
4. Use star ratings (1-5 stars) to prioritize by relevance
5. Create "must-read" folder/tag for essential papers
6. Take detailed notes on each paper:
   - Its relevance to thesis
   - Key findings
   - How it contributes to research
7. Review and refine organization regularly as research evolves

### Best Practices
- Organize papers as you research, not after
- Use consistent tagging system across library
- Cite as you write rather than leaving citations for end
- Verify citations regularly for accuracy
- Perform batch processing (import multiple papers at once)
- Leverage collaboration features if working with team
