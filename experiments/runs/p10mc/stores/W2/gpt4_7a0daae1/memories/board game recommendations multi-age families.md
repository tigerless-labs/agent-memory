Board game recommendations suitable for families with mixed ages:

1. **Ticket to Ride** - Ages 8+, train-themed, easy to learn with strategic depth
2. **Pictionary** - Ages 8+, drawing game, great for groups who know each other
3. **Scattergories** - Ages 10+, creative word game with category constraints
4. **Cranium** - Ages 10+, combines drawing, acting, trivia, wordplay
5. **Clue** - Ages 8+, classic detective/mystery solving game
6. **Uno** - Ages 6+, simple card game, plays quickly
7. **Settlers of Catan** - Ages 10+, strategy game with good depth
8. **Forbidden Island/Forbidden Desert** - Ages 10+, cooperative games
9. **Apples to Apples** - Ages 10+, party game with matching/selection
10. **Guess Who** - Ages 6+, classic guessing game

Most play with 2-6 players and can be adjusted for different age groups and attention spans.
