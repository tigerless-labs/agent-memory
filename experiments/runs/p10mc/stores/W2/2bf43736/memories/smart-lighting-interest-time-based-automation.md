## Smart Lighting Project

**Interest:**
- Smart bulbs that adjust brightness and color temperature throughout the day
- Automation features (scheduling, routines, geofencing)
- Integration with voice assistants

**Key Features Being Considered:**
- Scheduling: Set specific times for brightness/temperature changes
- Routines: Create moods for different times (e.g., "Wake Up", "Relax")
- Color Temperature Adjustment: Warmth/coolness changes
- Brightness Adjustment: Dimmable throughout day
- Automation: Sensor-based or voice-controlled

**Popular Smart Bulb Brands:**
- Philips Hue (comprehensive system)
- LIFX (remote control, long lifespan)
- Belkin Wemo (budget-friendly)
- IKEA Tradfri
- Samsung SmartThings

**Technical Considerations:**
- Hub/bridge requirements (some need hub, others connect directly)
- Wi-Fi compatibility
- Color temperature range
- Brightness levels
- Power outage memory feature
- Voice assistant compatibility (Alexa, Google Assistant, HomeKit)
