## Flow Blockchain Ecosystem
- **Flow Access API** — used to create and manage user accounts on Flow blockchain
- **Flow SDK** — APIs for interacting with smart contracts on Flow network

## NFT Marketplaces on Flow
- **Niftory** — tool for creating and minting NFTs on Flow blockchain
- **Puddle** — secondary market for buying, selling, trading NFTs on Flow

## Smart Contract Concepts
- **DEX (Decentralized Exchange) Swap Contracts** — enable swapping one cryptocurrency for another without intermediary; uses algorithms to determine exchange rates; auto-executes when conditions met
- **Evaluate's Swap Contract** — example DEX contract on Ethereum (written in Solidity); includes whitelist, fee handling, automatic liquidity provision; supports ERC-20 tokens and Ether

## User Onboarding: Blockchain Abstraction
Key principle: hide blockchain complexity to attract mainstream users
- Replace wallet setup with email/social login
- Enable credit card purchases instead of requiring crypto
- Hide technical details: gas fees, transaction confirmation, key management
- Goal: traditional web app UX, not blockchain-native interface

## API Role in Blockchain Development
- Standardized way for applications to interact with blockchain network
- Used to automate tasks and enable integration across platforms
- Simplifies development by reducing custom code needs
