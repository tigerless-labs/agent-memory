## Project Overview
User is building an educational game on the Flow blockchain with the following features:

### NFT Integration
- Using Niftory and Puddle Side by Side as NFT marketplaces
- Players can buy, sell, and trade in-game NFTs
- Secondary market for game assets

### Player Earning Mechanisms
1. Mining - players earn crypto by contributing mining power
2. Quests and challenges - earn crypto/NFTs for completing educational tasks (coding challenges, answering questions)
3. Trading and investing - buy/sell/trade NFTs on open market
4. Staking - earn interest on cryptocurrency holdings
5. Referral programs - rewards for bringing new players

### User Experience Goals
- Abstract away blockchain complexity for new users
- Sign up via email or social identity (not wallet setup)
- Purchase NFTs directly with credit cards (not crypto)
- Hide technical blockchain details (gas fees, transaction times, keys)
