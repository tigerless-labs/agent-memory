## Project Overview
User is developing an educational game on the Flow blockchain that incorporates NFT mechanics and monetization.

## NFT Marketplace Integration
- Plans to use **Puddle** and **Niftory** as NFT marketplaces for the game
- Both are Flow blockchain-based NFT platforms
- Strategy: create unique NFTs (mining rigs, rare items, collectibles) → list on Puddle/Niftory → players trade on secondary market

## Player Monetization Methods
1. **Mining** — players earn cryptocurrency by contributing mining power
2. **Quests and Challenges** — earn crypto or NFTs for completing educational tasks (coding challenges, quiz questions)
3. **Trading and Investing** — buy/sell/trade NFTs on open market; collect rare/valuable NFTs
4. **Staking** — earn interest on cryptocurrency holdings; earn percentage of transaction fees
5. **Referral Programs** — reward players for bringing in new users

## Blockchain Abstraction Strategy
Planning to hide blockchain complexity from new users:
- Sign up via email/social identity (not wallet setup)
- Purchase NFTs with credit cards (not crypto)
- Hide technical details (transaction times, gas fees, public/private keys)
- Goal: make experience feel like traditional web app, not blockchain tech

## Reference Game
**Crypto Quest** — educational blockchain game user is studying as reference; teaches blockchain/crypto basics through quests, rewards, and social features
