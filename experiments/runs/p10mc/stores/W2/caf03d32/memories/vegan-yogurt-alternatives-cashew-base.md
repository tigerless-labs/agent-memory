## Vegan Yogurt Alternatives

**Options for Slow Cooker Yogurt Base:**
1. **Soy Yogurt** — Silk, So Delicious
2. **Coconut Yogurt** — So Delicious, Coconut Bliss, Coyo (creamy and rich)
3. **Almond Yogurt** — Almond Breeze, Silk, So Delicious (low-calorie, low-fat)
4. **Cashew Yogurt** — So Delicious (creamy, indulgent) — user's preference
5. **Oat Yogurt** — Oatly, So Delicious (good for nut allergies)
6. **Rice Yogurt** — Rice Dream, So Delicious (hypoallergenic, easy-to-digest)
7. **Hemp Yogurt** — Good Karma, Elmhurst 1925 (protein-rich, omega-3s)
8. **Flax Yogurt** — Good Karma (low-calorie, high-fiber)

**Important notes:**
- Choose unflavored and unsweetened varieties to avoid extra sugars and flavorings
- Always check ingredient list and nutrition labels
- Use vegan yogurt starter or probiotic powder specifically designed for plant-based yogurts
