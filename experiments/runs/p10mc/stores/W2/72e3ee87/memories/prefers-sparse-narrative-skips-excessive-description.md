## Reading Style Preference

When discussing "Wuthering Heights," expressed discomfort with:
- Detailed descriptions of settings (moors, houses) that feel like "reading a travel guide"
- Actively skims long descriptive passages
- Finds the detailed moor descriptions distractingly prominent compared to plot/character focus
- Dislikes writing that feels "trying too hard to be poetic"

Prefers:
- Setting incorporated organically into story/character development
- Succinct, straightforward storytelling
- Focus on characters and plot over atmospheric description

Example: In "Wuthering Heights," felt Emily Bronte could have woven setting details into narrative more elegantly rather than listing every detail. Acknowledges setting has thematic value but wishes it weren't so foregrounded.
