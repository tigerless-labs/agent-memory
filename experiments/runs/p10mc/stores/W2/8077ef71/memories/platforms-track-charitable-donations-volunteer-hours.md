## Platforms for Tracking Charitable Activities

User wants centralized platform to track donations and volunteer hours.

Recommended platforms:
- GivingGrid — track donations, volunteer hours, fundraising efforts; discover new charities
- DonorPerfect — donor management software; track donations, receipts, charitable activities; set reminders/notifications
- Network for Good — donate to charities, track donations, receive receipts and tax deductions
- VolunteerMatch — volunteer network connecting to nonprofits; track volunteer hours, log activities, earn badges/rewards
- Bright Funds — donate to multiple charities through single platform, track donations, earn rewards/badges
- Charity Navigator Giving Basket — track donations, set up recurring gifts, receive receipts and tax deductions

All should be researched for security before creating accounts.
