## Expense Tracking Setup

**Method**: Spreadsheet (Google Sheets or Excel)

**Categories**:
- **Gifts** — birthday gifts, baby shower gifts, housewarming gifts
- **Charitable Giving** — groceries for Mrs. Johnson (elderly neighbor)

**Spreadsheet Structure**:
- Columns: Date, Description, Amount
- Tracking for category totals and running totals

**Google Calendar Integration**:
- Setting reminders for upcoming birthdays, baby showers, celebrations
- Reminders set 2-3 weeks in advance for planning time
- Notes include gift ideas and budget amounts
- Using different colors/labels for event types
- Setting recurring events for annual birthdays
