## Adobe Premiere Pro Lumetri Color Panel

User is learning advanced video editing in Premiere Pro and has decided to focus on the Lumetri Color Panel rather than Legacy Color Grading tools for their projects.

### Key Features Learned

**Creative Panel:**
- Intuitive, visual approach to color grading
- Six sections: Look, Color, Tone, Vibrance, Saturation, Exposure
- Best for quickly applying looks, broad creative adjustments, subtle natural-looking grades
- Good entry point for establishing a base look

**Curves Panel:**
- More advanced, technical approach with precise control
- Adjusts tonal range via x-axis (input) and y-axis (output) graph
- Three types: Luma Curve, Color Curve, Hue vs. Saturation Curve
- Best for precise technical adjustments, high accuracy work, complex nuanced grades

**Color Match Feature:**
- Automatically matches color/tone of one clip to another
- Useful for different cameras, lighting conditions, inconsistent scenes
- Analyzes: color tone, skin tones, exposure, contrast
- Can be applied node-by-node for targeted adjustments

**Color Wheels:**
- Three circular controls for shadows, midtones, highlights
- Make targeted adjustments to specific color ranges
- Use for warming/cooling, enhancing/muting colors, skin tones, skies
- Enables consistent look across shots

### Techniques for Cinematic Look

**S-Curve Method:**
- Add points at ~20-30% (shadows) and ~70-80% (highlights)
- Create gentle smooth curve that dips in shadows, rises in highlights
- Adds contrast and depth

**Toe and Shoulder Controls:**
- Toe: adjusts shadows (0-20%), affects black levels and shadow contrast
  - Toe In: reduce shadow contrast, lift blacks
  - Toe Out: increase shadow contrast, crush blacks
- Shoulder: adjusts highlights (80-100%), affects brightness and tone
  - Shoulder In: reduce highlight brightness, soften roll-off
  - Shoulder Out: increase highlight brightness, abrupt roll-off
- Start with subtle adjustments and fine-tune

### Best Practices for Color Grading

1. Start with a neutral grade (flat state) as clean slate
2. Work in consistent color space (Rec. 709 or DCI-P3)
3. Establish a color script/visual plan for palette, tone, mood
4. Work dark to light: shadows and midtones before highlights
5. Make subtle adjustments, avoid drastic changes
6. Reference work regularly during process
7. Maintain consistency throughout video

### Workflow

1. Establish base look using Creative panel (choose preset, fine-tune)
2. Refine with Curves panel for precise tonal/contrast adjustments
3. Balance overall brightness, contrast, color
4. Check levels with Histogram and Waveform monitors
5. Make local adjustments with Color Wheels or gradient filter
6. Fine-tune with subtle adjustments
7. Check work regularly for cohesion
