## Music Programming Learning Path

**Decision (May 21, 2023):** Starting with **Sonic Pi** as entry point to music programming.

### Why Sonic Pi
- Free and open-source
- Simple, beginner-friendly syntax
- Real-time feedback as code is written
- Good for live coding music
- Active community support

### Resources to Explore
1. Built-in tutorials (Help → Tutorial)
2. Example code library (Help → Examples)
3. Online communities: Twitter, Sonic Pi forums, Discord
4. Video tutorials: Sonic Pi Live Stream on Twitch
5. Local workshops or classes

### Previously Explored: ChucK
- Learned array syntax and indexing
- Studied melody arrays: `int melody[] = [60, 62, 64, 65, 67, 69, 71, 72];`
- Studied multi-dimensional arrays for chord progressions: `int chords[][] = [[60, 64, 67], [57, 60, 64], ...]`
- Understands `.cap()` method for array length

### Interest Areas
- Array applications in music
- Algorithmic composition
- Creating melodies and chord progressions
- Real-time music synthesis
