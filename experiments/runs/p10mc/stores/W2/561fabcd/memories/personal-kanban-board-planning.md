## Personal Kanban Project

**Date discussed:** May 21, 2023

**Goal:** Create a personal Kanban board to organize and visualize task workflow.

**Board options:**
- Digital: Trello, Asana
- Physical: Whiteboard, corkboard

**Workflow columns (customizable):**
1. To-Do — tasks waiting to start
2. In Progress — active work
3. Done — completed tasks

**Setup process:**
1. Determine scope (work tasks, personal tasks, or both)
2. Choose board format
3. Define columns tailored to your needs
4. Write tasks on sticky notes or cards, place in To-Do
5. Move tasks across columns as work progresses
6. Regularly review board and adjust priorities

**Key principle:** Keep the system simple and easy to use to avoid creating overhead.
