## Recurring Events Setup
- Creating separate "Gaming Sessions" calendar
- Setting recurring events (weekly, every 2 weeks, etc.)
- Adding dual time zones (both user and partner)
- Adding partner as guest via email invitation

## Google Calendar Features
- Find a time feature checks attendee availability, suggests time slots
- Propose a new time feature suggests alternatives if initial suggestions don't work
- Multiple reminder options: email, popup, Android notifications
- Preset reminders available: 10, 30, 60 minutes before event
- Custom reminder timing available

## Video Conferencing Integration
- Google Hangouts Meet integrated directly into events via Add conferencing
- Other tools like Zoom, Skype, Discord can add conferencing links
- Automatic meeting links included in invitations
- One-click join from calendar event

## Key Tips
- Gaming partner must share calendar for Find a time to work
- Setting specific event duration helps with accurate time suggestions
- Can use all features with recurring events like weekly gaming sessions
