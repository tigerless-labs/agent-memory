## Dell Inspiron 15 5000 (2018) Battery Issue

- **Model**: Dell Inspiron 15 5000 series (from 2018)
- **Use case**: Primary work laptop
- **RAM upgrade**: Recently upgraded to 16GB
- **Battery issue**: After RAM upgrade, battery life decreased from 6–7 hours to 4–5 hours
- **Other hardware/software changes**: None besides RAM upgrade
- **Battery status**: Using original battery
- **Troubleshooting plan**: Battery calibration (drain to 0%, charge to 100%, repeat 2–3 times)
- **Possible causes**: Battery recalibration needed, increased power consumption from additional RAM, or system resource changes
- **Next steps**: Monitor system resource usage in Task Manager, check power plan settings, consider BIOS update if calibration doesn't help
