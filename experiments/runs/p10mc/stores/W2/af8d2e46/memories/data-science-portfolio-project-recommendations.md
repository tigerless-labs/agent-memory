## Portfolio Strategy
Projects should demonstrate these core areas all three programs (Stanford, Berkeley, CMU) value:

### Data Visualization Projects
- Dashboard using Tableau or Power BI
- Interactive visualization with D3.js or Plotly
- Report/presentation effectively using visualizations to tell story
- **Berkeley emphasis**: visualization exploring social or environmental issues
- **CMU emphasis**: interactive visualizations enabling data exploration

### Data Manipulation & Analysis Projects  
- Complex dataset wrangling and preprocessing using Pandas/NumPy
- Exploratory data analysis (EDA) with statistical and visual methods
- Data mining: clustering, decision trees, regression
- Big data tools: Hadoop, Spark, or NoSQL databases

### Machine Learning Projects
- Implement and train models using scikit-learn, TensorFlow, or PyTorch
- Feature engineering, model selection, hyperparameter tuning
- Model evaluation using metrics: accuracy, precision, recall
- Compare/contrast different ML algorithms

## Sharing Platforms
- GitHub: code examples and full projects
- Kaggle: competitions and datasets
- Google Colab: notebooks with explanations
- Tableau Public: interactive visualizations
- Personal portfolio: context for each project (problem → data → insights)

## Key Qualities to Highlight
- Ability to work with different tools and libraries; willingness to learn new ones
- Understanding of core concepts: data cleaning, feature engineering, overfitting/underfitting, regularization
- Ability to extract insights and communicate results effectively through visualizations and reports
