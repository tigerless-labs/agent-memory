abstract: User finds multi-factor authentication and password management inconvenient, prefers convenience over security steps when accessing online accounts
---

In May 2023 conversation, user expressed skepticism about the value of personal data protection measures. Key points:

- Initially thought personal data "not that valuable" and questioned why companies need to invest in security
- Finds it "too much hassle" to remember multiple passwords and go through extra authentication steps
- Would prefer if companies made it easier to access information, even if it means less security
- Acknowledged the inconvenience of 2FA, multiple passwords, and other security measures

When explained why data security matters (identity theft, fraudulent credit/loans, tax returns), user still emphasized the inconvenience factor as a primary concern.

**Biometric alternatives that interest user:** fingerprint recognition, facial recognition — these were presented as easier ways to maintain security without the password burden.

This reveals a preference for usability over security when the two conflict, though user is willing to listen to explanations of why security matters.
