## Experience Level
- Complete beginner to woodworking
- First project: wooden pedestal with rounded base for F-16 model display

## Project Scope
- Simple wooden pedestal design (rounded base to complement F-16's sleek lines)
- Beginner-friendly complexity level
- Softwood material (pine or fir preferred)
- Will apply protective coating (stain/polyurethane/wax)

## Resources & Learning Path
- Planning to explore YouTube channels (The King of Random, Steve Ramsey, Woodworking Adventures)
- Considering local woodworking classes/workshops for hands-on experience
- Will reference: The Spruce Crafts, Woodworking Magazine, Instructables

## Key Beginner Tips for Self
- Prioritize safety equipment: safety glasses, dust mask, push stick
- Start with basic hand tools (tape measure, marking gauge, hand saw, clamps)
- Practice on scrap wood before working on pedestal
- Measure twice, cut once
- Sand thoroughly and apply finish to protect wood
- Join online woodworking communities for advice

## Design Intentions
- Rounded base shape (may need template/pattern to cut accurately)
- Consider cutting base in pieces then assembling for easier handling
- Add felt or foam base to prevent model slipping/scratching
