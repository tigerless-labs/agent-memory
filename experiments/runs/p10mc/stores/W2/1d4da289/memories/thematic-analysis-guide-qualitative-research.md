## Thematic Analysis Overview
Qualitative data analysis method for identifying, coding, and categorizing patterns or themes. Flexible and iterative process to uncover underlying meanings, concepts, and experiences in data.

## Seven-Step Process

1. Familiarize with data - read and re-read to understand content
2. Initial coding - assign codes to data segments
3. Coding framework development - group codes into categories and themes
4. Coding and theme identification - apply framework to entire dataset
5. Theme refinement and naming - review and refine themes
6. Theme mapping and diagramming - create visual diagrams of relationships
7. Theme interpretation and reporting - interpret in context of research questions

## Best Practices
- Use a coding framework to organize data
- Be open to emergent themes
- Refine framework as analysis progresses
- Create visual representations of relationships
- Link themes back to research questions
