## Lightroom Mobile vs Desktop

**What Lightroom Mobile Shares with Desktop**:
- Non-destructive editing (originals untouched, edits as metadata)
- Basic adjustments: exposure, contrast, highlights, shadows, color grading
- Presets library (apply with single tap)
- Selective adjustments to specific image areas
- Syncs with Lightroom catalog on desktop

**Key Limitations of Mobile Version**:
- Smaller feature set than desktop
- Simplified touch-friendly interface for small screens
- File format: DNG only (doesn't support native RAW from other manufacturers)
- Limited local adjustments vs desktop's Adjustment Brush and Gradient Filter
- Some desktop edits don't sync across devices (especially local adjustments)

**Missing Features**:
- Tone Curve
- Split Toning
- Lens Corrections
- Advanced local adjustment controls

**Best Use Pattern**:
- Edit on desktop (access full feature set)
- Refine on mobile (portability and convenience)
- Or: export desktop-edited images and re-import to mobile for further adjustments

**Summary**: Excellent companion app for quick on-the-go editing, not a replacement for desktop. Powerful syncing with desktop workflow but with reduced feature depth for touch interface.
