## Green Card Eligibility Categories

Family-Based Immigration using Form I-130 (Petition for Alien Relative)
- Spouse
- Parent
- Child
- Sibling

Employment-Based Immigration using Form I-140 (Immigrant Petition for Alien Worker)
- Job offer
- Investor
- Special skills

Other Categories
- Diversity visa (DV) lottery
- Refugee or asylum status

## Green Card Application Steps

1. Determine eligibility and choose correct category
2. Gather required documents (biographic, identity, citizenship, family, employment)
3. File appropriate petition form with USCIS
4. Wait for processing and interview scheduling
5. Undergo medical examination by USCIS-designated civil surgeon
6. Attend interview and receive decision
7. Receive green card if approved

## Required Documentation

- Passport-style photos
- Fingerprints via USCIS biometric appointment notice
- Valid passport
- Birth certificate with English translation if applicable
- Previous US visas and I-94 arrival/departure records if applicable
- Family relationship documents (marriage certificate, birth certificates of children, divorce or death certificates if applicable)
- Employment documents if job-based application

## Key Guidance

- Consult immigration attorney to confirm eligibility category
- Gather all documents and translations before submitting
- Be honest and accurate on all forms and during interviews
- Resolve family member visa status issues (overstay) before submitting own application
