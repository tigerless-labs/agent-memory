## Technology Stack

**Backend**: Python with Django Rest Framework
**Frontend**: React with Redux state management
**Database**: Azure Database for MySQL
**Deployment**: Microsoft Azure (Azure App Service)
**Version Control**: GitHub with SSH authentication

## Development Tools (July 2023 recommendations)

**IDE/Editor**: Visual Studio Code with extensions for Python, JavaScript, linting, debugging

**Git Management**:
- GitHub Desktop or GitKraken for GUI
- GitHub Actions for CI/CD pipelines
- GitHub Codespaces for cloud-based development environment

**API Development**: Postman for testing Django Rest Framework endpoints

**Front-end Debugging**: React Developer Tools, Redux DevTools (browser extensions)

**Project Management**: Trello for task tracking, Slack for team communication

**CI/CD**: Azure DevOps for build, test, deploy automation (integrates with Azure infrastructure)

## GitHub Codespaces Workflow

- Create codespace from repository Code button
- Full VS Code environment in browser
- Extensions installable from Marketplace
- Integrated terminal for running commands
- Built-in debugging and Git integration
- Delete when finished to free resources
