## Aircraft Cockpit Detailing Techniques

**Instrument Panels:**
1. Research reference images of F-15E cockpit layout and colors
2. Use cockpit-specific decals for instrument faces and warning lights (dry transfers or waterslide)
3. Paint background with dark gray or black acrylic
4. Add highlights and shading with small brush for depth
5. Create or add raised details: knobs, switches, buttons (plastic/resin parts or scratch-built with wire/plastic card)
6. Apply subtle weathering: dust, grime, scratches for used appearance

**Ejection Seats:**
1. Reference F-15E ejection seat design, colors, details
2. Paint seat base with acrylic, using color combinations for realistic worn look
3. Add seat details: belts, harnesses, buckles (plastic/resin or scratch-built materials)
4. Apply weathering: wear, tear, staining
5. Add texture using textured paint or paint mixed with acrylic gel

**General Tips for Cockpit Work:**
- Use magnifying glass or lamp for visibility and precision
- Work in layers from basic shapes to detailed elements
- Continuously reference photos for accuracy
- Practice on test pieces first
- Small details make huge visual impact despite scale
