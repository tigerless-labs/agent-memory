## Interest
User is interested in learning full-stack web development (both front-end and back-end).

## Recommended Learning Path
1. Start with front-end basics: HTML, CSS, JavaScript
2. Learn a back-end language: Python, Ruby, or PHP
3. Build projects combining both
4. Stay current with new technologies
5. Join developer communities

## Recommended Resources

**Front-end:**
- Codecademy (interactive lessons)
- FreeCodeCamp (free, comprehensive)
- Udemy (beginner to advanced)

**Back-end:**
- NodeSchool (Node.js workshops)
- Udacity (Python, SQL, Flask, Django)
- Coursera (Java, Spring, Hibernate)

## Key Insight
Full-stack developers need both hard skills (multiple programming languages) and ongoing learning, but gain the advantage of understanding the entire web development process.
