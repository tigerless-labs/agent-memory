## Ultegra Pedal Upgrade Project

Planning to upgrade road bike pedals to **Shimano Ultegra clipless pedals**, which have excellent reviews.

**Why the upgrade:**
- Improved pedaling efficiency (consistent pedal stroke)
- Increased power transfer for sprints and climbs
- Reduced fatigue on long rides
- Better control during cornering/descending

**Installation approach:**
- Ordering pedals online
- Plans to install self with basic tools (pedal wrench, Allen wrenches, torque wrench)
- Will read manual first and follow Shimano's torque specifications
- Willing to take to local bike shop for help if needed

**Other research findings:**
- Shimano makes multiple pedal types: SPD-SL (road), SPD (mountain), SPD-R (hybrid)
- Road pedals lighter/more aerodynamic than mountain pedals
- Key features to look for: adjustable float, release tension, weight, durability

**Next steps:**
- Order pedals
- Practice clipping in/out before actual ride
- Adjust cleats for comfort and security
