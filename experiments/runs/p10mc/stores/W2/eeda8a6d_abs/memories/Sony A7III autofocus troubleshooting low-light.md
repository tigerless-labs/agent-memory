Issue Details

Camera: Sony A7III
Lens: Sony 100-400mm E-mount native
Autofocus Mode: Single-Shot AF
Problem: Fails to focus intermittently indoors in dimly lit rooms
Behavior: No specific pattern, sometimes fails to focus
Firmware: Recently updated, not yet latest version

Recommended Settings to Try

1. Enable AF Micro Adjustment (Camera Settings > AF2 > AF Micro Adj.)
2. Set AF Drive Speed to Fast or Faster (Camera Settings > AF2 > AF Drive Speed)
3. Switch from Wide to Zone or Flexible Spot AF Area
4. Enable AF Illuminator if lens supports it
5. Clean lens and sensor
6. Update to latest camera firmware

User agreed to try these settings.
