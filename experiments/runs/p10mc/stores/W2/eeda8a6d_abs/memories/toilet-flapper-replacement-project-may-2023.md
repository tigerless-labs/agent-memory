## Toilet flapper replacement project

**Issue:** Toilet not flushing properly

**Solution approach:** Replace the flapper (DIY project)

**Preparation:**
- User already purchased replacement flapper compatible with their toilet model
- User feels confident proceeding with replacement

**Planned steps:**
1. Turn off water supply (locate shut-off valve behind toilet, turn clockwise)
2. Flush toilet to drain tank
3. Disconnect chain from flapper and flush handle
4. Remove old flapper from overflow tube (may need to wiggle)
5. Inspect and clean overflow tube area for mineral buildup/debris
6. Install new flapper, ensure properly seated
7. Reconnect chain, adjust length as needed
8. Turn water supply back on (turn valve counterclockwise)

**Tips given:**
- Work carefully to avoid damaging overflow tube or components
- Take time with the task
- YouTube tutorial available as backup if needed
- If uncomfortable, consult a plumber
