## Recommended Artists for Inspiration

- **Carsten Höller** - German artist known for interactive installations with slides, Ferris wheels, playful elements
- **Anicka Yi** - Korean-American artist creating immersive, scent-based installations exploring art, science, technology relationships
- **Rafael Lozano-Hemmer** - Mexican-Canadian artist creating interactive installations using biometrics, robotics, exploring surveillance and control themes

## Recommended Exhibition Spaces

- **Meow Wolf** (Santa Fe) - Collective creating immersive, interactive exhibitions blending art, technology, storytelling
- **The Color Factory** (San Francisco) - Interactive art installations exploring emotional and psychological effects of color
- **TeamLab** (Japan) - Collective creating stunning immersive exhibitions using technology and light for interactive environments

## Online Resources for Discovery
- Artspace - digital platform for interactive/immersive art experiences
- The Creators Project - showcases interactive art, music, technology projects
- Hyperallergic - art publication covering interactive/immersive exhibitions

## Technologies and Techniques Recommended

**Multi-sensory Technologies:**
- 3D audio / spatial audio (respond to viewer movement)
- Projection mapping (images/textures on walls/floor)
- Scent diffusion devices
- Haptic feedback (vibrating floors, walls, objects)

**For Collective Memory Concept:**
- Data visualization techniques
- Augmented reality (overlaying historical content)
- Interactive storytelling / branching narratives
- Collaborative platforms for viewer contributions

## Software/Tools to Explore
- **Unity** - popular game engine for interactive experiences
- **Max/MSP** - visual programming for interactive installations, sound/video manipulation
- **OpenFrameworks** - open-source C++ library for interactive installations
- **Arduino** - microcontroller platform for interactive objects and installations
