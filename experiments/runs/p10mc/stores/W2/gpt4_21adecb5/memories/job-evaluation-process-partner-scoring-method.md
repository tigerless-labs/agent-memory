## Evaluation Methodology

**Process Flow**
1. User provides block of candidate Q&A responses
2. Assistant confirms readiness with "Ready to Evaluate"
3. User requests evaluation on a specific criterion
4. Assistant provides numerical score (0-100) with supporting rationale

**Scoring Context**
- Scores should reflect the candidate's profile and explicit statements
- Rationale should reference specific quotes or behaviors from candidate responses
- Example criterion used: "Need for external support" 
  - Candidate scored 70 on this criterion
  - Rationale: candidate values mentorship and friend support, relies on others for enjoyment and grounding, but shows some self-reliance through sports achievement and professional growth

- Cycling-Manchester United-soccer coach candidate
- Evaluation date: 2022-10-22
- Criterion: Need for external support
- Score: 70
