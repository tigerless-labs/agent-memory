## Vintage Barbie Collection Documentation

User owns vintage Barbie dolls from the 1960s and is documenting them as part of an overall collectibles cataloging project.

**Plan:**
- Take high-quality photos of each doll
- Create spreadsheet to catalog collection
- Get appraisals for accurate value assessment
- Use documentation for collectibles insurance

**Value information for reference:**
- Early Barbie dolls (1961-1963): $300-$5,000+ depending on model
- Mid-1960s (1964-1966): $100-$1,000
- Later 1960s (1967-1969): $20-$300
- Condition, rarity, and original packaging significantly affect value
- #1 Ponytail Barbie (1959): $1,000-$5,000+
- Bubble Cut Barbie (1961): $300-$1,500
- American Girl Barbie (1965): $100-$600

**Documentation approach:**
- Using photos, itemized lists, and professional appraisals
- Considering specialized collectible insurance options
