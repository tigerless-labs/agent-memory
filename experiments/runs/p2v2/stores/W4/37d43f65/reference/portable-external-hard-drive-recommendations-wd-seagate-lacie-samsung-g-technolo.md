**Recommended portable external hard drives:**

1. Western Digital My Passport - compact, up to 5TB, various colors, password protection
2. Seagate Backup Plus - slim/lightweight, up to 5TB, Windows/Mac compatible, built-in USB hub
3. LaCie Rugged - rugged/waterproof, up to 5TB, durable design
4. Samsung Portable SSD - fast, compact, up to 2TB, ideal for on-the-go backups
5. G-Technology G-Drive Mobile - high-performance, up to 4TB, Windows/Mac compatible, Thunderbolt 3

**Selection factors:**
- Storage capacity needed
- Speed requirements (SSD vs HDD)
- Durability needs
- OS compatibility
- Security features (encryption/password protection)

**3-2-1 backup strategy:** 3 copies of data, on 2 different media types, with 1 offsite copy
