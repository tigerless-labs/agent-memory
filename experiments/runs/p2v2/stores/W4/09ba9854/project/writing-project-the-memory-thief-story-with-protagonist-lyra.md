Working on sci-fi romance story centered on protagonist Lyra, a skilled memory thief hired to steal memories from a powerful CEO. Lyra has fragmented memories with no recollection of their own past, creating central mystery of the narrative. Key plot elements: uncovering Lyra's true past and reason for memory loss; discovering CEO's true intentions and consequences of theft. Story explores identity, authenticity of experience/relationships, trust, and self-discovery through memory manipulation themes.
