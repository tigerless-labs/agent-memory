Online Resources & Tools for Character Development

Websites:
- Writers Digest: Character Development guide
- The Creative Penn: Character Development resources  
- Helping Writers Become Authors: Character Development category
- The Write Practice: Character Development Exercises
- Novel Writing Help: Character Development Exercises

Character Profiling Tools:
- Reedsy Character Profile Template (free downloadable) - 12 sections: basic info, physical appearance, personality, backstory, motivations, conflict, relationships, skills/abilities, fears/phobias, habits/quirks, emotional landscape, character evolution
- 16 Personalities: Free personality test tool for character insights

Recommended Books:
- 'Characters & Viewpoint' by Orson Scott Card - comprehensive character creation guide
- 'The Writer's Journey: Mythic Structure for Writers' by Christopher Vogler - hero's journey and character archetypes
- 'How to Write Short Stories and Use Them to Further Your Writing Career' by James Scott Bell - includes character development section

Brainstorming Exercises:
- Mind mapping for visualizing connections
- What-if questioning for exploring character responses
- Character interviews and monologues
- Scene writing to showcase character in action
- Character journaling from protagonist perspective
