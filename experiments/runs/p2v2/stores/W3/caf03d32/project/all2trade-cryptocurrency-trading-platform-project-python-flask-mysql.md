## Project: All2Trade\n**Purpose**: Automated cryptocurrency trading system leveraging crowdsourced user opinions to generate revenue\n\n**Business model**:\n- Users provide free opinions on currency trends via simple interface\n- System automatically executes trades based on aggregated opinions\n- Revenue generated from trades; users paid small percentage of profits\n- Platform takes difference as revenue\n\n**Tech stack**:\n- Backend: Python 3\n- Framework: Flask\n- Database: MySQL\n- Automation: Celery (scheduled tasks)\n- Libraries: Pandas (data), ccxt (exchange integration)\n- Auth: Flask-Login, Flask-JWT\n\n**Features**:\n- Completely automated and minimal\n- User authentication/authorization\n- Opinion collection interface\n- Automated trading execution\n- Payout system to contributors
