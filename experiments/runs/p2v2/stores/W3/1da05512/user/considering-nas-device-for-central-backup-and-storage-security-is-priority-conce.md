Current setup: backing up to external hard drive. Looking to upgrade.

Requirements:
- Central backup location for laptop, phone, and other devices
- Strong security features (encryption, access control)
- Capacity for files, videos, other media

Security priorities:
- AES-256 bit encryption for data at rest and in transit
- Granular access control / role-based access control (RBAC)
- Two-factor authentication (2FA)
- Regular security updates

Researched models:
- High-end: Synology DiskStation DS1819+, QNAP TS-1685, Netgear ReadyNAS RN628X
- Mid-range: Synology DS418play, QNAP TS-453D, Asustor AS6404T
- Budget: Western Digital My Cloud EX2 Ultra, Seagate Personal Cloud
- 2-bay vs 4-bay decision pending (balancing budget, space, future expansion needs)
