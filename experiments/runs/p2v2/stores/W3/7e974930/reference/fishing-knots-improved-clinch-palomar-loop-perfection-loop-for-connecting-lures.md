**Fishing knots for connecting lures to line:**

**1. Improved Clinch Knot**
Most widely used in fishing. High breaking strength, easy to learn.
- Thread line through lure eye
- Make small loop with line between thumb and index finger
- Pass tag end through loop
- Pass tag end through loop again from same side as before
- Moisten knot, pull tight by pulling tag end
- Trim excess tag end

**2. Palomar Knot**
Known for strength and reliability.
- Thread line through lure eye
- Make small loop with line between thumb and index finger
- Pass tag end through loop
- Pass tag end through loop again from opposite side
- Pass tag end through loop again from original side
- Moisten knot, pull tight by pulling tag end
- Trim excess tag end

**3. Loop Knot (Perfection Loop)**
Creates secure loop; won't slip. More time-consuming but very reliable.
- Hold line between thumb and index finger, making small loop
- Pass tag end through loop
- Pass tag end through loop again from same side
- Pass tag end through loop from opposite side
- Moisten knot, pull tight by pulling tag end
- Trim excess tag end
- Attach loop to lure by passing loop through eye of lure

**General tips:**
- Always moisten knot with saliva or water before pulling tight
- Pull tight by pulling on tag end, not main line
- Practice tying until proficient
- Trim excess tag end close to knot to avoid weak points
