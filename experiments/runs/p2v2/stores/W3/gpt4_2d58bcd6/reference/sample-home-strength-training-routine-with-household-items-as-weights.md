Example home strength training routine structure:

Equipment ideas:
- Water bottles or cans (1-2L) as dumbbells
- Backpack with books or weights
- Resistance bands
- Bodyweight exercises

Sample routine:

Monday (Upper Body):
1. Warm-up: 5-min jog or jumping jacks
2. Push-ups: 3 sets x 10-12 reps
3. Dumbbell press: 3 sets x 10-12 reps
4. Dumbbell rows: 3 sets x 10-12 reps
5. Tricep dips: 3 sets x 10-12 reps

Wednesday (Lower Body):
1. Warm-up: 5-min jog or jumping jacks
2. Squats: 3 sets x 10-12 reps
3. Calf raises: 3 sets x 10-12 reps
4. Lunges: 3 sets x 10-12 reps per leg
5. Glute bridges: 3 sets x 10-12 reps

Friday (Core):
1. Warm-up: 5-min jog or jumping jacks
2. Plank: 3 sets x 30-60 sec hold
3. Russian twists: 3 sets x 10-12 reps
4. Leg raises: 3 sets x 10-12 reps
5. Bicycle crunches: 3 sets x 10-12 reps

Principles:
- Focus on compound exercises
- Gradually increase weight/reps (progressive overload)
- Vary routine every 4-6 weeks
- Always warm up and cool down
