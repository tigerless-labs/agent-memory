Python bot template for Bitcoin trading. Uses ccxt library to connect to Bitmex exchange (BTC/USD). Features: fixed position size (1.0), stop-loss level, take-profit level, price monitoring loop. Sells at take-profit or stop-loss, waits 60 seconds between price checks. Basic example for learning bot trading concepts.
