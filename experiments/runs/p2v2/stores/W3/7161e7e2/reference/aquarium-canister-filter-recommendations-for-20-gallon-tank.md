**Canister Filter Options (May 2023):**

Eheim Classic 2211: Excellent filtration, quiet, somewhat bulky. Price $100-150.

Fluval 206: Compact, quiet, designed for 20-40 gallons. Price $100-150.

Hydor Professional 150: Modular design, very quiet, easy maintenance, built-in primer. Price $150-200.

API SuperClean: Easy setup and maintenance.

Flow rate needed: 100-200 gallons per hour. Biological media options include ceramic rings (6-12 month replacement), bio-balls (6-12 months), sintered glass (12-24 months), filter pads (1-3 months). Fill media basket to 2/3-3/4 capacity. Rinse new media in old tank water before adding.
