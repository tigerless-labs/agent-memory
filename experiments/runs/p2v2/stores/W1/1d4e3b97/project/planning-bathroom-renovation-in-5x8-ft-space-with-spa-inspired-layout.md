User is planning to redo a 5x8 foot bathroom with a spa-inspired retreat design. Key features:
- Keep existing tub, plus add freestanding tub
- Large walk-in shower with glass enclosure
- Double sink vanity
- Focus on relaxing, luxurious aesthetic

**Decisions made:**
- Tile: Glazed porcelain tile for both walls and floor (chosen for glossy finish, durability, stain resistance, and ease of cleaning)
- Grout: Cement-based grout (chosen as affordable, all-purpose option)

**Next steps:**
- Source materials (tiles, grout, tub, fixtures)
- Plan plumbing/electrical updates
- DIY what possible, hire pros for plumbing/electrical as needed
