System design for blockchain-based document verification:

**Key features:**
1. Online document submission capability
2. Blockchain document registry check - if document not found, sends approval request to relevant government agency (e.g., BIR for income tax returns, Office of Permits and Licenses for business permits)
3. Automatic blockchain storage once approved and verified by government agency
4. AI-based verification using:
   - OCR for text extraction
   - NLP for key feature identification (date, name, ID number)
   - Machine learning for document authenticity comparison
   - Digital signature and encryption
   - Pattern/anomaly detection for fraud identification

**Agencies involved:**
- BIR (Bureau of Internal Revenue) - income tax returns
- Office of Permits and Licenses - business permits

**Process flow:**
Submit online → Check blockchain → If not found, request agency approval → Agency verification → Auto-store in blockchain → User notification

Incorporates novel and non-obvious AI methods for enhanced security.
