External hard drive recommendations for photo backup storage:

Models discussed:
- Western Digital My Book (up to 16TB, Mac/PC compatible, compact)
- Seagate Backup Plus (up to 5TB, sleek design, 2-year warranty)
- LaCie Rugged (up to 5TB, durable/waterproof for rough handling)
- G-Technology G-Drive (up to 10TB, high-performance for creative professionals)

Key selection factors mentioned:
- Capacity (calculate 2-3x current storage needs)
- Interface (USB 3.0, Thunderbolt 3, USB-C)
- Speed (7200rpm or SSD preferred)
- Durability if transported
- Built-in encryption/security features
- Warranty length
- Portability

Backup strategy: 3-2-1 rule (three copies, two different media types, one offsite)
