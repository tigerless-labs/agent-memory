The Reedsy character profile template is a comprehensive 12-section tool that guides character development through: basic info, physical appearance, personality, backstory, motivations, conflicts, relationships, skills/abilities, fears/phobias, habits/quirks, emotional landscape, and character evolution. Also recommended: Writers Digest character development articles, The Creative Penn, Helping Writers Become Authors, and books by Orson Scott Card ('Characters & Viewpoint'), Christopher Vogler ('The Writer's Journey'), and James Scott Bell.
