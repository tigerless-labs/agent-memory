Interested in music production and programming. Explored several languages:
- ChucK: designed for music; supports array-based melody/chord generation
- SuperCollider: real-time audio synthesis
- Max/MSP: visual programming for custom instruments
- Pure Data: free/open-source version of Max/MSP
- Csound: long-established synthesis system
- Sonic Pi: beginner-friendly live coding environment for music

**Chose Sonic Pi to start** because:
- Simple syntax, easy to learn
- Real-time feedback as code runs
- Built-in tutorials and examples
- Active community with resources
- Available for workshops and online learning

**Resources to explore:**
- Built-in tutorials via Help menu
- Sample code examples
- Video tutorials (Sonic Pi Live Stream on Twitch)
- Online forums and unofficial Discord server
- Local workshops and classes at music schools/community centers
