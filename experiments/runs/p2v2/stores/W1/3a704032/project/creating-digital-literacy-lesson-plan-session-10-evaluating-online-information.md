Developed a lesson plan for the 10th session of a digital literacy course for 6th-grade elementary students.

**Session Focus:** Evaluating Online Information and Source Credibility

**Key Framework:** CRAAP Test
- Currency: timeliness of information
- Relevance: applicability to research topic  
- Authority: credibility of author/source
- Accuracy: reliability and verifiability
- Purpose: author's intent and bias

**Lesson Structure (60 minutes):**
1. Introduction (10 min): Frame the importance of verifying online sources
2. Instruction (20 min): Teach CRAAP Test framework with examples; practice with sample articles
3. Activity (30 min): Students research assigned topics, find 2 sources each, evaluate using CRAAP Test worksheet, present findings to class with reasoning
4. Break (10 min)
5. Discussion (20 min): Build class list of evaluation tips; practice techniques
6. Conclusion (10 min): Recap key takeaways

**Assessment Methods:**
- Review student CRAAP Test worksheets
- Evaluate student presentations
- Short quiz or class discussion

**Materials Needed:**
- Computers/internet access
- CRAAP Test worksheets (printed)
- Sample articles for practice
- Whiteboard for class list of tips
