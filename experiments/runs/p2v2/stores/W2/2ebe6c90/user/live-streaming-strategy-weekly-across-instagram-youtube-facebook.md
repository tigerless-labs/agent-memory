Doing at least one live stream per week across multiple platforms. Strategy includes:
- Planning engaging, mixed content types (Q&A, tutorials, behind-the-scenes, skincare/beauty)
- Keeping an ideas journal for content inspiration
- Repurposing existing content into new formats
- Tailoring content to each platform's audience expectations

Platform approach:
- Instagram: 10-30 min, visually-focused, mobile-first
- YouTube: 30-60 min, in-depth tutorials, high production value
- Facebook: 30-90 min, community-focused, personal stories

Current focus: live makeup tutorials on YouTube due to audience questions about skincare/beauty routine.
