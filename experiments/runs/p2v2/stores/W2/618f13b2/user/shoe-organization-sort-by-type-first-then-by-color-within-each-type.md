Prefers to organize shoe collection using a two-tier system:
1. First tier: sort by type (heels, flats, boots, sneakers, sandals, dress shoes)
2. Second tier: within each type, organize by color (neutrals, brights, pastels, etc.)

Additional practices:
- Stores out-of-season shoes in storage bins to free up rack space
- Keeps frequently worn shoes at eye level or front and center for easy access
- Uses shoe trees and stuffs shoes with paper to maintain shape and prevent creasing

Appreciates organized, visual systems that make it easy to find what's needed.
