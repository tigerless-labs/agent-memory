User has noticed online shopping habits adding up and is committing to cut down spending. Plans to:
- Track expenses more closely and set a budget
- Implement 'one in, one out' policy: get rid of an old item every time a new one enters home
- This creates mindfulness around purchases and reduces impulse buying
- User recognizes that inconsistent practice (e.g., a few times a week vs daily) is still worthwhile
