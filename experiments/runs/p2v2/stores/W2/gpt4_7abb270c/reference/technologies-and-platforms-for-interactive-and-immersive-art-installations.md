## Software Platforms\n- **Unity** — game engine for interactive immersive experiences\n- **Max/MSP** — visual programming language for interactive installations, sound/video manipulation\n- **OpenFrameworks** — open-source C++ library for interactive installations\n- **Arduino** — microcontroller platform for interactive objects and installations\n\n## Techniques and Technologies\n- **3D audio** — spatial audio responding to viewer movement\n- **Projection mapping** — project images/textures onto surfaces\n- **Scent diffusion** — scent-emitting devices for multi-sensory experience\n- **Haptic feedback** — vibrating floors, walls, objects for tactile experience\n- **Data visualization** — representing connections across cultures and time periods\n- **Augmented reality (AR)** — overlay historical images, sounds, texts on physical space\n- **Interactive storytelling** — branching narratives, choose-your-own-adventure interfaces\n- **Collaborative platforms** — allow viewers to contribute stories, images, objects to archive\n\n## Reference Artists\n- **Carsten Höller** — interactive immersive installations with slides, Ferris wheels, playful elements\n- **Anicka Yi** — scent-based immersive installations exploring art, science, technology\n- **Rafael Lozano-Hemmer** — interactive installations with biometrics, robotics on surveillance/control themes\n- **Meow Wolf** — Santa Fe collective creating immersive interactive exhibitions blending art, tech, storytelling\n- **TeamLab** — Japanese collective, technology and light creating interactive environments
