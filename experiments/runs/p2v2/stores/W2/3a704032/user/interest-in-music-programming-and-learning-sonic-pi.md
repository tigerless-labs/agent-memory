Interested in getting into music production and coding. Chose Sonic Pi as the starting point because it's beginner-friendly with:
- Simple, easy-to-learn syntax
- Real-time feedback as you write code
- Live coding environment designed specifically for music

Resources to explore:
- Built-in tutorials in Sonic Pi
- Sample code examples in the application
- Community: Sonic Pi forums, Twitter, unofficial Discord server
- Video tutorials online (e.g., 'Sonic Pi Live Stream' series on Twitch)
- Local workshops or community classes on music programming

Also learned about other music programming languages that might be relevant for deeper exploration:
- Max/MSP (visual programming, commercial)
- Pure Data/PD (free, open-source, similar to Max/MSP)
- SuperCollider (real-time audio synthesis and algorithmic composition)
- Csound (software synthesis system, 30+ years old)
- ChucK (concurrent language for real-time audio)
- Swift (for creating music apps on Apple devices)

Music programming applications include creating melodies, rhythms, chord progressions, algorithmic compositions, and more complex musical structures.
