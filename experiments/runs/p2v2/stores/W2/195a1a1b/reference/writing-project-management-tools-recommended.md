Tools recommended for organizing writing projects and tracking progress:

Project Management:
- Trello (boards, lists, cards for project stages)
- Scrivener (writing software with built-in project management)
- Asana (task management with deadlines)

Note-Taking and Organization:
- Evernote (notebooks, tags, notes)
- Google Sheets (spreadsheet for tracking)
- Ulysses, Byword, Novelize (writing apps with project management)

Writing Progress Tracking:
- Wordcounter (daily word count tracking)
- Writeordie (word count with timer mode)
- WriteTrack (word count, time spent, streaks, customizable goals) - RECOMMENDED
- Habitica (gamified habit tracking)
- HabitBull (simple habit tracking)
- NaNoWriMo writing tools
- 750 Words (writing community platform)

Other:
- YWriter, WriteWay, StoryBox (writer-specific software)
- Calendar apps for deadlines and reminders
- Paper planners or bullet journals
