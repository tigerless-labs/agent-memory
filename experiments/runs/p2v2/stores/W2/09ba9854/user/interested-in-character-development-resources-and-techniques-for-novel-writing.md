When writing fiction, focuses on detailed character development. Uses resources like:\n- Reedsy character profile template (12 sections: basic info, physical appearance, personality, backstory, motivations, conflict, relationships, skills, fears, habits, emotional landscape, evolution)\n- Writers Digest character development articles\n- The Creative Penn\n- Brainstorming techniques: mind mapping, 'what if' questions, character interviews, scene writing, character journaling\n\nKey interest areas: character motivations, short/long-term goals, internal and external conflicts, character flaws and how they react to obstacles.
