## Lyra Character (The Memory Thief)

**Role**: Protagonist; skilled memory thief hired to steal a powerful CEO's memories.

**Core Setup**:
- No recollection of own past; fragmented, unclear memories
- Identity is shrouded in mystery even to themselves
- Must confront the possibility their memories/identity may be fabricated or altered

**Story Arcs**:
- Discovers clues about own past while stealing CEO's memories
- Key plot twist: revelation of true past and reason for memory loss
- Forces character to re-evaluate sense of self and purpose
- Relationship arc: slow-burn connection with their mark (the CEO)
- Must decide whether to continue as memory thief or forge new path

**Themes**: Identity, authenticity of memory and experience, self-discovery, vulnerability and trust

**Setting Context**: Dystopian future with advanced neurotechnology allowing memory extraction, storage, and manipulation. Memories can be transferred between people but process is risky and alters personality.
