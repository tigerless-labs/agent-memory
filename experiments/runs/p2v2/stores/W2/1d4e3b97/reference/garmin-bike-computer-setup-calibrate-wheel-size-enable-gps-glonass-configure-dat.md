**Garmin Bike Computer Setup for Accurate Readings**\n\n**Initial Setup:**\n1. Charge fully and update to latest software via Garmin Express\n2. Configure bike settings:\n   - Enter wheel circumference in millimeters or inches (found in bike manual or online)\n   - Set bike type (road, mountain, etc.)\n3. Enable GPS and GLONASS for dual-satellite accuracy\n4. Choose appropriate ride mode (Ride, Bike, or Cycling)\n\n**Data Configuration:**\n1. Customize data screens (typically 3-5 screens available)\n2. Display preferred metrics: speed, distance, heart rate, cadence\n3. Set units of measurement (miles/km, mph/kph)\n\n**Advanced Features:**\n1. Auto-pause: automatically pause when stopped\n2. Auto-lap: mark splits at intervals (e.g., every 5 miles)\n3. Speed and cadence sensors: calibrate if using them\n\n**Verification:**\n- Test during a ride to ensure accurate tracking\n- Review data during and after ride\n- Confirm distance and speed readings match expectations
