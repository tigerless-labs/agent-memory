## Project Overview
- Combining seasonal photography + wildlife/nature themes
- Focus on natural settings (forest, wetland, or similar location)
- Goal: capture how light and colors change throughout the year
- Plan to visit a specific location regularly (park or trail)

## Long-term Goal
- Attempt to photograph same scene at same time each year
- Document transformation across multiple years to see how it changes over time

## Skills & Techniques
- Experimenting with different photographic techniques and compositions
- Using mobile editing tools: Lightroom Mobile, VSCO, Snapseed
- Organizing photos with keywords, folders, ratings system

## Motivation Strategy
- Set realistic milestones
- Create shooting schedule (regular visits as non-negotiable appointments)
- Track progress in journal/log
- Share work for feedback and community
- Celebrate milestones

## Status (as of Aug 2023)
- Excited about starting the seasonal project
- Researching best locations for the project
