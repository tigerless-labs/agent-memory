# Ceramics Learning

Learning ceramics and pottery, specifically:
- **Current project**: Hand-building earthenware vases using coiling and scoring techniques
- **Skills developing**: Coiling, scoring, glaze application, glaze formulation, kiln firing
- **Interest in**: Creating custom glaze recipes, achieving food-safe finishes, experimenting with different clay bodies (earthenware, stoneware, air-dry clay)
- **Focus areas**: Consistent glazing techniques, firing temperature control, food-safety standards

Interested in exploring clay body types:
- Earthenware (currently using) - low firing temperature, colorful glaze options
- Stoneware - more durable, high-temperature firing, food-safe
- Air-dry clay - for projects without kiln access

Resources mentioned: Simon Leach Pottery, Pottery By Osa, The Ceramic School, Ceramic Arts Network, Craftsy
