**Date discovered:** May 2023

Exploring programming languages for music production and algorithmic composition. Starting with beginner-friendly options.

**Languages explored:**
- **ChucK**: Sound interesting for audio synthesis and music programming
  - Arrays for melody/chord progression generation
  - Real-time audio synthesis capabilities
  - Good for learning music programming fundamentals

- **Sonic Pi**: Chosen as starting point for actually learning
  - Free and open-source live coding environment
  - Simple syntax, easy learning curve
  - Real-time feedback as you code
  - Great for beginners

**Other languages of interest (for later):**
- Max/MSP (visual programming, electronic music)
- Pure Data (free alternative to Max/MSP)
- SuperCollider (real-time audio synthesis, experimental music)
- Csound (synthesis system, 30+ year track record)
- Swift (iOS/macOS music apps)

**Resources to explore:**
- Sonic Pi built-in tutorials and examples
- Online community (forums, Discord, Twitter)
- Video tutorials (Sonic Pi Live Stream on Twitch)
- Local workshops/classes if available
