Interested in learning music programming. Explored options including ChucK, Max/MSP, Pure Data, SuperCollider, and Csound. Chose Sonic Pi because it has a low learning curve, user-friendly live-coding interface, active community, and built-in tutorials. Learning interests include using arrays to create melodies, chord progressions, and algorithmic composition. Started learning as of May 2023.
