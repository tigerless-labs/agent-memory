**Project name:** All2Trade

**Purpose:** Automated cryptocurrency trading system that uses collective user opinions to make trading decisions and generate revenue.

**Technology stack:**
- Language: Python 3
- Backend framework: Flask
- Database: MySQL
- Deep learning: TensorFlow/PyTorch/Keras (planned)
- Automation: Celery (for scheduled tasks)
- Crypto exchange integration: ccxt library

**Business model:**
- Platform is completely free for users
- Revenue generated by trading using user opinions
- Users receive small percentage of trading profits
- Platform keeps the difference

**Features:**
- Completely automated and minimal interface
- Simple interface for users to provide opinions on currency trends
- Users predict trends (up, down, neutral) for currencies they want to trade
- Deep learning system learns from data and improves predictions over time
- Periodic model retraining with latest market data

**Database structure includes tables:**
- Users: id, username, password, email, first_name, last_name
- Opinions: id, user_id, currency, trend, timestamp
- Trades: id, currency, trend, buy_price, sell_price, profit, timestamp
- Payouts: id, user_id, amount, timestamp

**Future enhancement:**
- Add deep learning system that learns from historical data and user opinions
- Model input: users' opinions + market data + relevant information
- Model output: probability distribution of future currency trends
- Continuous model improvement through regular retraining
