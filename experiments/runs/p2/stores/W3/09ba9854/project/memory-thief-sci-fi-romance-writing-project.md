Working on a sci-fi romance story titled "The Memory Thief" exploring themes of identity and self-discovery. 

**Protagonist:** Lyra, a skilled memory thief with no clear memory of their own past - fragmented and unclear recollections.

**Setting:** Dystopian future where memories can be extracted, stored, and sold on black market. Advanced neurotechnology enables memory manipulation.

**Plot:** Lyra is hired to steal memories from a powerful CEO. As they uncover the CEO's memories, they discover clues about their own past and true identity. Key plot twists include Lyra's discovery of their true past/reason for memory loss and revelation of the CEO's true intentions.

**Themes:** Identity, self-discovery, authenticity, the nature of memory and self. Also interested in exploring "The Royal Affair" concept (sci-fi romance with forbidden interspecies love).
