Experimenting with Negroni variations using different bitter liqueurs to change flavor profile: Cynar (artichoke, vegetal), Aperol (orange-forward, lighter), Luxardo Bitter (herbal, intense), Suze (gentian, crisp/earthy), Meletti (citrus-forward, smooth). Also exploring White Negroni using dry vermouth (Dolin recommended) instead of sweet, with Suze or Luxardo Bitter for drier, more herbaceous profile. Learning to adjust ratios and balance flavors as liqueur changes.
