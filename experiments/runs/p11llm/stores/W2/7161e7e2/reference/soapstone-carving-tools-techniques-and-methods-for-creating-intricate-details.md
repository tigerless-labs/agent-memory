**Basic Tools**
- Carving tools set: gouges (remove small amounts, create details), chisels (remove larger amounts, deeper grooves), files (smooth and refine), rasps (shape smooth, especially curves)
- Safety equipment: dust mask, safety glasses, gloves

**Core Techniques**
- Rough shaping — use gouges and chisels to remove excess and create overall shape
- Refining — use files and rasps to smooth surface, remove rough spots
- Detailing — use small gouges and chisels for intricate details (feathers, eyes, beaks)
- Texturing — create surface textures like feathers, fur, scales

**Methods for Intricate Details**
- Stippling — detailed patterns using small dots/points, useful for feathers or scales
- Hatching — detailed lines using small parallel strokes, for feathers or fur
- Relief carving — carve design into soapstone, creating raised or recessed effect
- Inlaying — insert small pieces into carved design, often for eyes or beaks

**Best Practices**
- Work in small sections to maintain focus and avoid mistakes
- Use reference images of birds for accuracy
- Experiment with different tools and techniques
- Practice patience — soapstone carving requires time and repetition to master
