## Progressive\n- **Snapshot**: Usage-based program with up to 30% discount\n- **Loan/Lease Gap Coverage**: Covers difference if vehicle is totaled\n- **Advanced Safety Features Discount**: For lane departure warning, blind spot detection, forward collision warning\n- **Disappearing Deductible**: Reduces deductible over time if accident-free\n- **Name Your Price Tool**: Set desired premium and get customized policy\n- Other discounts: accident forgiveness, good driver, multi-car, bundling, paperless\n\n## State Farm\n- **Drive Safe & Save**: Similar to Progressive's Snapshot program\n- **Car Safety Features Discount**: For advanced safety systems\n- **Large agent network**: Local personalized service\n- **Praised claims process**: Known for efficiency\n- Other discounts: multi-car, bundling, defensive driving, good student
