Bedroom ceiling light is too harsh and disrupts cozy ambiance. Considering two approaches:

**Option 1: Dimmer switch**
- Adjustable brightness for flexibility
- Works with LEDs, halogens, incandescent
- Requires installation but universal

**Option 2: Softer bulb**  
- Replace with warm white bulb (2700K-3000K)
- Gentler on eyes
- Simpler, no installation needed

**Plan**: Will try both options to see which works best for bedroom aesthetic. Install dimmer switch if wanting flexibility, or use warm soft bulb. LED bulbs recommended.
