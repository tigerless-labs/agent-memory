Recommended external hard drives for backing up high-resolution photos:\n\n1. **Western Digital My Book** - Up to 16TB, compact, built-in power management, Mac/PC compatible\n2. **Seagate Backup Plus** - Up to 5TB, sleek design, 2-year warranty\n3. **LaCie Rugged** - Up to 5TB, rugged and durable for rough handling, Mac/PC compatible\n4. **G-Technology G-Drive** - Up to 10TB, high-performance for creative professionals, fast transfer speeds\n\nFactors to consider: capacity (2-3x current needs), compatibility (Mac/PC), interface (USB 3.0, Thunderbolt 3, USB-C), speed (7200rpm or SSD), durability, power requirements, security features (encryption, password protection), warranty, portability, and price.\n\nBest practice: Follow the 3-2-1 backup rule (three copies, two different media types, one offsite), set up automatic backups, and verify backups periodically.
