Decision: Chose Construct 3 as the game engine for a 2D deserted island escape game.

Game Concept:
- Goal: Player must build a raft to escape the island
- Core mechanic: Collect 8 materials through exploration and puzzle-solving
- Progression: Finding materials unlocks clues and doors; solving riddles and puzzles reveal material locations

Game Chapters (Development Plan):
1. Game concept and mechanics (completed)
2. Engine selection: Construct 3 chosen (completed)
3. Visual and audio elements (in progress)

Why Construct 3: Beginner-friendly, drag-and-drop interface (no coding), good for 2D games, free version available, easier than Unity/Unreal/Godot
