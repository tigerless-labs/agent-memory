Breathing meditation is recommended as entry point. Start with 5 minutes daily, gradually increase. Daily consistency more important than session length. Six main meditation types: mindfulness, transcendental, loving-kindness, body scan, breathing, and visualization. Each has different purpose - stress reduction, relaxation, compassion cultivation, body awareness, or mental focus. Use quiet environment, consider guided recordings, don't worry about thought distractions.
