Troubleshooting guide for TP-Link Archer AX50 when experiencing slow internet speeds.

**Router Access:**
- Default IP: 192.168.0.1 or 192.168.1.1
- Default credentials: admin / admin

**Wireless Settings to Check:**
- Channel Width: set to 20/40 MHz or Auto
- Channel: try specific channels (1, 6, 11) instead of Auto to reduce interference
- Wireless SSID: ensure unique name

**Firmware Update Process:**
1. Visit tp-link.com, Support section
2. Search for Archer AX50
3. Download latest firmware (.bin file)
4. Log into router web interface
5. Navigate to Management/Advanced Settings > Firmware Update
6. Upload firmware file
7. Do NOT interrupt or turn off router during update
8. Router will reboot automatically to apply

**Additional Troubleshooting:**
- Use Wi-Fi Analyzer tool to check for channel congestion
- Check for device interference (cordless phones, microwaves, etc.)
- Optimize router placement (central, elevated, away from obstacles)
- Set up Quality of Service (QoS) for bandwidth prioritization
- Try cold reboot: unplug 30 seconds, plug back in
- Temporarily reduce connected devices to test if congestion is cause
