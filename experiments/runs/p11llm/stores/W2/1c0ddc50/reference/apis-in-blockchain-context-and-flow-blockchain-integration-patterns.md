APIs (Application Programming Interface) provide standard protocols for software components to communicate and exchange information across platforms and languages.

**Blockchain API uses:**
- Flow Access API: Create and manage user accounts on Flow blockchain
- Flow SDK: Interact with smart contracts on the network
- DEX swap contracts: Facilitate cryptocurrency swaps without intermediaries (e.g., Evaluate's Swap Contract)

**Benefits:**
- Streamline development with standard interaction patterns
- Enable third-party integrations (access data, trigger actions)
- Facilitate automation and workflow integration
- Support seamless user experiences (e.g., social login integration)

**In game context:** APIs allow game backends to interact with blockchain networks and smart contracts for NFT management, token transfers, and transaction handling.
