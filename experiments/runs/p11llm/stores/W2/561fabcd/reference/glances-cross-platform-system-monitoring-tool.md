Glances is a cross-platform system monitoring tool for Linux, Windows, and macOS written in Python using psutil library.

Features:
- Real-time monitoring of CPU, memory, disk I/O, network activity, and more
- Client-server architecture for remote monitoring  
- Web-based interface for viewing system metrics
- Alarms and notifications based on system metrics
- Plugin support for extending functionality

Can export metrics to InfluxDB via InfluxDB export plugin for integration with Grafana dashboards. Useful for system administrators and developers to identify performance bottlenecks and troubleshoot issues.
