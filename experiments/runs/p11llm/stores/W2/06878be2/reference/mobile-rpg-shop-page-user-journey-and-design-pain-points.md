## User Journey Flow

1. Player accesses shop through main menu or dedicated button
2. Browse items/categories (in-game currency, equipment, consumables, cosmetics)
3. Use sorting/filtering options to narrow search
4. View item details (stats, effects, appearance) and compare
5. Purchase using real money or in-game currency
6. Receive purchase confirmation; item added to collection/inventory
7. Continue browsing or exit shop

## Pain Points to Address

- Unclear or incomplete item information
- High prices or limited availability
- Technical issues or purchase errors
- Security/fairness concerns

Developers can address these through clear info, fair pricing, reliable/secure purchase system, and prompt issue resolution.

*Discussed in context of Hearthstone shop system*
