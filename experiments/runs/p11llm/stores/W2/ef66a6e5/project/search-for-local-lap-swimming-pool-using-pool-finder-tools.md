## Pool Finder Tools
- Swim.com: Filter by hours, pool length, temperature, programs/teams
- PoolFinder: Filter by hours, pool characteristics, programs/activities  
- USA Swimming Pool Finder: Filter by pool hours, pool characteristics, programs/teams

## Search Tips
- Use keywords: morning lap swim, early bird swim, dawn patrol, 25-yard pool, short course
- Filter by USMS (United States Masters Swimming) affiliation
- Contact pools directly to confirm details not listed online

## Questions to Ask Pools
- Equipment: kickboards, pull buoys availability and cost
- Lane sharing: designated fast/medium/slow lanes, circle swimming direction
- Programs: masters swimming, swim teams, coaching availability
- Amenities: locker rooms, shower facilities, lane width/availability
