Router admin interface: 192.168.0.1 or 192.168.1.1, default username and password are both 'admin'. Download firmware from tp-link.com Support section (Routers > Archer AX50 > Firmware). Upload .bin file through router's Management/Advanced Settings > Firmware Update page. Do not interrupt or turn off during update. Router auto-reboots when complete. Verify by checking firmware version after reboot.
