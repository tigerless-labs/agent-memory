## Popular dog bed options for Max

1. **Big Barker Orthopedic Dog Bed**: Durable, extra joint support, machine washable, various sizes
2. **K&H Thermal-Nesting Orthopedic Bed**: Plush, thermal layer for warmth, easy to clean, non-slip bottom
3. **Pawfect Pets Orthopedic Memory Foam Bed**: Supportive memory foam, machine washable, soft plush cover
4. **PetFusion Ultimate Dog Lounge**: Stylish, sturdy base, soft plush cushioning, easy to clean, non-slip bottom

Consider: Max's preferences (snuggle vs stretch), age, health needs (orthopedic support for older dogs), machine washability.
