Organizes photos using Lightroom's collection system:\n\n**For categorization:**\n- Creates collections by trip/location (e.g., 'Beach Vacation 2023', 'Wildlife Outing 2023')\n- Within each trip, creates sub-collections by photo type: Landscapes, Wildlife, Flora, Macro/Close-ups\n- Uses drag-and-drop to add photos to collections and manually curates content\n\n**For automated filtering:**\n- Uses Smart Collections with criteria like date range and location\n- Example: Smart Collection for 'Beach Vacation 2023' includes all photos from specific dates and location\n\n**For editing workflow:**\n- Uses Develop module for adjustments: Exposure, Contrast, Highlights, Shadows, White Balance\n- Focuses on vibrant edits with shadow recovery to enhance details\n- Uses Before/After views to compare edits\n\n**Best practices:**\n- Tags photos with keywords and metadata during import\n- Uses 1-5 star rating system to identify favorites\n- Applies sync feature to apply edits across multiple photos\n- Uses Grid and Loupe views for efficient navigation
