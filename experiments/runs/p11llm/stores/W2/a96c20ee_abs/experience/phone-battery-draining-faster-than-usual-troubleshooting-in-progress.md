**Issue:** Battery draining faster than normal, especially when using social media apps and watching videos.

**Attempted solutions:**
- Closed some background apps
- Adjusted screen brightness
- Results: minimal improvement

**Recommended troubleshooting steps to try before factory reset:**
1. Limit social media apps (disable background refresh, location services), use lite/data saver versions
2. Reduce video quality/resolution or download for offline viewing
3. Enable Auto-Brightness
4. Disable Bluetooth, GPS, Wi-Fi when not in use
5. Disable 4G/LTE in poor coverage areas
6. Limit push notifications
7. Try battery calibration (drain to 0%, charge to 100%, repeat)
8. Check for software updates
9. Check battery health using device tools
10. Identify resource-intensive apps using battery tracker
11. Use Power Saving/Low Power Mode

**Note:** Recommended trying troubleshooting steps before attempting factory reset to avoid data loss and to identify root cause.
