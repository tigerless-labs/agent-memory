Framework for setting campaign goals with the following components:

**Specific:** Clearly define what you want to achieve with metrics (e.g., increase brand awareness by 20%, achieve $100k revenue)

**Measurable:** Establish trackable metrics like social media followers (+10%), website traffic (+15%), leads generated (500+), sales targets

**Achievable:** Based on resources - budget, team size, past performance data

**Relevant:** Goals should directly impact business outcomes (revenue, market share)

**Time-bound:** Set clear timelines with milestones
- Typical campaign: 6 weeks total with phases like planning/content creation (weeks 1-2), launch/promotion (weeks 3-4), optimization/evaluation (weeks 5-6)

Key Performance Indicators to track: website traffic, social engagement, lead generation, sales revenue, average order value
