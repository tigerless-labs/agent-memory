**Mathematics & Statistics Resources:**\n- Khan Academy (khanacademy.org) — algebra to advanced calculus, statistics, linear algebra\n- MIT OpenCourseWare (ocw.mit.edu) — free courses in calculus, differential equations, linear algebra\n- Coursera (coursera.org) — math courses from Stanford, Duke\n- edX (edx.org) — courses from Harvard, Berkeley including calculus and statistics\n- Stat Trek (stattrek.com) — online statistics tutorials with interactive lessons\n- Statistics in Python (statistics.freeCodeCamp.org) — interactive statistics fundamentals\n\n**Programming & Data Science:**\n- DataCamp (datacamp.com) — interactive courses in Python, R, SQL, and statistics\n- Codecademy (codecademy.com) — interactive coding in Python, R, SQL\n- Kaggle (kaggle.com) — practice with datasets and competitions\n\n**Data Visualization Tools:**\n- Tableau — drag-and-drop tool for interactive dashboards\n- Python libraries: Matplotlib, Seaborn, Plotly\n- R packages: ggplot2, Shiny\n- D3.js — JavaScript library for interactive web visualizations\n- Power BI — Microsoft business analytics tool\n\n**Online Communities:**\n- Reddit: r/learnprogramming, r/statistics, r/datascience — forums for questions and learning from others
