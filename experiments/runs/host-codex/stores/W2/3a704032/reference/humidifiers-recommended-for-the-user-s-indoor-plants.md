Recommendations given on 2023-05-24 were Levoit LV600HH Hybrid Humidifier (cool and warm mist, adjustable humidistat, 6-liter tank), Honeywell HUL520W Mistmate Humidifier (1-liter tank), Deneve Minimal Aroma Humidifier (ultrasonic, 2.5-liter tank), and Crane Drop Ultrasonic Cool Mist Humidifier (1-liter tank). For African violets, the assistant emphasized a small-to-medium cool-mist, low-noise, easy-to-clean unit and 50-60% relative humidity.
