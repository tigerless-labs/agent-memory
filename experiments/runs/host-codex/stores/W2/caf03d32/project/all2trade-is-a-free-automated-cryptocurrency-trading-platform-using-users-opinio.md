All2Trade is a proposed minimal, completely automated cryptocurrency trading system. Users submit opinions through a simple interface about the future trend of a currency. The system condenses the user base knowledge to make trades, pays contributing users a small percentage of the payout, and retains the difference. The platform is intended to be free for users. Stated technologies: Python 3, Flask, and MySQL.
