## Recommended Swimming Workout Types

### 1. Endurance Sets
- 4-6 sets of 200-400 meters at moderate pace (60-70% effort)
- Rest 20-30 seconds between sets
- Focus on consistent pace throughout each set

### 2. Interval Training
- 25-50 meters at high intensity (80-90% effort)
- Rest 15-25 seconds
- 8-12 reps
- Cool down with 25-50 meters easy swimming

### 3. Pyramid Workout
- Start at 25 meters, increase by 25m each set (50m, 75m, 100m, etc.)
- Then decrease back down (100m, 75m, 50m, 25m)
- Moderate pace throughout
- Rest 20-30 seconds between sets

### 4. Sprint Intervals with Kicking
- 25 meters high intensity (80-90% effort) with kickboard
- Rest 15-25 seconds
- 8-12 reps
- Cool down with 25-50 meters easy swimming

### 5. Long, Steady-State Swim
- 10-20 minutes at moderate pace (60-70% effort)
- Focus on consistent pace and efficient technique

## Warm-up and Cool-down
- **Warm-up**: 5-10 minutes easy swimming (freestyle, backstroke, breaststroke) + dynamic stretching
- **Cool-down**: 5-10 minutes easy swimming + static stretching (hamstrings, shoulders)

## Key Principles
- Mix different stroke types to engage different muscle groups
- Gradually increase distance and intensity over time
- Include drills like flip turns, dives, kicking exercises
- Maintain technical efficiency throughout workouts
