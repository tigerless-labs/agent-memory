## Azure Management Tools

Three tools manage Azure resources:

1. **Azure PowerShell** — Module for Windows PowerShell and PowerShell Core; provides Azure-specific commands
2. **Azure CLI** — Cross-platform CLI for Linux, macOS, Windows; command-line program for Azure resource administration
3. **Azure Cloud Shell** — Browser-accessible, interactive shell running on temporary Azure-hosted environment; requires storage account and Azure File share

All three access resources through **Azure Resource Manager (ARM)**, which provides a consistent management layer for deploying, updating, and deleting resources. ARM also enables deployment through Azure Portal, REST API, and client SDKs.
