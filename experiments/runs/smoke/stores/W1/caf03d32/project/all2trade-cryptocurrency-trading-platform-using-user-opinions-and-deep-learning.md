Automated cryptocurrency trading platform that leverages collective user opinion and deep learning predictions. Technology: Python 3, Flask, MySQL with Celery task scheduling. Free for users; platform takes percentage of trading profits and distributes small payouts to opinion providers. Plans include deep learning model that learns and improves over time. Status: Architecture and database design phase as of 2023-05-21.
