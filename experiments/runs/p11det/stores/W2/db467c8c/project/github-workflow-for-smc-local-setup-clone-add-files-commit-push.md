1. Configure Git globally with username and email. 2. Generate SSH key (ed25519) and add to GitHub account for secure authentication. 3. Create new repository on GitHub. 4. Clone repository to local machine using SSH URL. 5. Add project files to cloned repository. 6. Stage files with 'git add .'. 7. Commit with meaningful message. 8. Push to GitHub using 'git push origin main'. Use GitHub Desktop or GitKraken for graphical Git management if preferred.
