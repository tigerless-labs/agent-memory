6S (SIAC_GEE): Radiative transfer model on Google Earth Engine. Input: Level-1C. Batch processing, custom outputs.

MAJA: Physical atmospheric model from CNES. Standalone software. For Sentinel-2.

Sen2Cor: ESA tool combining physical models, look-up tables, and ML. Input: Level-1A. Output: Level-2A. Processes one image at a time.

Sentinel-2: 10m resolution (visible/NIR), 20m (SWIR). 5-day revisit. Level 2 globally available (free via Copernicus Hub), affected by cloud cover.
