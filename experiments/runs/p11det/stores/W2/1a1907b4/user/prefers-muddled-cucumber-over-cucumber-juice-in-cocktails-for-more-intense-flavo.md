When making cocktails with cucumber flavor, user prefers muddling cucumber slices over using cucumber juice.

**Reasoning:**
- Muddling releases more intense, fresh, herbaceous flavors
- Adds pleasant refreshing texture to the drink
- Provides visual appeal with green garnish
- More pronounced cucumber flavor compared to the milder, sweeter flavor of juice

Cucumber juice is used when a subtle, smooth cucumber flavor is desired instead.
