**VAT Rate**: 12% in the Philippines

**Calculation**: Total cost × 0.12

**Example**: PHP 1,000 × 0.12 = PHP 120 VAT
Total with VAT: PHP 1,000 + PHP 120 = PHP 1,120

**VAT Registration Requirements**:
- Businesses with annual sales/gross receipts **above PHP 3 million** must register for VAT
- VAT-registered businesses must:
  - Charge VAT on sales
  - Include VAT in invoices
  - File VAT returns with the Bureau of Internal Revenue (BIR)

- Businesses with annual sales **below PHP 3 million** are not required to charge or include VAT

**Note**: Only VAT-registered businesses are legally required to include VAT on invoices.
