Popular portable external hard drive options discussed:

1. **Western Digital My Passport**
   - Compact, durable
   - Up to 5TB capacity
   - Multiple color options
   - Built-in password protection

2. **Seagate Backup Plus**
   - Slim and lightweight design
   - Up to 5TB capacity
   - Compatible with Windows and Mac
   - Built-in USB hub for charging devices

3. **LaCie Rugged**
   - Rugged and waterproof design
   - Heavy-duty use
   - Up to 5TB capacity
   - Can withstand rough handling

4. **Samsung Portable SSD**
   - Faster, more compact option
   - Up to 2TB capacity
   - Great for backing up on the go

5. **G-Technology G-Drive Mobile**
   - High-performance
   - Durable design
   - Up to 4TB capacity
   - Thunderbolt 3 port for fast data transfer
   - Compatible with Windows and Mac

Selection factors to consider:
- Storage capacity needed
- Speed (portable SSD vs hard drive)
- Durability and portability
- Compatibility with operating system
- Security features (password protection, encryption)
- Price and reviews
