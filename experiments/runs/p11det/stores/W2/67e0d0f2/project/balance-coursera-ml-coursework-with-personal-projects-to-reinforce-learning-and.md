Decided to work on personal machine learning projects alongside Andrew Ng's course to:

- Apply concepts to real-world problems
- Build deeper understanding and retain material better
- Maintain motivation through contextual learning
- Develop a portfolio of ML work

**Strategy:**
- Dedicate specific time blocks for both coursework and personal projects
- Start with small, manageable projects aligned with course topics
- Choose projects matching personal interests (e.g., image classification, text analysis, recommendation systems, time series forecasting)
- Prioritize completing coursework and meeting deadlines
- Gradually scale up project complexity as skills develop

**Example project ideas:**
- Image classification (sports teams, animals)
- Text analysis (sentiment, themes, author style)
- Recommendation systems (movies, music, products)
- Time series forecasting (stock prices, weather, sports performance)
