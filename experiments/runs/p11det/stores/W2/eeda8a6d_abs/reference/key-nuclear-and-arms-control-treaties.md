Key treaties: NPT (non-proliferation), START (strategic arms reduction), ABM Treaty, CTBT (comprehensive test ban), INF Treaty (intermediate-range), CWC (chemical weapons), BWC (biological weapons), TPNW (prohibition), New START, Treaty on Open Skies. These aim to prevent nuclear proliferation, reduce arsenals, limit weapons types, and promote transparency.
