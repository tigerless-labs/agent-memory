User actively learns Adobe Premiere Pro's Lumetri Color Panel for color grading. Interested in creating cinematic looks using:

- Curves panel techniques (S-curves, Toe/Shoulder controls, black level adjustments)
- Color Wheels for targeted color adjustments in shadows, midtones, highlights
- Color Match feature to match clips across different cameras/lighting
- Creative panel for establishing base looks before refinement
- Combining Creative and Curves panels for cohesive color grades

Prefers Lumetri Color Panel over Legacy Color Grading tools. Values best practices including:
- Starting with neutral grades
- Working dark-to-light (shadows → midtones → highlights)
- Making subtle adjustments
- Maintaining consistency across footage
- Regular reference checking
- Color scripting before grading

Focuses on practical, creative color grading rather than technical precision.
