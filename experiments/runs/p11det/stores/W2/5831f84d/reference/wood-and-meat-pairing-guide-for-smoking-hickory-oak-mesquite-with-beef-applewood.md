**Wood Types and Pairings:**\n- Hickory (strong, sweet, smoky): ribs, brisket, bacon, sausages\n- Oak (earthy, mellow): pulled pork, chicken, turkey, vegetables\n- Mesquite (strong, earthy, bitter): beef steaks/burgers, lamb, game meats\n- Applewood (fruity, sweet, mild): poultry, pork tenderloins, baby back ribs, sausages\n- Cherrywood (fruity, sweet, mild): poultry, pork tenderloins, game meats\n\n**Tips:**\n- Start with mild wood if new to smoking (applewood/cherrywood)\n- Experiment with wood blends for complex flavors\n- Soak wood chips/chunks for 30+ minutes before use\n- Monitor smoker temperature for ideal range\n- Practice and experiment to find personal preferences
