Steps to activate Thrive feature on Higher Logic platform:

1. Log in to Higher Logic account → Admin interface
2. Click Features tab
3. Search for 'Thrive' and click Activate
4. Follow prompts: agree to terms, set up billing, configure Thrive settings
5. Once active, set up community: create groups, add members, configure settings

**Important:** Thrive may not be available to all Higher Logic customers—restricted by pricing tier or requires additional fees. Contact Higher Logic support to confirm eligibility.
