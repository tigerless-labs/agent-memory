**Linear Algebra Learning Plan**

Sequence:
1. Start with Khan Academy Linear Algebra Course (free, foundational)
2. Progress to Coursera Linear Algebra Specialization (4-course specialization by University of Pennsylvania)

Context: Supplementary to Coursera data science/machine learning course  
Goal: Build mathematical foundation for data science and machine learning  

Also available as backup resources:
- MIT OpenCourseWare: Linear Algebra
- 3Blue1Brown's Linear Algebra animated video series
- Gilbert Strang's free online textbook and YouTube lectures
