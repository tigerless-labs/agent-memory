## Character Development Resources Recommended

**Online Resources:**
- Writers Digest: Character Development (writersdigest.com)
- The Creative Penn: Character Development (thecreativepenn.com)
- Helping Writers Become Authors (helpingwritersbecomeauthors.com)
- The Write Practice: Character Development Exercises (thewritepractice.com)
- Novel Writing Help: Character Development Exercises (novelwritinghelp.com)
- 16 Personalities: Free personality test for character insights

**Recommended Books:**
- "Characters & Viewpoint" by Orson Scott Card
- "The Writer's Journey: Mythic Structure for Writers" by Christopher Vogler
- "How to Write Short Stories and Use Them to Further Your Writing Career" by James Scott Bell

**Brainstorming Techniques:**
- Mind Mapping: Visualize character motivations, goals, and conflicts
- What If?: Ask hypothetical questions about character situations
- Character Interviews: Imagine interviewing the character
- Scene Writing: Write scenes that showcase character motivations and conflicts
- Character Journaling: Write journal entries from character's perspective

**Tips for Maximizing Writing Time:**
- Warm-up exercises (10-15 min character work before main writing)
- Set specific goals for each session
- Use Pomodoro Technique (25 min focused work + 5 min break)
- Review and reflect on progress (last 10-15 min)
