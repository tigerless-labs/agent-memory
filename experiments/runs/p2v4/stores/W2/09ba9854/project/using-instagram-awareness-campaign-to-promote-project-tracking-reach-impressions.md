Decided to launch Instagram ad campaign with Awareness objective to increase project visibility. Will monitor these metrics to gauge effectiveness:

- **Reach** — total people exposed to ads
- **Impressions** — number of ad displays
- **Frequency** — average views per person (watch for ad fatigue)
- **Engagement** — likes, comments, saves, shares
- **CPM** — cost per thousand impressions
- **Ad Recall Lift** — how well people remember the ad and brand

Uses Facebook Ads Manager to set up and track campaigns. Set up Instagram Business Account first to access Ads Manager.

Setup steps: convert to business account → create Ads Manager account → set up payment → choose ad objective → define audience → create ad creative → set budget/schedule → launch & monitor.
