Music programming languages for composition and audio synthesis: Max/MSP (visual, electronic music), Pure Data (free/open-source alternative), SuperCollider (real-time synthesis, algorithmic), Csound (30+ years, complex structures), ChucK (simple syntax), Swift (Apple platforms), Python (general purpose, beginner-friendly), Sonic Pi (beginner-focused live coding)
