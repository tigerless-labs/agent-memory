Escalation Engineer II at Amazon Web Services resolves highly complex customer issues at the highest level of AWS support. Main responsibilities: troubleshooting complex technical problems through analysis and collaboration with other AWS teams; providing technical guidance on optimizing AWS services; creating technical content like whitepapers and best practices; collaborating with product, operations and security teams. Requires strong technical skills, excellent communication and problem-solving, customer-focused mindset.
