Resources for learning Sonic Pi: explore the interface and live-coding workflow; use built-in tutorials (Help > Tutorial); experiment with sample code (Help > Examples); join active community on Twitter, forums, Discord; find local workshops/classes; watch video tutorials including Sonic Pi Live Stream on Twitch. Sonic Pi is free/open-source with real-time feedback and large sample library.
