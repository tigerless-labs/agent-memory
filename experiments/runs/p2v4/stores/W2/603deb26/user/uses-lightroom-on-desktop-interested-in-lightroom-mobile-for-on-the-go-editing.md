Using Lightroom on desktop for primary photo editing. Recently learned about Lightroom Mobile, a mobile version with condensed but useful features like exposure, contrast, selective adjustments, and presets. Mobile version lacks some desktop features like Tone Curve and Split Toning but offers portable editing capability. Also interested in other mobile editing apps including VSCO, Snapseed, and Adobe Photoshop Express for quick adjustments before sharing on social media.
