When creating image prompts, user prefers rich, descriptive language that includes specific camera equipment (model, lens, aperture settings), ISO, shutter speed, lighting conditions, composition details, and Midjourney parameters (aspect ratio, quality, version). Wants assistant to act as professional photographer/illustrator/animator when creating prompts. Example structure: detailed subject description → camera setup (specific model and lens) → camera settings (aperture, ISO, shutter speed) → lighting and atmosphere → composition → Midjourney parameters (e.g., --ar 16:9 --q 2 --v 5).
