A cryptocurrency trading platform that aggregates user opinions to make automated trading decisions.

**Purpose**: Generate revenue by using condensed knowledge from the user base to make profitable trades.

**Business Model**:
- Platform is free for users
- Revenue generated from trades made using user opinions  
- Users receive a small percentage of profits from successful trades
- Platform takes the difference

**User Base**: Open to anyone who wants to help improve trading decisions and receive profit sharing.

**Core Features**:
- Minimal, fully automated system
- Simple interface for users to input opinions on currency trends
- Users select the currency they want to predict trends for
- System makes trades based on aggregated user opinions

**Technology Stack**:
- Python 3
- Flask (web framework)
- MySQL (database)
- CCXT (crypto exchange integration)
- Pandas (data manipulation)
- Celery (task scheduling)
