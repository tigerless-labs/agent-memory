Adobe Lightroom Smart Collection setup:\n1. Access Collections panel > Click '+' icon > Select 'Smart Collection'\n2. Define rules using 'Capture Date' (Is in range) for date filtering\n3. Add location rule using 'Contains' operator\n4. Lightroom automatically includes matching photos\n\nUseful for organizing large photo sets by trip date and GPS location data. Can combine multiple rules to refine criteria (e.g., time of day, keywords).
