**Flight booking:** Skyscanner, Google Flights, Kayak, Momondo, Airfarewatchdog

**Accommodations:** Booking.com, Airbnb, HotelsCombined, Trivago, Hostelworld

**Package deals:** Expedia, Orbitz, Priceline

**Travel inspiration/planning:** TripAdvisor, Lonely Planet, Travel + Leisure

**Key booking tips:**
- Optimal booking window: 54 days before departure (Skyscanner study)
- Prime booking window: 21-121 days before (CheapAir study)
- Avoid booking on Tuesdays, Wednesdays, Saturdays (peak booking days)
- Consider off-peak seasons for cheaper flights
- Set up fare alerts for deals
- Use price comparison tools to track trends
