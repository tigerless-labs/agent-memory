# Training Course Survey System Requirements

## Core Functionality
- Trainees complete survey at course start and end
- Trainees view their own progress (before/after comparison)
- Trainees view class-wide results at end of course
- Instructors collect and review all survey responses
- Instructors view individual trainee results for feedback
- Instructors view aggregate class results to evaluate program effectiveness

## User Stories (8 total)
1. Trainee: take beginning-of-course survey for initial feedback
2. Trainee: take end-of-course survey for final feedback
3. Trainee: track personal progress over course
4. Trainee: compare initial vs final results to see change
5. Trainee: view class results to benchmark against peers
6. Instructor: collect surveys to track trainee progress
7. Instructor: view individual results for personalized feedback
8. Instructor: view class results for program evaluation
