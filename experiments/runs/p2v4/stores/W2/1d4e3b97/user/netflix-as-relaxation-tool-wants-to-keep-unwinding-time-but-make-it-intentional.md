Uses Netflix to unwind after work—considers it essential for relaxation. Goal is not to eliminate it but to make viewing more intentional and bounded rather than mindless scrolling.

Preferred approach: set specific 30-60 minute relaxation window for Netflix or alternative screen-free activity (reading, music, yoga, etc.), rather than cutting it out entirely.
