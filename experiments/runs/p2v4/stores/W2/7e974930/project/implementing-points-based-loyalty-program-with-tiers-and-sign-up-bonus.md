Decided to set up a loyalty program for repeat customers with the following structure:

- Points-based system where customers earn points per purchase
- Multiple tier levels with increasingly exclusive rewards
- Sign-up bonus to encourage enrollment
- Promotion channels: social media, email newsletters, in-store signage, staff mentions at checkout

Goals: increase repeat business, build customer retention, encourage word-of-mouth marketing.
