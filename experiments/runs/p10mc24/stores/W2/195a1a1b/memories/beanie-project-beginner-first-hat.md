## Next Knitting Project

**Project:** Beanie (fitted hat, not slouchy)

**Why beanie over slouchy hat:** Beginner knitter chose beanie because:
- Easier to shape for beginners
- Requires fewer stitches than slouchy hats
- More forgiving of small mistakes
- Requires basic skills: knit, purl, increases, decreases
- Quicker, more manageable project

**Yarn:** Purple worsted weight yarn with subtle texture
- Same yarn used for completed purple scarf (May 21, 2023)
- User loves the yarn's characteristics and how it worked
- Has leftover yarn from scarf project (sufficient for beanie)
- Beautiful purple color, subtle texture adds visual interest

**Pattern notes:** User will choose a simple, beginner-friendly pattern with straightforward design and minimal shaping

**Fitting:** User will measure head circumference (widest part above eyebrows and ears) to ensure correct size selection; most patterns provide size ranges to choose from
