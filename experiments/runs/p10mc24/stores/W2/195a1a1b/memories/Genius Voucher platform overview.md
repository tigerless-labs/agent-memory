## What It Is
Genius Voucher is a platform for NGOs to manage and control voucher-based humanitarian distribution projects in real-time.

## Components (All-in-One Solution)

### Hardware
- **POS machines** — issued to authorized vendors for processing transactions
- **Smart cards** — issued to beneficiaries to receive items or cash

### Software
- **Portal** — NGO project team uses this to create, monitor, and manage distribution projects in real-time

## Core Features
- Eliminates manual data entry — automatic tracking when items or cash issued
- Real-time monitoring of all distribution activities
- Generates periodic reports for accountability
- Beneficiary receipt generation at point of redemption
- Real-time user balance tracking for easier top-up planning
