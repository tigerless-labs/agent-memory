## Andrew Ng Machine Learning Course — Coursera

**Course Details:**
- **Duration:** 11 weeks (approximately 3-4 months)
- **Effort:** 2-3 hours/week
- **Level:** Beginner-friendly (programming experience recommended)
- **Platform:** Coursera
- **Instructor:** Andrew Ng

**Week-by-Week Topics:**
1. Introduction to ML (types, supervised/unsupervised learning)
2. Linear Regression (simple, cost function, gradient descent)
3. Linear Regression II (overfitting, regularization)
4. Logistic Regression (cost function, regularization)
5. Regularization (L1/L2, dropout, early stopping)
6. Neural Networks (intro, multiclass, backpropagation)
7. Neural Networks II (practice, gradient descent, backprop)
8. Support Vector Machines (hard/soft margin, kernels)
9. Clustering/Unsupervised Learning (K-means, hierarchical, PCA)
10. Dimensionality Reduction (PCA, t-SNE, autoencoders)
11. Large Scale ML (handling datasets, distributed computing, MapReduce)

**Assignments:** 11 total (programming exercises + quizzes)
- Linear Regression (housing price prediction)
- Neural Networks (MNIST handwritten digit classification)
- Support Vector Machines (spam email classification)

**Optional Certificate:** Available upon completion

**Prerequisites:**
- Programming experience (Python, R, or MATLAB recommended)
- Basic linear algebra and calculus
