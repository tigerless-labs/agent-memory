## HTML DOM vs Browser BOM

**HTML DOM (Document Object Model)**
- Programming interface for manipulating web page content and structure
- Represents web page as hierarchical tree of objects (elements, attributes, text nodes)
- Allows dynamic modification of page contents, user interaction responses, dynamic effects/animations
- Example: dynamically add/remove elements based on user input

**Browser BOM (Browser Object Model)**
- Programming interface for manipulating browser behavior and appearance
- Provides access to browser-specific features: history, location, navigation properties
- Enables creating pop-up windows, displaying dialogs, manipulating status bar
- Example: navigate to different URL or display pop-up when user clicks button

**Key Difference**
- DOM focuses on page content/structure manipulation
- BOM focuses on browser window/features manipulation
- Together they provide tools for creating interactive, dynamic web applications
