## DHTML Events

DHTML (Dynamic HTML) events are JavaScript events triggered by user actions or browser events that enable real-time modification of web page content, behavior, and appearance.

**Commonly Used DHTML Events:**

1. **onmouseover** — triggered when mouse cursor moves over an HTML element
2. **onmouseout** — triggered when mouse cursor moves out of an HTML element
3. **onclick** — triggered when an HTML element is clicked
4. **ondblclick** — triggered when an HTML element is double-clicked
5. **onkeydown** — triggered when a keyboard key is pressed down
6. **onkeyup** — triggered when a keyboard key is released
7. **onload** — triggered when a web page finishes loading
8. **onsubmit** — triggered when an HTML form is submitted
9. **onreset** — triggered when an HTML form is reset
10. **onresize** — triggered when the size of the browser window is changed
11. **onscroll** — triggered when the user scrolls the web page
12. **onerror** — triggered when an error occurs during loading of resources (images, scripts, etc.)

**Usage**
- Attach to HTML elements using attributes (e.g., `<button onclick="alert('Hello')">`)
- Enable responsive, interactive web experiences
- Widely used in modern web applications and user interfaces
