## Why Lightroom
- User chose Adobe Lightroom because already comfortable with Adobe ecosystem

## Import Process
1. Connect camera or memory card
2. File > Import Photos and Video (Ctrl+Shift+I Windows, Command+Shift+I Mac)
3. Configure import settings:
   - Build Previews: Select "Minimal" for faster import
   - Render Previews: Choose "Standard" or "1:1"
   - Destination: Choose location for imported photos
4. Add metadata and keywords during import
5. Click "Import" to begin

## Organization Strategy
- Create hierarchical folder structure by trip or year
- Create collections for different photo types
- Use collections to group related photos together
- Create Smart Collections to automatically organize based on criteria

## Collections Setup
1. Library module > Collections panel
2. Click "+" icon > select "Collection"
3. Name collection (e.g., "Landscapes", "Wildlife", "Flora")
4. Drag and drop photos to collections
5. Alternative: Right-click photo > "Add to Collection"

## Smart Collections
1. Click "+" icon in Collections panel > select "Smart Collection"
2. Define rules:
   - Capture Date: "Is in range" - specify start and end dates
   - Location: "Contains" - specify location name
3. Can add multiple rules to refine criteria
4. Automatically updates when new matching photos are added
5. Can also use keywords, tags, time of day as rules

## Develop Module Editing
- Access: Develop tab or Ctrl+Shift+D (Windows), Command+Shift+D (Mac)
- Key panels:
  - **Basic Panel**: Most common adjustments
    - White Balance: Auto or custom
    - Exposure: Brighten/darken image
    - Contrast: Add depth
    - Highlights: Recover bright details
    - Shadows: Recover dark details
  - **Tone Curve Panel**: Advanced tone and contrast adjustments
  - **Details Panel**: Sharpening and noise reduction
  - **Lens Corrections Panel**: Correct lens distortions

## Editing Best Practices
- Use Before/After views to compare original vs edited
- Make subtle adjustments - avoid overdoing it
- Use histogram to optimize exposure and contrast
- Use Gradient Filter or Adjustment Brush for local adjustments
- Sync button: Apply same adjustments to multiple photos
- Reset button: Revert to original if needed

## Tagging and Metadata
- Use consistent naming conventions
- Add keywords during import
- Use 1-5 star rating system for favorites
- Use flags to mark photos for editing
- Add camera settings metadata (aperture, shutter speed, ISO)
- Include date, time, GPS coordinates if available
