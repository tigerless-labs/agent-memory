## Basic Tools for Soapstone Carving

### Carving Tools
- **Gouges**: Remove small amounts of soapstone and create details
- **Chisels**: Remove larger amounts and create deeper grooves
- **Files**: Smooth and refine soapstone surface
- **Rasps**: Shape and smooth soapstone, especially curved or rounded shapes

### Safety Equipment
- **Dust mask**: Prevents inhaling soapstone dust
- **Safety glasses**: Protect eyes from flying debris
- **Gloves**: Prevent cuts and abrasions

## Carving Techniques

### Primary Techniques
1. **Rough shaping**: Use gouges and chisels to remove excess and create overall bird shape
2. **Refining**: Use files and rasps to smooth surface and remove rough spots
3. **Detailing**: Use small gouges and chisels for intricate details like feathers, eyes, beaks
4. **Texturing**: Create textures using specialized tools or techniques

### Methods for Intricate Details and Textures
- **Stippling**: Create detailed patterns using small dots or points (feathers, scales)
- **Hatching**: Create lines or patterns using small parallel strokes (feathers, fur)
- **Carving in relief**: Carve design into soapstone creating raised or recessed effect
- **Inlaying**: Insert small pieces of soapstone or other materials into carved design (eyes, beaks)

## Best Practices for Bird Carvings
- Work in small sections to maintain focus and avoid mistakes
- Use reference images of birds for accuracy and detail
- Experiment with tools and techniques to achieve desired effects
- Practice patience - mastery requires time and practice
