User wants to improve preparation for book club discussions by developing better summarization and note-taking skills.

**Summarizing approach:**
- Identify main plot points and key events
- Determine author's purpose and themes
- Identify key characters and their motivations
- Note setting and atmosphere
- Focus on climax and resolution

**Note-taking while reading:**
- Use dedicated notebook or app for consistency
- Create a system using colors, symbols, or headings for characters/themes/plot
- Write down quotes with page numbers for reference
- Ask questions and make connections to own life or other books
- Summarize each chapter/section
- Use sticky notes or tabs for important pages
- Create character maps showing relationships and conflicts
- Research author background and historical context

**Additional strategy:** Discuss with others to gain different perspectives and insights.
