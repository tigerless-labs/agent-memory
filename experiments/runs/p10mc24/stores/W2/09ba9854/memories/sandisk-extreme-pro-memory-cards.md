## SanDisk Extreme Pro Memory Cards

**Currently in use:**
- SanDisk Extreme Pro 64GB cards

**New acquisition:**
- Two SanDisk Extreme Pro 128GB cards (arrived February 12, 2023)
- Provide more storage space for high-resolution image capture

**Organization practices:**
- Label each card with capacity, type, and unique identifier (e.g., "128GB-1")
- Store in protective cases or memory card wallet to prevent loss and damage
- Format cards regularly before use to prevent data corruption
- Develop file naming system (by date, camera, or project)
- Rotate cards regularly to ensure even wear
- Backup files from each card to computer or external hard drive after shoots
