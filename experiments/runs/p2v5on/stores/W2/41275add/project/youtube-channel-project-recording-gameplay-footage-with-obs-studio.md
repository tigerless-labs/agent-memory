Planning to start YouTube channel recording gameplay footage.

**Tool chosen:** OBS Studio (free, open-source)
- Reasons: Free, large community, extensive plugin ecosystem, highly customizable
- Alternatives considered: XSplit (paid), ShadowPlay, Fraps, Bandicam, Camtasia
- Hardware well-suited: OBS optimized for RTX 3080 + Ryzen 9 5900X

**Goals:**
- Create unique visual look/branding for channel
- Leverage customization features of OBS
- Build custom overlays and scenes

**Notes:**
- Considering investing in quality microphone and webcam
- Will explore plugins: Streamlabs OBS, OBS.Live, Move Transition
