Keeps an ideas journal for capturing content ideas throughout the day. Repurposes existing content across formats. Tailors content to each platform (Instagram: short 10-30min visual-focused; YouTube: longer 30-60min in-depth; Facebook: 30-90min community-focused). Prioritizes real-time audience interaction via comments, questions, polls. Experiments with different formats: Q&A sessions, tutorials, behind-the-scenes, skincare routines. Monitors analytics to track performance and adjusts strategy based on audience feedback.
