- Issue: Desktop graphics card causing gaming performance issues
- Initial research: NVIDIA GeForce RTX 3070, approximately 500 dollars (too expensive)
- Budget constraint: Need more affordable options

**Recommended affordable alternatives:**
- NVIDIA GeForce GTX 1660 Super (200-250 dollars): mid-range, good for 1080p/1440p
- AMD Radeon RX 5600 XT (200-220 dollars): strong competitor to GTX 1660 Super
- NVIDIA GeForce GTX 1650 Super (150-180 dollars): entry-level option
- AMD Radeon RX 5500 XT (150-180 dollars): entry-level option

**Considerations:**
- Monitor resolution (1080p vs 1440p+) affects card choice
- Power supply must handle new card requirements
- System CPU and motherboard compatibility needed
