## Google Calendar Features for Scheduling

### Find a time
- Checks attendees' calendars and suggests available time slots
- Requires attendee calendar sharing
- Useful for coordinating across time zones

### Propose a new time
- Send alternative time suggestions when initial recommendations don't work
- Attendee responds with availability
- Can be used repeatedly until finding suitable slot

### Reminders
- Set via dropdown menu (15m, 30m, 1h, 2h, or custom)
- Notification types: email, popup, or Android device notification
- Helpful for not missing scheduled sessions

### Video Conferencing Integration
- **Google Hangouts Meet**: One-click meeting creation via 'Add conferencing' dropdown
- **Zoom**: Install Zoom add-on from G Suite Marketplace; streamlines meeting scheduling with automatic invitations
- **Other tools**: Can add custom conferencing links (Discord, Skype, etc.)

### Time Zone Handling
- Add secondary time zone display to events
- Shows both your local time and partner's time in event details
- Add notes with partner's timezone for clarity
