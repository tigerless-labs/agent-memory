Starting a beanie knitting project (beginner pattern). Using the same purple worsted weight yarn with subtle texture from completed scarf. Reasons for choosing beanie: easier for beginners than slouchy hat, fewer stitches, more forgiving. Measured head circumference above eyebrows and ears to determine correct size. Tips to remember: swatch for gauge, maintain even tension, follow simple pattern.
