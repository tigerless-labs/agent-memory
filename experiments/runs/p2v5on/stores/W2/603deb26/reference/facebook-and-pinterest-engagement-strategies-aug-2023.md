**Facebook engagement boost strategies:**
- High-quality visuals (images/videos)
- Concise, scannable posts with questions
- Post when audience is active (check Facebook Insights)
- Respond to comments promptly
- Use Facebook Live (higher engagement than regular video)
- Create Facebook Stories
- Run Facebook Polls
- Host Q&A sessions
- Create Facebook Groups for community
- Cross-promote on other channels
- Monitor analytics and adjust strategy
- Consistent posting schedule with authentic brand voice

**Pinterest growth strategies:**
- Complete profile with keywords
- Create relevant, well-named boards
- Use vertical images (platform-optimized)
- Enable Rich Pins (prices, reviews, cooking times)
- Pin regularly on a consistent schedule
- Engage: like/comment on others' pins, respond to comments
- Create Pinterest Stories
- Use Carousels for storytelling
- Add Pinterest button to website/blog
- Cross-promote on other channels
- Use Pinterest Analytics to track performance
- Experiment with different content types and timing
