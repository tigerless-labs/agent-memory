Beginner-friendly: Sonic Pi (free, live coding, real-time feedback), ChucK (free, music-specific, simple syntax), Python (general-purpose, large community). Professional: Max/MSP (visual, electronic music production), Pure Data (free alternative to Max), SuperCollider (synthesis + algorithmic composition), Csound (30+ year old synthesis system), Swift (iOS/macOS music apps).
