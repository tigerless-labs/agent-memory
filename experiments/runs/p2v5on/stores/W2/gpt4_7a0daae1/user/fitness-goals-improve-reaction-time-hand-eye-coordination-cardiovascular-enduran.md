Main fitness objectives:
1. Reaction time and hand-eye coordination (tennis-focused)
2. Cardiovascular endurance for 30-minute runs
3. Overall performance improvement in tennis and running
4. Core and leg strength for better athletic performance

Plans to use drills and exercises like wall ball bounces, catch-and-throw, tennis-specific racket work, HIIT training, hill sprints, and tempo runs.
