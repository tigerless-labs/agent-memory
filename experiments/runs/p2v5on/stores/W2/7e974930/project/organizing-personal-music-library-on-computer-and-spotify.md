Goal is to organize both local computer music files and Spotify library. Plans include: using consistent naming conventions (e.g., 'Artist - Album - Track Number - Track Title'), creating folder/subfolder structure organized by genre/decade/mood/artist, adding metadata tags (genre, album art, lyrics), removing duplicate tracks, and creating mood/activity-based playlists for efficient browsing and music discovery.
