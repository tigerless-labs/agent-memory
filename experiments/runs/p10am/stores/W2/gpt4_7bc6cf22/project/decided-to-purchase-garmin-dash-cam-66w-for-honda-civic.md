After researching dash cam options and comparing capacitor-based vs battery-based models, decided on Garmin Dash Cam 66W for the Honda Civic. Key decision factor: wanted parking mode functionality for security while parked.

Plans: Purchase the Garmin Dash Cam 66W and hardwire it to the car's electrical system using the optional hardwire kit (sold separately) for extended parking mode capability and reduced battery drain.

Key Features of Garmin Dash Cam 66W:
- 1440p (QHD) video at 30fps
- Built-in GPS with GLONASS
- 140-degree wide-angle lens
- 2-inch LCD screen
- Impact detection with automatic footage saving
- Parking mode with up to 24-hour internal battery
- Lane departure warning
- Forward collision warning
- Wi-Fi connectivity
- Voice command support

Next steps: Obtain optional hardwire kit and arrange professional installation for the hardwiring to ensure proper connection to car's electrical system.
