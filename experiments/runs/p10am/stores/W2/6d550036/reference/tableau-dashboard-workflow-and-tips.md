Connecting to Data: Open Tableau Desktop, click Connect to Data, select source type, enter credentials. Creating Dashboard: Drag fields to Columns/Rows, use Show Me for chart type, customize with filters. Publishing: Server menu > Publish to Web or Server, enter details, deploy. Sharing: Find dashboard, click Share, enter recipients, set permissions (Viewer/Editor/Owner). Alternative: Tableau Public for free public sharing.
