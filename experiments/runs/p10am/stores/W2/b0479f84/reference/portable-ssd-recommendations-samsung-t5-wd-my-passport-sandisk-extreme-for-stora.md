Compact and reliable portable SSDs for laptop storage expansion:

**Compact Options:**
- **Samsung T5 Portable SSD** — Up to 2TB, 51g, sleek design
- **WD My Passport SSD** — Up to 2TB, lightweight and portable
- **SanDisk Extreme Portable SSD** — Up to 1TB, rugged and durable

**High-Capacity Options:**
- **Seagate Backup Plus Portable SSD** — Up to 5TB, designed for large files and backups
- **G-Technology G-Drive Mobile SSD** — Up to 4TB, built for creative professionals
- **LaCie Rugged SSD** — Up to 2TB, extreme durability with water/dust resistance

**Reliable Brands:**
- **Samsung** — High-performance, widely available
- **WD (Western Digital)** — Trusted brand, features like password protection
- **SanDisk** — Rugged design, fast transfer speeds
- **Seagate** — Large capacity options
- **LaCie** — Built for durability and security

**Key Considerations:** Capacity (based on file sizes), speed (USB 3.2 Gen 2 or Thunderbolt 3), durability/ruggedness, security (password/encryption), compatibility with OS and USB ports
