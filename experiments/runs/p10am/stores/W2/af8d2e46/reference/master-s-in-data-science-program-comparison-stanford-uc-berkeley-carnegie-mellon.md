Graduate program competitiveness and focus areas (May 2023):\n\n**Stanford University MS-DS**\n- Acceptance rate: ~5-7% (most competitive)\n- Emphasis: Machine learning, AI, data-driven research, data visualization\n- Strengths: World-renowned faculty, strong industry network, interdisciplinary approach\n- Skills valued: Python/R/Julia, Tableau/D3.js, computer science background\n\n**UC Berkeley MS-DS**\n- Acceptance rate: ~10-15%\n- Emphasis: Practical applications, statistical computing, collaborative research\n- Strengths: Collaborative program (Statistics, CS, Electrical Engineering), social impact focus\n- Skills valued: Statistical modeling, data visualization, machine learning algorithms\n\n**Carnegie Mellon University MS-DS**\n- Acceptance rate: ~10-15%\n- Emphasis: Machine learning, AI, data-driven research\n- Strengths: World-renowned faculty, strong industry network, interdisciplinary\n- Skills valued: Python/R/Julia, Tableau/D3.js, business value applications\n\n**Common application requirements across all three programs:**\n- GRE (competitive scores 320-325+)\n- 3 letters of recommendation\n- Personal statement (2-3 pages)\n- Resume/CV\n- Official transcripts\n- Prerequisite knowledge: Programming, statistics, linear algebra
