Paper: Detecting stochastic gravitational waves with binary resonance

Authors: Diego Blas (Universitat Autònoma de Barcelona, IFAE) and Alexander C. Jenkins (King's College London)

Published: Phys. Rev. D. (closed access) — Daily Paper Summaries summary by Emma Clarke, Feb 8, 2023

Key concept: Proposes using Earth-Moon binary system to detect gravitational waves in the microhertz (10−6 Hz) frequency gap between pulsar timing arrays and space-based interferometers like LISA.

Technical approach: Exploits resonant response when gravitational wave frequency is integer multiple of orbital frequency. Uses existing Moon retroreflectors. Requires Earth-Moon distance measurement to ~0.1 mm accuracy. Moon's 28-day orbit matches microhertz frequency range needed.

Why it matters: Fills frequency coverage gap in gravitational wave detection across the detector spectrum.
