Comprehensive beginner curriculum for digital product design covering: (1) Introduction to Digital Product Design - basics, history, types, business importance, process; (2) User Research - interviews, surveys, personas, journey mapping; (3) User Experience Design - UX principles, wireframes, prototypes, information architecture, usability testing; (4) User Interface Design - UI principles, visual hierarchy, color/typography, UI elements, accessibility, high-fidelity prototypes; (5) Interaction Design - principles, interactive prototypes, animation, micro-interactions; (6) Design Tools - Sketch, Figma, Adobe XD, design systems; (7) Designing for Business - balancing goals and user needs, conversion, performance; (8) Professional Development - portfolio building, interviews, staying current. Curriculum takes learner from no prior experience to novice-intermediate proficiency.
