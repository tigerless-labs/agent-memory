**Seaborn**: High-level interface, statistical graphics focus, built on Matplotlib. Easier learning curve. Docs: https://seaborn.pydata.org/tutorial.html

**Matplotlib**: Low-level control, wide range of plot types, extensive customization. Steeper learning curve. Docs: https://matplotlib.org/stable/tutorials/introductory/pyplot.html

**Plotly**: Interactive, web-based visualizations. Docs: https://plotly.com/python/getting-started/

**Bokeh**: Interactive, web-based visualizations. Docs: https://docs.bokeh.org/en/latest/docs/user_guide.html
