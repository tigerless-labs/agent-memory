Glances: cross-platform system monitoring tool (Linux/Windows/Mac), written in Python, uses psutil library. Features: real-time metrics (CPU, memory, disk I/O, network), client-server architecture for remote monitoring, web-based interface, alarms/notifications, plugin support. Can export to InfluxDB via influxdb-python library for Grafana visualization.
