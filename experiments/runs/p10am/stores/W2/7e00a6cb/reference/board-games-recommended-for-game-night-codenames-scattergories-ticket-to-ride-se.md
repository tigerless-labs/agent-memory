**Codenames** (30-45 min): Word-guessing game, great for groups, encourages teamwork and creative thinking.

**Scattergories** (30-45 min): Creative word game with timer, fast-paced and energetic.

**Ticket to Ride** (30-60 min): Train-themed game where players build railroad routes.

**Settlers of Catan** (30-60 min): Resource management and trading game.

**Pandemic** (30-60 min): Cooperative game to save the world from diseases.
