Adobe's mobile companion to Lightroom Desktop for on-the-go editing and social media prep.

**Shared with Desktop:**
- Non-destructive editing (original files untouched, edits as metadata)
- Basic adjustments: exposure, contrast, highlights, shadows, color grading
- Presets and selective/local adjustments

**Key Differences from Desktop:**
- Limited features: lacks Tone Curve, Split Toning, Lens Corrections, advanced local adjustment tools
- File format: DNG-only; cannot directly edit RAW files from other manufacturers
- Simplified touch-optimized interface
- Incomplete syncing: some edits (especially local adjustments) don't sync desktop→mobile

**Best Practices:**
- Desktop for major work → mobile for refinements and quick adjustments
- Effective for quick exposure/color fixes before social media sharing
- Can export desktop edits and re-import for additional mobile adjustments
- Complements rather than replaces desktop version

**Value:** Extends Lightroom editing to mobile for desktop Lightroom users.
