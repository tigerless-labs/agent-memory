Planned approach for skill development and application:\n\n1. **DataCamp Python course**: Complete the DataCamp course on Data Visualization with Python to build solid foundation in Python programming.\n\n2. **Personal projects**: Work on smaller personal projects first to practice and apply new skills in a low-stakes environment. Examples include:\n   - Visualizing datasets from Kaggle or UCI Machine Learning Repository\n   - Creating dashboards to track personal metrics (fitness, finance, etc.)\n   - Analyzing datasets related to hobbies or interests\n\n3. **Tableau exploration**: Explore Tableau Public (free version) to get familiar with enterprise visualization tools.\n\n4. **Incremental application**: Gradually apply new skills to the major bank project, starting with small, incremental changes and building up to more significant contributions.\n\nThis approach reduces risk of errors on production work and ensures solid foundation before full integration into bank project.
