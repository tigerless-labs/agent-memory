Allows quick lowering of saddle 100-150mm while riding for improved control on technical descents. Benefits: increased confidence and control, improved clearance from obstacles, enhanced descending capability, efficient climbing position, convenient remote adjustment. Considerations: adds weight, requires maintenance, can be added as a later upgrade if on tight budget.
