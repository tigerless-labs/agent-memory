## Current Activities\n- Running and cycling for base endurance\n\n## Planned Cardio (2-3x per week)\n- HIIT: 30s burpees/jump squats + 30s rest\n- Aerobic: 20-30 min steady jogging/cycling\n- Plyometric: box jumps, depth jumps, ladder drills\n\n## Plyometric Exercises (2-3x per week)\n- Box jumps: 3 sets 10-15 reps\n- Depth jumps: 3 sets 10-15 reps\n- Lateral bounds: 3 sets 10-15 reps\n- Tuck jumps: 3 sets 10-15 reps\n- Medicine ball throws: 3 sets 10-15 reps\n- Rest 30-60s between sets\n\n## Stretching Routine\n- Especially after Saturday tennis lessons\n- Focus: neck, shoulders, chest, calves, hamstrings, quads, hip flexors, forearms, rotator cuff, glutes\n- Hold each stretch 30 seconds
