**Gibson Les Paul Standard** — features coil-tap function on tone controls for brighter, more agile sound

**Gibson Les Paul Traditional** — features coil-splitting function to access single-coil sound from humbuckers

**Gibson Les Paul Custom** — often features coil-tap or coil-splitting function depending on specific configuration

These features allow access to a wider range of tones by tapping into different parts of the humbucker coil, providing options ranging from bright and snappy to warm and fat.
