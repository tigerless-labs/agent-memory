User is planning to build a VR gaming PC. Key considerations:

**Compatibility checks:**
- Check VR headset recommended system requirements
- Ensure processor and GPU combination meets/exceeds requirements
- Verify motherboard supports latest processors and graphics cards
- Confirm PSU can power all components
- Ensure case has sufficient space and airflow

**Assembly tips:**
- Ground yourself to avoid ESD damage
- Install PSU first for cable management
- Install motherboard carefully with proper screw tension
- Install CPU, memory, and storage on motherboard
- Firmly secure graphics card in PCIe slot
- Keep cables organized with ties
- Test system POST and BIOS before OS installation
- Install latest drivers and firmware updates
