45-minute spin class structure with modified intervals for individual fitness level.

Warm-up: 5 min easy spinning

Interval 1 - Modified Sprints (3 min): 20 sec moderate intensity + 40 sec easy recovery, repeat

Interval 2 - Modified Hill Climbs (5 min): 1 min moderate-intensity hill simulation + 1 min easy recovery, repeat

Interval 3 - Modified Endurance Intervals (7 min): 1.5 min moderate intensity + 1.5 min easy recovery, repeat

Cool-down: 5 min easy spinning and stretching

Adaptation tips: start with shorter intervals (20-30 sec), reduce resistance as needed, extend recovery time if needed, use perceived exertion as guide rather than exact targets.
