Movie tracking spreadsheet columns:
- Movie Title
- Release Year
- Watch Date
- Rating (4/5 or 8/10 scale)
- Notes
- Franchise/Series
- Genre
- Type (Sequel, Remake, Standalone, Prequel, Spin-off, Reboot)
- Platform (Theaters, Amazon Prime, Netflix, Hulu, Disney+, Blu-ray/DVD, YouTube, iTunes)
- Format (Theater, Streaming, Blu-ray)
- Re-watch (Yes/No)
- Month Watched
- Optional: Director, Cast, Runtime, Language

Plans to populate using copy-paste method from existing list in note-taking app, one movie per line.
