Attention Is All You Need (Vaswani et al.) - foundational transformer paper. The Illustrated Transformer (Jay Alammar) - visual explanation blog post. Attention Mechanisms in Deep Learning (Machine Learning Mastery) - tutorial on self-attention, multi-head attention. Deep Learning for NLP with Python (Nicolette Zeeman) - includes practical examples with Keras. NVIDIA Deep Learning Institute course on attention-based models. 3Blue1Brown video - animated explanation of attention mechanisms.
