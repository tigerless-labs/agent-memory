Java Moss: Low-moderate lighting 1-2W/gal, 72-82F, pH 5.5-8.5, attach to rocks/driftwood, fertilize weekly with 5-5-5 NPK. Provides hiding for neon tetras. Anacharis: Moderate-high lighting 2-4W/gal, 72-82F, pH 6.5-8.5, floating plant, pleco will graze on leaves. Both sensitive to copper medications.
