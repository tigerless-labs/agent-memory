Recommended resources for reviewing Python fundamentals:

- **Codecademy's Python Course** — interactive and comprehensive course to learn Python from scratch
- **Python.org** — official Python documentation with tutorials and guides for beginners
- **W3Schools Python Tutorial** — concise and easy-to-follow tutorial covering Python basics, syntax, variables, control structures, and functions
- **Python Crash Course by Eric Matthes** — free online book covering Python basics, data types, functions, and object-oriented programming
