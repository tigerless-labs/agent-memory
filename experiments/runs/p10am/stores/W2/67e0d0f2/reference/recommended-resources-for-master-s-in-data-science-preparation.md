## Math and Statistics
- Khan Academy: linear algebra, calculus, probability, statistics
- MIT OpenCourseWare: probability, statistics, linear algebra

## Programming and Data Science
- Python for Data Science Handbook (free online)
- DataCamp: Python for Data Science, Introduction to R
- R for Data Science by Hadley Wickham and Garrett Grolemund (free online)
- Data Science Handbook by Jake VanderPlas (free online)

## Machine Learning and Tools
- Machine Learning by Andrew Ng on Coursera
- Scikit-learn documentation
- Data Visualization by UC Berkeley on edX
- Matplotlib and Seaborn tutorials
- Big Data Specialization by UC San Diego on Coursera
- NoSQL Databases by CU Boulder on Coursera
