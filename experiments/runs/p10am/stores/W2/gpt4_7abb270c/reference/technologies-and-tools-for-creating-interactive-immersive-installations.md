Technologies: 3D spatial audio (responsive to viewer movement); Projection mapping (images/textures on surfaces); Scent diffusion (multi-sensory experiences); Haptic feedback (vibrating surfaces/objects); Data visualization (connections between cultures and time periods); Augmented reality overlays (historical images, sounds, texts); Interactive storytelling (branching narratives); Collaborative platforms (viewer contributions to collective memory archive). Tools and frameworks: Unity (game engine for interactive experiences); Max/MSP (visual programming for installations and media); OpenFrameworks (open-source C++ library for interactive installations); Arduino (microcontroller for interactive objects and installations).
