When reading, prefers setting descriptions to be woven naturally into character development and plot progression rather than presented as extensive separate passages. Heavy descriptive detailing of landscape/environment can feel like a distraction from the story itself when not well-integrated. This reinforces preference for character-driven narratives—setting should serve character development, not overshadow it.
