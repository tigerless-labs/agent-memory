Stack chosen for All2Trade cryptocurrency trading system:
- **Frontend & Framework:** Flask (lightweight Python web framework)
- **Database:** MySQL 
- **Backend Language:** Python 3
- **Task Automation:** Celery for scheduled jobs
- **Exchange Integration:** CCXT library for cryptocurrency exchange APIs
- **Data Processing:** Pandas for data manipulation
- **Machine Learning:** TensorFlow, PyTorch, or Keras for deep learning model
- **Authentication:** Flask-Login and Flask-JWT

Deep learning system will:
- Learn from historical market data and user opinions
- Periodically retrain with latest data
- Provide trend predictions to improve trading decisions
- Generate new opinions to complement user input
