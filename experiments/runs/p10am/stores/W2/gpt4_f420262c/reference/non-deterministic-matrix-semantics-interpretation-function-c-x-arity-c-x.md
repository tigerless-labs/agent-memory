The proper mathematical formulation for revised non-deterministic matrix semantics should use the interpretation function:

\·: C × X^arity(C) → ℘(X)

This ensures that each logical connective c ∈ C with specified arity is interpreted as a function from arity-tuples of truth-values to a set of truth-values, properly accounting for the arity of each connective.
