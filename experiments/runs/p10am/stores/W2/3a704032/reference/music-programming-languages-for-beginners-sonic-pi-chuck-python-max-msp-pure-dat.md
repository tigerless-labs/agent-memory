## Overview

Programming languages commonly used in music production:

- **Sonic Pi** — Free, open-source live coding environment designed for creating music. Simple syntax, real-time feedback.
- **ChucK** — Free, open-source language designed specifically for music programming. Supports arrays for melodies, chord progressions, and complex musical structures.
- **Max/MSP** — Visual programming language widely used in electronic music. Create custom instruments and effects by connecting virtual patch cables.
- **Pure Data (PD)** — Free, open-source platform similar to Max/MSP. Used for interactive music and multimedia installations.
- **SuperCollider** — Programming language and platform for real-time audio synthesis and algorithmic composition. Supports wide range of synthesis methods.
- **Csound** — Software synthesis system (30+ years old). Allows custom sound generators and effects using C-like syntax.
- **Swift** — Apple's programming language. Can create music apps for iOS/macOS.
- **Python** — General-purpose language with large community and good documentation. Can be used for music production.

For beginners, Sonic Pi and ChucK are recommended for their simple syntax and music-focused design.
