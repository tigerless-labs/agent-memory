Simple Python bot trading example using ccxt library. Bot connects to Bitmex exchange, trades BTC/USD with 1.0 amount, stop-loss at -100 USD, take-profit at +200 USD. Uses while loop to continuously check price, sells at take-profit or stop-loss level, waits 60 seconds between price checks.
