Zizuh is a company/project to build a remittance service similar to Strike. Core capability: send money instantly and nearly free cross-border using Bitcoin's Lightning Network, without requiring users to handle Bitcoin the asset directly.

Key features:
- Connect user's conventional bank account to the app
- Debit funds and convert to Bitcoin on Lightning Network
- Send to recipient's account in their local currency
- No exposure to Bitcoin volatility unless user chooses
- Drive cross-border payment costs toward zero
