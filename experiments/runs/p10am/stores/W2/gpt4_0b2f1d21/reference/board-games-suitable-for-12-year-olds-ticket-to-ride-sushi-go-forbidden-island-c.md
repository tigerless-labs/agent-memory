**Recommended Board Games for Age 12+**

- **Ticket to Ride** (8+, 30-60 min): Build railroad routes across North America; develops strategic thinking
- **Sushi Go!** (8+, 15-30 min): Fast-paced card game collecting sushi sets; quick to learn and play
- **Forbidden Island/Forbidden Desert** (10+, 20-30 min): Cooperative game retrieving treasures before island sinks/desert buries; promotes teamwork
- **Carcassonne** (10+, 30-45 min): Tile-laying game building medieval landscape with cities, roads, fields; easy to learn with strategic depth
- **Azul** (8+, 30-45 min): Tile-laying game creating beautiful mosaic patterns; simple mechanics with depth
- **Qwirkle** (6+, 15-30 min): Tile-matching game with colors and shapes; develops spatial awareness
- **Codenames** (10+, 15-30 min): Word-guessing team game; develops vocabulary and teamwork

**Selection strategy:** Choose based on child's interests (strategy, speed, cooperation), attention span, and group size
