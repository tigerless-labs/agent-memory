**Core Principles:**

- Lifelong behavioral change requires correct movement patterns and progressive exercise
- Never rush healing; follow its natural rhythm
- Master each progression level before advancing

**Progressive Levels (Crawl → Walk → Run):**
1. Marching in place with neutral spine
2. Walking with neutral spine (weight-bearing phase)
3. Hip-hinging (bending from hips, not spine)
4. Full-body rotation (chest/navel/hips move together)
5. Combined movements (torso rotation + hip-hinge + squat)

**Key Movement Principles:**
- Maintain neutral spine (stable lower back position)
- Use core muscles to lock position in place
- Engage glutes and latissimus dorsi for support
- Rotate from hips/pelvis, not waist
- Arm swing from shoulders (arm to opposite leg pattern)
- If pain occurs: regress to previous level, rest, then retry

**Application to Daily Tasks:**
- Unloading dishwasher
- Putting up groceries
- Any bending and reaching task

**Troubleshooting:**
- Knee pain: pivot feet, reduce range, lighter on feet
- Back pain: check form on each submovement, practice in mirror, increase range gradually
