A system for writing Arabic using Latin characters, where numbers represent specific Arabic phonemes:

- **3** = 3ain (ع) — glottal stop / pharyngeal fricative
- **5** = 5kh (خ) — voiceless velar fricative (like German 'ch' in 'Bach')

Examples provided:
- 3anjad → anjad
- zene5 → zenekh  
- m5alal → mkhalal

Also known as Franco-Arabic or Arabizi. Commonly used for online communication and texting in Arabic-speaking communities.
