Tax requirements for international students earning in Australia (non-resident for tax purposes):

**Tax-Free Threshold:**
- 18,201 AUD annually (may need to file return even if below threshold)

**Non-Resident Tax Rates (2022-2023):**
- 32.5% on taxable income: 0-90,000 AUD
- 37% on taxable income: 90,001-180,000 AUD
- 45% on taxable income: above 180,000 AUD

**Obligations:**
- Must pay taxes on all Australian-sourced income (including freelance/tutoring)
- Self-employed: responsible for own tax payments
- May need to make quarterly PAYG (Pay As You Go) instalment payments
- Must file tax return (NAT 2541) by October 31 each year
- May need Tax File Number (TFN) application (NAT 1432)

**Recommendations:**
- Consult tax professional/accountant familiar with international student tax laws
- Check visa restrictions on freelancing/online work
- Stay informed of ATO updates and law changes
- Track all business expenses for deductions

Contact: Australian Taxation Office (ATO)
