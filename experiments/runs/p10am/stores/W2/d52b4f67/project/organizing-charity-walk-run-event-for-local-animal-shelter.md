Planning a fundraising event for a local animal shelter. Key decisions: using walk/run format as main fundraiser, incorporating pet costume contest with multiple categories (best overall, funniest, most creative, cutest, best owner-pet lookalike), hosting auction/raffle with donated pet-related items and services, displaying photos from previous charity events to showcase commitment and inspire participation. Planning to include music (live DJ/band), food stations, activities (photo booth, adoption fair, vendor fair, raffle), and volunteer opportunities.
