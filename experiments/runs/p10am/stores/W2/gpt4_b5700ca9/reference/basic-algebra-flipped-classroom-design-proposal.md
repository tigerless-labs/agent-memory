Proposed flipped classroom model for basic algebra:

Current structure:
- Traditional lecture format with on-board presentations
- Students take notes during lectures
- Problem sets assigned outside class and reviewed together in class

Proposed flipped model:
- Short video lectures for pre-class viewing
- Class time freed up for interactive and collaborative activities
- Online quizzes and activities to reinforce concepts
- Additional practice opportunities outside class

This design was discussed with Professor Dr. Smith in a higher education consultation.
