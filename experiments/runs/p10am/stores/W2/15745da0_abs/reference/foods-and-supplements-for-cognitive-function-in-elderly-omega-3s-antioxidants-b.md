Omega-3 fatty acids (salmon, tuna, mackerel) improve memory and cognitive function. Antioxidants (berries, spinach, kale) reduce oxidative brain damage. B vitamins (B6, B9/folate, B12) in leafy greens, nuts, fortified cereals support cognition. Moderate caffeine in coffee/tea associated with improved cognitive function. Curcumin (in turmeric) has anti-inflammatory properties and may improve cognition. These should supplement a balanced diet, not replace it. Consult healthcare professional before starting new supplements.
