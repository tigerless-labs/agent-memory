When transferring files from Mac to Windows PC, consider:

**Cloud services** (easiest): Google Drive, OneDrive, Dropbox for seamless transfer between systems

**External hard drive**: Connect external drive to Mac, transfer files, then connect to Windows PC

**Format compatibility issues**:
- Mac uses APFS/HFS+, Windows uses NTFS—may need conversion
- Mac-specific formats (Pages, Numbers) may need export to compatible formats (.docx, .xlsx)

**Other methods**:
- Direct Ethernet or Wi-Fi transfer using Finder/File Explorer
- Migration Assistant (primarily for Mac-to-Mac but some Windows compatibility)
- Parallels or Boot Camp for dual-OS setup

**Key consideration**: Mac-to-Windows file transfer more complex than Mac-to-Mac due to different file systems and format compatibility.
