Recommended foods and supplements for improving cognitive function in elderly individuals:

- **Omega-3 fatty acids**: Found in fatty fish (salmon, tuna, mackerel); improves memory and cognitive function
- **Antioxidants**: Berries, spinach, kale; reduces oxidative damage in the brain  
- **B vitamins**: B6, B9 (folate), B12 found in leafy greens, nuts, fortified cereals
- **Caffeine**: Moderate consumption via coffee or tea; associated with improved cognitive function
- **Curcumin**: Found in turmeric; anti-inflammatory properties and may improve cognitive function

Note: Should not replace a balanced healthy diet; consult healthcare professional before starting new supplements.
