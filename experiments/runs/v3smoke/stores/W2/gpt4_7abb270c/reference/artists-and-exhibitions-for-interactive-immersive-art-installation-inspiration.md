Recommended artists and exhibitions for exploring interactive and immersive art installation approaches:

**Artists:**
- Carsten Höller - interactive installations with slides, Ferris wheels, playful elements
- Anicka Yi - immersive, scent-based installations exploring art/science/technology
- Rafael Lozano-Hemmer - interactive installations using biometrics, robotics, exploring surveillance and control

**Exhibition Spaces/Collectives:**
- Meow Wolf (Santa Fe) - immersive interactive exhibitions blending art, technology, storytelling
- The Color Factory (San Francisco) - interactive installations exploring emotional/psychological effects of color
- TeamLab (Japan) - immersive exhibitions using technology and light for interactive environments
