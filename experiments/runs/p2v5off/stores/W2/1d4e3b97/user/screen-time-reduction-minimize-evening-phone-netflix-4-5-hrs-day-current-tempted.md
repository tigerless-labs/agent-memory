# Screen Time & Digital Wellbeing

**Current habits:**
- Devices: smartphone and laptop (most frequent)
- Total daily screen time: ~4-5 hours (work + leisure combined)
- Top 3 apps: social media, email, Netflix
- Peak temptation times: 7-8pm (after dinner, while watching TV) and before bed

**Goals & strategies:**
- Screen-free dinner time (7-8pm)
- 30-minute calming pre-sleep routine (no screens)
- Netflix as intentional treat, not default unwinding:
  - Set 30-60 minute relaxation window; alternate Netflix with screen-free activities
  - Choose specific shows instead of mindless browsing
  - Use timer to avoid binge sessions
- Set time limits on social media and email
- Create screen-free zones: bedroom (sleep), dinner table
- Replace screen time with: reading, journaling, yoga, stretching, meditation, music

**Motivation:**
Uses Netflix to unwind after long workdays but recognizes need to balance relaxation with reducing total screen time. Avoids replacing one screen with another device.
