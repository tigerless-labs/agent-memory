Committing to strength training program to improve tennis and running performance. Plan: focus on proper form, progressive overload (increase 2.5-5lbs every 2 weeks), core exercises (planks, Russian twists, leg raises, bicycle crunches) 2-3x/week, leg exercises (squats, lunges, calf raises, deadlifts) 1-3x/week. Will allow 48-72 hours recovery between sessions and balance with cardio (tennis, running) and flexibility exercises (stretching, yoga). Will start with lighter weights and progress gradually.
