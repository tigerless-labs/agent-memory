### Emerging Privacy-Enhancing Technologies

- **Homomorphic encryption**: Allows computations on encrypted data without decryption. Still early-stage with high computational costs; likely to see wider adoption as computing power increases and costs decrease.
- **Differential privacy**: Adds random noise to datasets to prevent re-identification attacks. Already in use by Apple and Google; expected to see broader adoption.
- **Federated learning**: Trains ML models using distributed data without centralizing it. Enables machine learning on sensitive data without exposing it.
- **Blockchain**: Uses decentralized ledgers for secure, transparent data storage and sharing with authorization controls.

Discussed as technologies with potential to enhance privacy protections in coming years.
