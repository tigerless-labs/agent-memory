Key techniques: rough shaping with gouges/chisels, refining with files and rasps, detailing with small hand tools. For intricate work: stippling (dots for feathers/scales), hatching (parallel lines for texture), relief carving (raised/recessed effects), inlaying (small pieces for eyes/beaks). Tools needed: various gouges, chisels, files, rasps. Safety: dust mask, safety glasses, gloves. Tips: work in small sections, use reference images, practice with diverse tools and techniques.
