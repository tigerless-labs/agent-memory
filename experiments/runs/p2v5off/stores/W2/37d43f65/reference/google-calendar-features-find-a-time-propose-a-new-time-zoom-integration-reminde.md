From conversation about calendar tools for coordinating gaming sessions:

**Google Calendar Features Explored:**
- Recurring events setup (set frequency, duration, end date)
- 'Find a time' feature: checks attendee availability, suggests available time slots based on shared calendars
- 'Propose a new time' feature: alternative suggestions when initial times don't work, requires calendar sharing
- Multiple time zone display in event details
- Reminder options: email, popup, device notifications (preset: 30 min, 1 hour, 2 hours or custom)

**Video Conferencing Integration:**
- Zoom: Cloud-based platform, integrates via add-on to Google Calendar, one-click meeting creation, automatic invitations, recording feature, virtual backgrounds, breakout rooms, polls
- Google Hangouts Meet: Native integration in Google Calendar
- Discord and Skype: Can add conferencing links manually to events

**Setup Requirements:**
- Gaming partner must share calendar for 'Find a time' to work
- Zoom add-on installation from G Suite Marketplace, authorization needed
- Time zone considerations essential for cross-city scheduling

This was explored for coordinating twice-weekly gaming sessions with a partner in another city.
