User plans to purchase a NAS device to replace/supplement existing external hard drive backups.

**Use case:**
- Central backup location for laptop and phone
- Media storage and streaming
- File backup automation

**Requirements:**
- Beginner-friendly setup and interface
- Strong encryption (AES-256)
- Access control/permissions
- Two-factor authentication (2FA) support
- Regular security updates

**Considerations:**
- Storage capacity calculation based on current files and videos
- Number of bays: 2-bay for small networks (~16TB max), 4-bay+ for larger needs
- RAID configuration for data redundancy
- Budget constraints
- Compatibility with Windows, Mac, and mobile devices

**Decision factors:**
- Balancing security features with budget
- Future storage expansion needs
- Space constraints at home
