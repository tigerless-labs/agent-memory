User is interested in using supplements to boost horses' immune systems prior to vaccination appointments, with particular focus on reducing adverse vaccination reactions. Supplements of interest include omega-3 fatty acids, antioxidants (vitamin C, E, beta-carotene), probiotics, beta-glucans, amino acids (L-glutamine, L-arginine, L-carnitine), and herbal supplements (turmeric, ginger, boswellia).
