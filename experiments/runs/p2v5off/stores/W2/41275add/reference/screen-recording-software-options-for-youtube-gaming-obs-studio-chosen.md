**Chosen: OBS Studio** (free, open-source)\n- Lightweight, feature-rich, large community\n- Plugins available, highly customizable\n- Hardware acceleration support for RTX 3080\n\n**Alternatives evaluated:**\n1. XSplit — user-friendly, polished UI, subscription-based, built-in editor\n2. ShadowPlay — free for NVIDIA, 30 min @ 1440p or 60 min @ 1080p, instant replay\n3. Fraps — lightweight, good for high frame rates, limited features\n4. Bandicam — known for quality, free trial, 4K support\n5. Camtasia — powerful editor + recorder, free trial available\n6. Game Bar — Windows 10 built-in, gaming-focused\n\n**OBS Studio setup tips:** Download 64-bit version, familiarize interface (Scenes/Sources/Audio Mixer), configure video capture settings, set up audio input, create custom scenes with sources (video capture, overlays, text), explore plugins (Streamlabs, Move Transition), test before recording.
