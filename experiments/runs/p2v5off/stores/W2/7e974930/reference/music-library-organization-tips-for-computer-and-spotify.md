**Computer library organization:**
- Create consistent naming convention (e.g., 'Artist - Album - Track Number - Track Title')
- Use folders/subfolders for genres, decades, moods, or by artist/album
- Tag files with metadata (genre, album art, lyrics)
- Clean up duplicates
- Create playlists for different moods/activities

**Spotify organization:**
- Create playlists by genre, mood, or theme
- Use 'Your Library' tab to organize saved tracks
- Leverage Discover Weekly, Release Radar, and Daily Mix features
- Follow friends and music influencers

**Music discovery:**
- Explore Spotify's curated playlists
- Follow music bloggers and influencers
- Attend concerts and festivals
- Ask friends and family
- Try platforms like Bandcamp, SoundCloud, Apple Music
- Check 'Fans also like' section on artist pages
- Use Spotify Radio feature to create stations based on artists/tracks
