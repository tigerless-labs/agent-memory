Wants to ask for feedback and collaboration opportunities without being pushy or annoying. Key principles:
- Be respectful of people's time and keep asks concise
- Be clear about what you're asking for (feedback, collaboration, guidance)
- Show genuine interest in their work before asking for help
- Be open to constructive criticism
- Offer value in return (skill swap, network connection, acknowledgment)
- Be prepared to answer questions about the project
- Respect boundaries if someone declines
