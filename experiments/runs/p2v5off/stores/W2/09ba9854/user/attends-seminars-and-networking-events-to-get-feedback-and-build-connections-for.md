Uses seminars and networking events (e.g., entrepreneurship seminars at co-working spaces) as opportunities to:
- Network with like-minded individuals
- Spread the word about projects
- Gather feedback and constructive criticism
- Find potential collaborators
- Learn from others' experiences

**Networking approach:**
- Prepares an elevator pitch about the project
- Listens to others and asks questions
- Seeks advice and feedback
- Follows up after events (email, LinkedIn) to maintain connections
- Values genuine connections over transactional asks
