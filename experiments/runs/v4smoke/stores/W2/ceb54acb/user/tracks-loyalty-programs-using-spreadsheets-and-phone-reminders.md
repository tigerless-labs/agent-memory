Prefers spreadsheet-based tracking for loyalty programs with columns for: program name, points/rewards type, current earned, amount needed for reward, expiration date, and notes. Strategy for remembering to use cards/apps: set phone reminders for specific stores/times, keep cards in easily accessible spot, link loyalty cards to credit/debit cards when possible, incorporate usage into daily routine. Interested in staying informed about promotions through: newsletters, social media follows, mobile apps/push notifications, in-store promotions, and loyalty program aggregators (Stocard, AwardWallet).
