When organizing loyalty programs, prefers:
- Spreadsheet tracking (Google Sheets or Excel) for points and rewards
- Phone reminders set for specific stores or times to prompt using loyalty apps/cards
- Building using loyalty cards/apps into daily routine as a habit
- Staying informed about promotions via newsletters, social media, and in-store notices
- Tracking different reward types (points-based vs stamp-based) in same spreadsheet with customized columns

Motivated to maximize rewards and not miss out on earning opportunities.
