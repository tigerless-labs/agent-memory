**Math and Statistics:**
- Khan Academy: linear algebra, calculus, probability, statistics
- MIT OpenCourseWare: probability, statistics, linear algebra courses

**Programming Languages:**
- Python: 'Python for Data Science Handbook' (free), DataCamp Python for Data Science course, scikit-learn documentation
- R: 'R for Data Science' by Hadley Wickham and Garrett Grolemund (free), DataCamp Introduction to R

**Data Science Fundamentals:**
- 'Data Science Handbook' by Jake VanderPlas (free)
- DataCamp's Data Science with Python and R

**Machine Learning:**
- Machine Learning by Andrew Ng on Coursera (primary recommendation)
- scikit-learn library documentation

**Data Visualization:**
- UC Berkeley's Data Visualization course on edX
- Matplotlib and Seaborn tutorials

**Big Data & Databases:**
- UC San Diego Big Data Specialization on Coursera
- Colorado Boulder NoSQL Databases course on Coursera

**Practice & Portfolio:**
- Kaggle: competitions and datasets
- KDnuggets: datasets and projects
- r/datasets on Reddit
- Personal projects applying concepts

**Community & Staying Current:**
- Machine Learning Mastery blog
- KDnuggets
- Data Science Podcast
- Online forums: Kaggle, Reddit (r/MachineLearning, r/DataScience), GitHub
- Webinars, meetups, conferences
