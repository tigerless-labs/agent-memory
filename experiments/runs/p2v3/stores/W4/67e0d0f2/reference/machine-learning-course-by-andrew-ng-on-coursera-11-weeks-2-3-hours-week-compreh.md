**Course:** Machine Learning  
**Instructor:** Andrew Ng  
**Platform:** Coursera  
**Duration:** 11 weeks (approximately 3-4 months)  
**Time Commitment:** 2-3 hours/week  
**Level:** Beginner-friendly with prior programming experience recommended  

**Key Topics Covered:**
- Supervised and unsupervised learning
- Linear regression and logistic regression
- Regularization techniques
- Neural networks and backpropagation
- Support vector machines (SVMs)
- Clustering (K-means, hierarchical clustering)
- Dimensionality reduction (PCA, t-SNE, autoencoders)
- Large-scale machine learning and distributed computing

**Format:**
- 11 programming assignments (Python/Octave/MATLAB)
- Quizzes on concepts
- Optional certificate upon completion
- Discussion forums for peer support

**Prerequisites:**
- Basic programming experience (Python, R, or MATLAB recommended)
- Understanding of linear algebra and calculus
