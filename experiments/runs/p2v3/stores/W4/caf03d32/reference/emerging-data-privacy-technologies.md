**Homomorphic encryption**: Allows computation on encrypted data without decryption. Still emerging due to computational costs, but has promising applications.

**Differential privacy**: Already used by Apple and Google. Injects random noise into datasets to prevent re-identification attacks.

**Federated learning**: Trains ML models on distributed data from multiple sources without centralizing/exposing the data.

**Blockchain**: Could enable decentralized, secure data storage and sharing with controlled access.
