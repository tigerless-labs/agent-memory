Improved Clinch Knot: Widely used, high breaking strength. Thread line through lure eye, make small loop, pass tag end through loop twice, moisten, pull tight. Palomar Knot: Strong and reliable. Thread line through eye, make loop, pass tag end through loop twice from opposite side, pass through loop again same side, moisten, pull tight. Loop Knot (Perfection Loop): Creates secure loop at line end, won't slip. Hold line between thumb and finger, make loop, pass tag end through loop twice different sides, moisten, pull tight, attach loop to lure eye. General tips: Always moisten knot before tightening, pull tight from tag end not main line, trim excess tag end close to knot, practice until proficient.
