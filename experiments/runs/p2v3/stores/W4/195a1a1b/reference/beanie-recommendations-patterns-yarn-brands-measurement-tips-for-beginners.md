**Beanie vs slouchy hat for beginners:** Beanie recommended — easier to shape, fewer stitches, more forgiving, requires basic skills (knit, purl, increases, decreases).\n\n**Yarn recommendations:** Malabrigo Worsted (soft with sheen), Cascade 220 (affordable, easy to work with), Plymouth Yarn Company Worsted (subtle texture), Berroco Ultra Alpaca (lightweight, good for sensitive skin).\n\n**Head measurement tips:** Wrap flexible measuring tape around widest part of head just above eyebrows and ears, measure circumference, compare to pattern size. Can use string + ruler if no tape available. Measure multiple times for accuracy. Consider yarn stretch when sizing.
