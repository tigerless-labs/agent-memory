**File transfer methods:**
- Cloud services (Google Drive, iCloud, Dropbox, OneDrive)
- External hard drives
- Migration Assistant (Mac to Mac only)
- Direct transfer via Ethernet or Wi-Fi

**Mac-to-Windows specific considerations:**
- File system compatibility: Mac uses APFS, Windows uses NTFS (may require conversion)
- File type compatibility: Pages, Numbers docs need export to compatible formats (e.g., Word, Excel)
- Use cloud services for seamless cross-platform compatibility

**Before transferring:**
- Backup data using Time Machine, iCloud, or external drive
- Check application compatibility with new OS
- Plan for password, bookmark, and settings migration

**Additional steps:**
- Organize files during transfer
- Allow time for thorough transfer (don't rush)
- Verify all data transferred correctly before removing from old computer
