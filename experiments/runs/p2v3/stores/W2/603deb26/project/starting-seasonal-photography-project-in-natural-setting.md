Decided to start a long-term photography project focusing on capturing the changing seasons in a natural setting (forest or wetland). Plans to:
- Visit a specific location regularly to document seasonal transformation
- Capture the same scene at the same time each year to track changes over time
- Combine seasonal documentation with wildlife/nature photography themes
- Experiment with different techniques and compositions as the seasons change

Motivated by interest in how light and colors change throughout the year.
