Recommended mobile apps for quick photo editing with focus on exposure and color adjustments before social media sharing:

**Free options:**
- Lightroom Mobile (iOS, Android) - powerful Adobe tool with advanced editing, optional subscription for features
- Snapseed (iOS, Android) - Google's professional-grade app, selective adjustments, layers, masking
- Adobe Photoshop Express (iOS, Android) - streamlined desktop Photoshop version with quick fixes
- PicsArt (iOS, Android) - feature-rich with filters, effects, text overlays
- Polarr (iOS, Android) - AI-powered, quick adjustments to exposure/color/contrast

**Paid apps:**
- VSCO (iOS, Android) - film-inspired presets, in-app purchases
- TouchRetouch (iOS: $1.99, Android: $2.99) - removing unwanted objects
- Facetune (iOS: $3.99, Android: $2.99) - portrait retouching
- Filterstorm (iOS: $2.99) - advanced curves, layers, masking
- Afterlight (iOS: $2.99, Android: $1.99) - filters, textures, frames
- Lightroom Mobile - desktop version exists and syncs with mobile version, though mobile is more limited in features
