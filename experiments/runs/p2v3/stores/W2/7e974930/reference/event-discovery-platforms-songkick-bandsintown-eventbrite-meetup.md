Recommended platforms for finding local live music, comedy, and other events:\n- **Songkick** - for music events\n- **Bandsintown** - for music events by artists\n- **Eventbrite** - general event discovery\n- **Meetup** - community groups and events\n\nAlso useful: following local venue social media pages, checking local newspaper event calendars, joining Facebook groups focused on music/comedy.
