Decided to set up a loyalty program for repeat customers with the following features:
- Points-based system: customers earn points for each purchase
- Tier system: frequent customers unlock exclusive rewards
- Sign-up bonus to encourage enrollment
- Promotion strategy: social media, email newsletters, in-store promotions, staff mentions at checkout

Promotion methods planned:
- Social media marketing
- Email newsletters
- In-store promotions
- Staff training to mention program at checkout
