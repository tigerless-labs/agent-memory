Committed to better prioritizing work tasks to avoid staying up late finishing projects. Strategies: Eisenhower Matrix (urgent/important quadrants), time-blocking, breaking large tasks into chunks, setting realistic deadlines with 10-20% padding, learning to say no to non-aligned tasks, taking regular breaks. Goal: manage workload better and protect personal time/sleep schedule.
