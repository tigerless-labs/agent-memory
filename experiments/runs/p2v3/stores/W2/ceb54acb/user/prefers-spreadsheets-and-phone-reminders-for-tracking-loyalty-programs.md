User wants to organize loyalty program tracking using spreadsheets with columns for program name, points/stamps earned, points needed for reward, expiration date, and notes. Plans to set phone reminders to use loyalty apps/cards when near specific stores or at certain times of day, and incorporate loyalty program usage into daily routine. Interested in staying informed about promotions via newsletters, social media, mobile app push notifications, text messages, and in-store signage.
