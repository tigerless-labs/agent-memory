Platform-specific live streaming recommendations. Instagram Live: 10-30 min, visual-focused, mobile-first (vertical). YouTube Live: 30-60 min, in-depth educational content, high production value, SEO-optimized. Facebook Live: 30-90 min, longer-form, community-focused with strong CTAs. Key strategies: real-time audience interaction, repurpose content across platforms, keep ideas journal, use platform-specific features (Instagram polls/quizzes, YouTube Super Chat, Facebook call-to-action buttons).
