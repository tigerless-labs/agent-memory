Genius Voucher is a platform designed to manage voucher-based humanitarian projects, particularly suited for NGOs operating in Africa.

## What it does
- Manages and controls distribution activities in real-time
- Generates periodic reports for accountability
- Eliminates manual data entry for item/cash distribution
- All-in-one solution with hardware and software components

## Hardware
- POS machines issued to authorized vendors
- Smart cards for beneficiaries to receive items or cash

## Software
- Portal for project teams (NGOs) to create and monitor distribution projects in real-time

## Key advantages for Africa

**Accountability & Transparency**
- All transactions use POS machines with receipts
- Real-time monitoring by project team prevents corruption and mismanagement
- Smart card + PIN system ensures proper verification
- Real-time balance monitoring enables efficient planning for card top-ups

**Works in remote areas**
- Operates offline without internet connection
- Devices sync data locally during distribution
- NFC cards hold beneficiary data for smooth redemptions
- Data syncs to database after each round to reflect distribution progress

**User-friendly**
- Beneficiaries simply tap smart card on POS terminal, choose items, enter PIN
- Streamlined redemption process vs. manual distribution systems
