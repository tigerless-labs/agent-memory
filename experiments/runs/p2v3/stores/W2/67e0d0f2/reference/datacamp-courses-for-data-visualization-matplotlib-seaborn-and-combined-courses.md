Recommended DataCamp courses for data visualization:

**Matplotlib:**
- Introduction to Data Visualization with Python
- Data Visualization with Matplotlib
- Matplotlib for Data Visualization

**Seaborn:**
- Data Visualization with Seaborn
- Seaborn for Data Visualization
- Visualizing Data with Seaborn

**Combined:**
- Data Visualization with Python: Matplotlib and Seaborn (recommended starting point)
- Python Data Visualization: Matplotlib, Seaborn, and Plotly

**Interactive visualization:**
- Interactive Data Visualization with Bokeh
- Data Visualization with Plotly

All courses are hands-on with exercises, quizzes, and projects. DataCamp offers free trial.
