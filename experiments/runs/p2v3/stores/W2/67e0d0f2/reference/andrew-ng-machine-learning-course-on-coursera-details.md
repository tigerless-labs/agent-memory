Course: Machine Learning by Andrew Ng on Coursera. Duration: 11 weeks, approximately 3-4 months. Effort: 2-3 hours per week. Includes 11 assignments (programming and quizzes). Topics: linear regression, logistic regression, neural networks, support vector machines, clustering, dimensionality reduction, large scale machine learning. Prerequisites: programming experience (Python/R/MATLAB), basic linear algebra and calculus.
