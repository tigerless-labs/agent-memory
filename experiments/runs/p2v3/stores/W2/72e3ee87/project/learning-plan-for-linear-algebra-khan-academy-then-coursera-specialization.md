Planned learning sequence for linear algebra:
1. Start with Khan Academy's Linear Algebra Course (free, comprehensive basics)
2. Follow with Coursera's Linear Algebra Specialization by University of Pennsylvania (4-course specialization, covers fundamentals and applications)

Linear algebra is foundational for data science and machine learning work.
