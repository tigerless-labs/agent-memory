**Installation concept 1: Recreating sensations of specific environments/memories**\nGoal: Simulate the experience of being in a place or memory using multi-sensory elements.\nExample: Forest walk installation with bird sounds, leaves rustling, damp earth scent.\nTechnologies: Spatial audio, projection mapping, scent diffusion, haptic feedback.\n\n**Installation concept 2: Collective memory and shared human experience**\nGoal: Explore how individual experiences connect to shared cultural and historical contexts.\nApproach: Incorporate found objects, images, and sounds from different cultures and time periods.\nTechnologies: Data visualization, augmented reality, interactive storytelling, collaborative platforms.\n\n**Potential tools and platforms:**\n- Unity — game engine for interactive experiences\n- Max/MSP — visual programming for interactive installations, sound/video manipulation\n- OpenFrameworks — open-source C++ library for interactive installations\n- Arduino — microcontroller platform for interactive objects\n\n**Design considerations:**\nFocus on creating empathy and connection through multi-sensory engagement. Explore how storytelling and narrative can support themes of identity and memory.
