**Context:**
- Currently backing up files to external hard drive, looking for more convenient and scalable solution
- Needs to support backup for multiple devices: laptop and phone
- Beginner user (needs ease of setup and user-friendly interface)

**Security Requirements:**
- Encryption (AES-256)
- Access control and granular permissions
- Two-factor authentication (2FA) support
- Regular security updates from manufacturer

**Storage Considerations:**
- Evaluating 2-bay (~150 USD) vs 4-bay (~300-350 USD) vs larger models
- Wants data redundancy/RAID capabilities
- Future expansion potential
