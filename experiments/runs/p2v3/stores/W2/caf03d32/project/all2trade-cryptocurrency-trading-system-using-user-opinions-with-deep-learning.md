A cryptocurrency trading platform that collects user opinions on currency trends and uses them (combined with deep learning predictions) to automatically execute trades. Free for users; revenue from trading spread. Users receive percentage of profits. Tech stack: Python 3, Flask, MySQL, TensorFlow/PyTorch/Keras, Celery for automation, CCXT for exchange APIs. Database: Users, Opinions, Trades, Payouts tables.
