Learned about music programming languages: Max/MSP (visual, complex), Pure Data (free/open, interactive), SuperCollider (synthesis/algorithmic), Csound (synthesis system), ChucK (designed for music, arrays), Sonic Pi (beginner-friendly, live coding). Sonic Pi has built-in tutorials, examples, active community forums, Discord, Twitch live streams, and workshops available.
