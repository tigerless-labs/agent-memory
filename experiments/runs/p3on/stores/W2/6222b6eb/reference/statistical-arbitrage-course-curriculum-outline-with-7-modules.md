## Course Modules

1. **Introduction to Statistical Arbitrage** — Overview, history, basic concepts, mean reversion vs momentum strategies

2. **Python for Financial Data Analysis** — Using Pandas, NumPy to acquire, clean, and manipulate financial data from APIs, CSV files, databases

3. **Exploratory Data Analysis (EDA)** — Matplotlib, Seaborn for data visualization, pattern identification, outlier detection

4. **Mean Reversion Strategies** — Pairs trading, cointegration testing, z-score computation, trading signals, parameter optimization, backtesting

5. **Momentum Strategies** — Trend following, breakout strategies, moving averages, Bollinger Bands

6. **Portfolio Management** — Risk management, diversification, Sharpe ratio, drawdown, portfolio optimization and performance evaluation

7. **Advanced Topics** — Machine learning for forecasting, alternative data sources, high-frequency trading, risk mitigation

Suggested delivery: mix of lectures, hands-on coding exercises, real-world case studies, community forum/Slack channel for collaboration
