Kanji learning app recommendations for practicing Japanese reading:

**Top picks:**
- **WaniKani** (Web, iOS, Android) - Comprehensive platform using mnemonics, radicals, spaced repetition
- **Anki** (Web, iOS, Android) - Customizable spaced repetition flashcard app
- **Kanji Study** (iOS, Android) - Dedicated app with large database, stroke orders, example sentences
- **Memrise** (Web, iOS, Android) - Language learning with kanji courses, user-generated content
- **Joyo Kanji** (iOS, Android) - Free app focused on standardized Joyo kanji
- **KanjiQ** (iOS) - Simple, gamified kanji quizzes
- **Learn Japanese with Yomiwa** (iOS, Android) - Comprehensive with dictionary, flashcards, exercises
- **Kanji Grid** (Android) - Practice kanji readings through grid filling
- **Kanji Senpai** (iOS) - Free with large database, flashcards, exercises
- **NHK WORLD-JAPAN's Kanji Master** (Web) - Free interactive lessons from Japan's public broadcaster

Recommendation: Consistency with daily practice is key.
