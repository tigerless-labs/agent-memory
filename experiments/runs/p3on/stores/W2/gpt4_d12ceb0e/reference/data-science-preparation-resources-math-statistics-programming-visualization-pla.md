Online platforms for math and statistics: Khan Academy (khanacademy.org), MIT OpenCourseWare (ocw.mit.edu), Coursera (coursera.org), edX (edx.org), Stat Trek (stattrek.com), DataCamp (datacamp.com). Programming and data science: Codecademy (codecademy.com), Kaggle (kaggle.com). Data visualization tools recommended: Tableau (user-friendly, industry standard) and Python libraries (Matplotlib, Seaborn, Plotly). Also Power BI for Microsoft analytics.
