# Chapter 15: Rule #6 — Crawl Before You Walk, Walk Before You Run

## Core Principle
Progressive, deliberate movement retraining—not rushing the healing process. Exercise must be done correctly to avoid reinforcing compensatory patterns.

## Key Sections

### Learning Phase
- Go slow through progressions; master each level before advancing
- Cannot rush healing; it has its own rhythm

### Neutral Spine Integration
- First: march in place with neutral spine (the 'crawl' phase)
- Second: walk with neutral spine (weight-bearing with glute and lat support)
- Finally: complex movements

### Walking with Neutral Spine (4 Steps)
1. Stand with good posture; tilt pelvis to find neutral
2. Lock neutral spine with core engagement
3. Walk maintaining position; swing arms shoulder-to-shoulder (opposite arm to leg)
4. Rest when needed; gradually increase walking duration

### Complex Movement Patterns

**Hip-Hinging**: Bend forward from hips, not lumbar spine. Lower back stays neutral and protected.

**Full-Body Rotation**: Chest, navel, hips move together; rotate via hips/knees/pelvis—not waist.

**Torso Rotation + Hip-Hinge + Squat**: Combine all three for functional everyday movements (unloading dishwasher, groceries). Achieves 180° rotation without spine compression.

## Troubleshooting
- Knee pain: be lighter on feet, allow foot pivoting, reduce ROM gradually
- Back pain: isolate which component causes pain; master each separately before combining
