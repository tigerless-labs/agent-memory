## Note-Taking Apps
- Notion: All-in-one workspace, highly customizable
- Evernote: Organize notes into notebooks with tagging
- OneNote: Microsoft's hierarchical note-taking, integrates Outlook/Office
- Bear: Minimal, beautiful interface with focus mode
- Simplenote: Distraction-free, minimal option

## Project Management
- Asana: Work management, task assignment and progress tracking
- Trello: Visual Kanban boards
- Basecamp: Message boards, schedules, file sharing
- Jira: For software development teams
- Wrike: Real-time visibility, custom workflows

## Automation & Delegation
- Zapier: Connect apps and automate workflows
- IFTTT: If This Then That automation
- Calendly: Automated meeting scheduling
- FullContact: Contact management and business card scanning

## Strengths Assessment
- CliftonStrengths: Identify top strengths/talents
- StrengthsFinder 2.0: Book with assessment access
- VIA Institute on Character: Free character strengths survey
