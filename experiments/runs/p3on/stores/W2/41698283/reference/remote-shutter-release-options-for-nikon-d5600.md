Considering remote shutter release for low-light and portrait photography with Nikon D5600.

Options reviewed:
1. Nikon MC-36a Multi-Function Remote Cord: wired, affordable, reliable
2. CamRanger: wireless WiFi, advanced features including camera control, live view, focus stacking, expensive
3. Hahnel Captur Remote Control: wireless RF technology, compact, lightweight
4. Vello RS-N2II Wired Remote Shutter Release: simple wired option, affordable

Selection factors: compatibility with D5600, wired vs wireless preference, range needed, additional features desired
