Leaning towards the Garmin Forerunner 245 Music running watch for Saturday morning lake runs.

Key features valued:
- GPS Tracking: Multi-satellite GPS (GLONASS, Galileo) for accurate distance and pace measurement
- Music Storage: Up to 500 songs on device (3.6 GB storage, supports MP3/AAC/FLAC)
- Heart Rate Monitoring: Built-in sensor for fitness tracking
- Route Navigation: Can create and follow pre-planned courses (up to 100 courses with 10,000 waypoints max)
- Battery Life: 7 hours in GPS mode with music, sufficient for runs
- Price Point: ~$300 (mid-range option)

Plans to use music during runs and create route for the regular group run path.
