Cloud-based automation platform connecting web apps using trigger-action patterns (IFTTT). Integrates with 1000+ apps: Gmail, Google Drive, Trello, Slack, Stripe, HubSpot, Buffer, Facebook, Google Forms, Airtable, etc.

**Setup**: Connect apps → set trigger events → define actions → map data fields → enable zap.

**Key Features**: Free plan, delay/wait for timed automations, filtering, multiple actions per zap.

**Comparison**: Zapier has broader third-party integrations and easier UX for non-technical users vs Power Automate's deeper Microsoft integration.

**Common patterns**: Email→Task (Gmail→Trello), Form→Task (Google Forms→Trello), Social scheduling (Buffer→Facebook), Payment→CRM (Stripe→HubSpot), Lead notifications (Form→Slack).
