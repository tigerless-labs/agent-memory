5 hands-on exercises for UI Design: (1) Design a landing page—layout, hierarchy, typography, colors, elements, conversion optimization; (2) Create a UI kit in Sketch/Figma with buttons, forms, icons, organized by category; (3) Redesign an existing product with wireframes, prototypes, usability testing, and iteration; (4) Design a mobile app with user flow, screens, branding, and prototype; (5) Create a design system with style guide, components, usage guidelines, and continuous updates.
