5 hands-on activities for User Research: (1) Conduct user interviews—identify target audience, develop questions, analyze responses for pain points; (2) Create user personas—research target audience, identify characteristics/behaviors, create fictional personas; (3) Conduct usability testing—create prototype, recruit users, develop tasks, observe and iterate; (4) Develop user journey maps—map discovery to purchase, identify pain points, develop solutions; (5) Conduct competitive analysis—research competitors' strengths/weaknesses, identify differentiation opportunities.
