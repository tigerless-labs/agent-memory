Event display strategy to improve visibility and sales:\n- Create 'New Arrivals' section to showcase latest products\n- Arrange candles/scarves in color gradients (rainbow effect)\n- Use risers, pedestals, stacked crates for varied heights\n- Create focal point with statement pieces\n- Keep display tidy and organized\n- Leave breathing room; avoid clutter\n- Consider themed displays (e.g., 'Cozy Winter')
