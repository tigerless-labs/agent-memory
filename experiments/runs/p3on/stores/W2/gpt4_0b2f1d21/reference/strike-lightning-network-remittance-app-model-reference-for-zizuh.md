Strike is a mobile remittance application that combines traditional finance with Bitcoin's Lightning Network.

Features: Sends money globally with minimal fees; connects bank account to app; debits in fiat, converts to BTC on Lightning Network, sends to recipient, converts back to their local currency; users never need to hold Bitcoin.

Use case: Drives cross-border remittance costs toward zero while using Lightning Network infrastructure transparently.

Relevance: Competitive reference for Zizuh project architecture and user experience model.
