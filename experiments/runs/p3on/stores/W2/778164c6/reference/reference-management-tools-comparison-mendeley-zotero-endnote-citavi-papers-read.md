**Tools compared for thesis reference management:**

- **Mendeley**: Free, user-friendly interface, web importer feature, annotation support, Word/Google Docs/LaTeX integration, large community database
- **Zotero**: Free, open-source, flexible, steep learning curve but powerful, good citation style support, browser extension, BibTeX import
- **EndNote**: Commercial, widely used in academia, automated formatting, collaboration tools
- **Citavi**: Comprehensive with knowledge management and task planning
- **Papers**: Designed for Mac/iOS users, clean interface
- **ReadCube**: Free, focuses on article discovery, desktop app available
- **RefWorks**: Web-based, popular with students, collaboration features

**Key selection factors:** citation style support, integration with writing tools, collaboration needs, ease of use, cost (free vs. paid)

**Core features:** in-text citation insertion, auto-complete suggestions, automated bibliography generation, PDF management, tagging/categorization, notes/annotations
