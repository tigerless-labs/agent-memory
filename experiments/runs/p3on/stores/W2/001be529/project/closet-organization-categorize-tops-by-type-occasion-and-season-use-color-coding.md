Started organizing a cluttered closet after recent thrift shopping haul. Focus areas:\n\n**Categorization method:**\n- By type: short-sleeve tops, long-sleeve tops, dressy tops, activewear\n- By occasion: everyday, work, date night, lounging\n- By season: store out-of-season items in labeled bins\n- By color: create visually pleasing, easy-to-navigate system\n\n**Organization strategy:**\n- Keep frequently worn items at eye level or front\n- Use double hangers to maximize space\n- Leave space between items to avoid overcrowding\n- Hang or fold based on fabric type (delicate pieces hung, casual folded)\n- Set aside 15-30 min/week for maintenance\n\n**Goal:** Create system that works for personal lifestyle and makes outfit creation easier by seeing how new pieces complement existing wardrobe.
