DHTML (Dynamic HTML) events are JavaScript events that create interactive web pages.

Common DHTML events:
- **onclick** - triggered when element clicked
- **ondblclick** - triggered when element double-clicked  
- **onmouseover** - triggered when mouse moves over element
- **onmouseout** - triggered when mouse moves out of element
- **onkeydown** - triggered when keyboard key pressed
- **onkeyup** - triggered when keyboard key released
- **onload** - triggered when web page finishes loading
- **onunload** - triggered when user leaves page
- **onsubmit** - triggered when form submitted
- **onreset** - triggered when form reset
- **onresize** - triggered when browser window resized
- **onerror** - triggered when error occurs loading resource
- **onscroll** - triggered when user scrolls page

Used to respond to user actions and browser events in real-time, providing interactive user experience.
