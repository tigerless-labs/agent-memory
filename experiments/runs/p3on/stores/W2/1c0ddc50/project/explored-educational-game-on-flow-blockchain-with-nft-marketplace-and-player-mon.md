User researched building an educational game on Flow blockchain integrated with NFTs.

NFT platforms considered: Niftory (minting) and Puddle Side (secondary market trading).

Player monetization methods explored: mining for cryptocurrency, quest/challenge rewards, NFT trading, staking interest, referral bonuses.

UX design priority: abstract blockchain complexity from new users through email/social login, credit card NFT purchases, and hiding technical details (gas fees, transaction times, key management).

This was exploratory research into Flow ecosystem capabilities for game monetization, conducted around May 2023.
