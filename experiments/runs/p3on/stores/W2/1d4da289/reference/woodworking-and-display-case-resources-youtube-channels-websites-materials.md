Resources recommended for woodworking and model display building:\n\n**Online Platforms:**\n- The Spruce Crafts (guides for wooden display cases)\n- Woodworking Magazine\n- Instructables (DIY tutorials)\n\n**YouTube Channels:**\n- The King of Random\n- Steve Ramsey\n- Woodworking Adventures\n\n**Materials for beginners:**\n- Softwoods: pine or fir (easier to work with)\n- Display case woods: maple, cherry, walnut\n\n**Tips for first project:**\n- Start with basic hand tools (tape measure, marking gauge, hand saw, clamps)\n- Practice on scrap wood first\n- Measure twice, cut once\n- Sand thoroughly and apply finish (stain, polyurethane, or wax)
