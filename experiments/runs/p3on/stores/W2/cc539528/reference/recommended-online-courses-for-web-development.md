## Front-end development resources
- Codecademy — interactive lessons and projects on HTML, CSS, JavaScript
- FreeCodeCamp — non-profit offering free courses in web development (HTML, CSS, JavaScript, React)
- Udemy — wide range of front-end courses from beginner to advanced

## Back-end development resources  
- NodeSchool — community-driven workshops and interactive courses on Node.js
- Udacity — courses in back-end development including Python, SQL, Flask, Django
- Coursera — online courses on Java and web frameworks like Spring and Hibernate
