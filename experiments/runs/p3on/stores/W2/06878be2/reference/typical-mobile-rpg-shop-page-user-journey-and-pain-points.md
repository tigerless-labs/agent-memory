## Shop Page User Journey

**Steps:**
1. Access shop through main menu or dedicated button
2. Browse items/products (in-game currency, equipment, consumables, cosmetics)
3. Use sorting/filtering to narrow search
4. View detailed item info (stats, effects, appearance), compare items
5. Purchase with real money or in-game currency
6. Receive purchase confirmation, item added to collection/inventory
7. Continue browsing or exit

**Common Pain Points:**
- Unclear or incomplete item information
- High prices or limited availability
- Technical issues or purchase errors
- Security or fairness concerns about shop mechanics

**Developer Solutions:**
- Provide clear, accurate item information
- Offer fair, reasonable pricing
- Ensure reliability and security
- Respond promptly to player issues
