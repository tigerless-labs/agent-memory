**Glances** is a cross-platform system monitoring tool for Linux, Windows, and macOS.

**Key features**:
- Real-time monitoring of CPU usage, memory usage, disk I/O, network activity
- Client-server architecture for remote monitoring
- Web-based interface for viewing metrics
- Ability to set alarms and notifications based on system metrics
- Plugin system to extend functionality
- Written in Python using psutil library

**Usage modes**:
- Standalone mode (local monitoring)
- Client-server mode (remote monitoring)
- Web server mode (web-based UI)

**Integration capability**: Data export plugins available (e.g., InfluxDB plugin) to send metrics to external databases for archival and visualization.

**Useful for**: System administrators and developers monitoring system performance and troubleshooting bottlenecks.
