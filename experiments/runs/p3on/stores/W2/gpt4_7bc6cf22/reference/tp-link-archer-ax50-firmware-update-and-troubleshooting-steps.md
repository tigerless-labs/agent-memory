**Firmware Update Process:**
1. Login to router at 192.168.0.1 or 192.168.1.1 (default credentials: admin/admin)
2. Download latest firmware from tp-link.com support page
3. Upload via Management/Advanced Settings > Firmware Update
4. Do NOT interrupt during update process
5. Reboot when complete and verify version updated

**Troubleshooting for slow speeds:**
- Check channel congestion using Wi-Fi Analyzer app
- Verify no interference from microwaves, cordless phones, neighboring networks
- Consider QoS settings for bandwidth prioritization
- Try different router placement (central, elevated, fewer obstacles)
- Restart router with 30-second power-off interval

**When to check:**
- ISP status page for outages/maintenance
- Current firmware version before updating
