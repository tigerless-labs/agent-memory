Citation management workflow in Mendeley:\n- Create thesis folder with subfolders for each chapter\n- Use tags to categorize papers by theme and methodology\n- Use star rating system (1-5 stars) to prioritize papers by relevance\n- Create separate 'must-read' folder/tag for essential papers\n- Take notes on each paper with relevance to thesis, key findings, and connections\n\nThis system helps organize papers by relevance and engage deeply with source material.
