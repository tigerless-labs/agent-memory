Interested in applying principles from 'Atomic Habits' and 'Deep Work' to improve reading speed and retention. Specific goals:

**Habit building (from Atomic Habits):**
- Habit stacking: attach reading to existing routine (e.g., after breakfast, before bed)
- Identity-based habits: see self as a 'reader'
- Start small and scale: begin with 10–15 minute daily sessions
- Implementation intentions: 'If [time], I'll read for [duration] in [location]'

**Deep work sessions (from Deep Work):**
- Eliminate distractions: find quiet, comfortable reading spot
- Schedule dedicated deep reading blocks
- Use Pomodoro Technique: 25 minutes focused reading + 5-minute breaks
- Active reading: take notes, ask questions, summarize material

Also interested in tracking progress and creating rewards for reaching milestones.
