## Recommended Courses

**Deep Learning:**
- Andrew Ng's Deep Learning Specialization (Coursera) — 5-course specialization covering neural networks, optimization, structuring ML projects
- Deep Learning by Google (Coursera) — 3-course specialization with TensorFlow and applications

**NLP:**
- Natural Language Processing with Deep Learning (Stanford University, Stanford Online) — by Prof. Christopher Manning
- Natural Language Processing (University of Colorado Boulder, Coursera)
- Deep Learning for Natural Language Processing (University of Oxford, edX)
- Natural Language Processing with Python and NLTK (DataCamp) — hands-on course

**Key Focus:**
Start with fundamentals of neural networks, backpropagation, optimization. Then progress to NLP-specific concepts (embeddings, RNNs). Focus on deep learning techniques for NLP (Transformers, attention mechanisms).
