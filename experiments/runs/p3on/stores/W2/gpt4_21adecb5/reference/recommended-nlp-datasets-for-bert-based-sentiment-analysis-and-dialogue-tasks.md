IMDB (50k movie reviews, binary), Stanford Sentiment Treebank SST-2 (10k movie reviews), Amazon Product Reviews, Yelp Dataset. For ABSA: Semeval-2014 (3k restaurant reviews), Semeval-2015 (1.5k laptop reviews). For intent detection: CLINC150 (15k samples), HWU64 (64k samples). For dialogue: Ubuntu Dialogue Corpus (1M utterances), DialogRE (10k dialogues), ConvAI2 (10k dialogues), DSTC (10k dialogues with state tracking).
