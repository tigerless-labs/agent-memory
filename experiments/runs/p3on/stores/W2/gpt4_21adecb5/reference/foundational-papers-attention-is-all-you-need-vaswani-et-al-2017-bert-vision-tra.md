## Essential Research Papers

**Transformers & Attention:**
- Attention Is All You Need (Vaswani et al., 2017) — original Transformer model for machine translation
- Attention Is All You Need (Distill) — interactive article explaining attention and Transformers

**Language Models:**
- BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding (Devlin et al., 2019)
- RoBERTa: A Robustly Optimized BERT Pretraining Approach (Li et al., 2019)
- DistilBERT: A Distilled Version of BERT (Sanh et al., 2019)
- XLNet: Generalized Autoregressive Pretraining for Language Understanding (Yang et al., 2020)
- T5: Text-To-Text Transformer for Unified Text Generation (Raffel et al., 2020)
- BART: Denoising Sequence-to-Sequence Pre-training for Natural Language Generation (Lewis et al., 2020)
- Transformer-XL: Attentive Language Models beyond a Fixed-Length Context (Dai et al., 2019)

**Computer Vision with Transformers:**
- Vision Transformers (ViT): An Image is Worth 16x16 Words (Dosovitskiy et al., 2020)
- Swin Transformer (Liu et al., 2021)
- DETR: End-to-End Object Detection with Transformers (Carion et al., 2020)
- Deformable DETR (Zhu et al., 2020)

**Applications:**
- Various papers on text classification, sentiment analysis, question answering, dialogue systems using transformers (2020+)
