Ryan avoids overexerting himself when starting hiking in new areas or as part of a progression. Decided to start with a 2-3 mile hike before attempting the 5-mile hike he was initially considering, to build confidence, assess fitness level, and develop basic hiking skills like navigation and hazard recognition.
