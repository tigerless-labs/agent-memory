**Course:** Machine Learning by Andrew Ng on Coursera\n\n**Duration:** 11 weeks, 2-3 hours/week\n\n**Topics covered:**\n- Linear regression and gradient descent\n- Logistic regression\n- Regularization\n- Neural networks & backpropagation\n- Support vector machines\n- Clustering & unsupervised learning (K-means, PCA)\n- Dimensionality reduction\n- Large scale machine learning\n\n**Assignments:** 11 programming assignments covering practical applications:\n- Linear regression (housing price prediction)\n- Neural networks (MNIST digit classification)\n- SVMs (email spam detection)\n\n**Prerequisites:** Some programming experience (Python/R/MATLAB), basic linear algebra and calculus.
