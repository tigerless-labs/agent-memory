Development workflow for SMC platform uses Visual Studio Code in browser via GitHub Codespaces for cloud-based development without local setup. Key tools: Postman for REST API testing (Django Rest Framework endpoints), React Developer Tools and Redux DevTools for front-end debugging. Project management via Trello, team communication on Slack with GitHub/Trello integration. Git configuration via GitHub Desktop or command line. SSH key authentication to GitHub (ed25519 key recommended).
