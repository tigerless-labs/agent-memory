Primary IDE: Visual Studio Code - supports Python, JavaScript, HTML, CSS with wide extension support for linting, debugging, syntax highlighting. Git integration built-in. Alternative: PyCharm - powerful Python IDE with strong Django support, intelligent code completion, refactoring features, code navigation. Both options considered for SMC development team.
