System for writing Arabic using Latin characters and numbers in informal communication.

**Number-to-sound mappings:**
- 3 = ع (ayn)
- 5 = خ (kha)

**Examples:**
- 3anjad = anjad (عنجد)
- zene5 = zenekh
- m5alal = mkhalal

**Use case:** Common in Arabic-speaking online communities and informal texting.
