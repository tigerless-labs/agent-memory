Bike security products and registration services recommended for commuter bike theft prevention.

## High-security locks
- **Kryptonite** — U-lock and chain lock options, highly rated for security
- **Abus** — high-security rating locks
- **OnGuard** — secondary cable lock for securing components

## Bike registration and recovery
- **BikeIndex** — free online bike registration platform with police-searchable database to recover stolen bikes
- **National Bike Registry** — non-profit national database for bike registration

## Best practices for locking
- Use U-lock or chain lock (avoid cable locks—easily cut)
- Lock frame and wheels to immovable object (bike rack, signpost, lamppost)
- Keep lock off ground to prevent leverage tools
- Use secondary lock for removable components (wheels, seat)
- Register bike with serial number, photo, and description to increase recovery chances if stolen
- Consider bike lockers or indoor parking for maximum security
