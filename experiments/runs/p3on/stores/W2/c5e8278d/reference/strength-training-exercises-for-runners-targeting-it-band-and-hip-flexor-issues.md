## Strength Training for Runners - IT Band & Hip Flexor Focus

Aim for 2-3 strength sessions per week on non-consecutive days.

### Strengthen Glute Medius (prevents IT band syndrome)
- Side lunges: 3 sets x 8-12 reps per leg
- Clam shells: 3 sets x 12-15 reps  
- Side leg lifts: 3 sets x 12-15 reps per leg

### Strengthen Hip Flexors
- Step-ups: 3 sets x 8-12 reps per leg
- Lunges: 3 sets x 8-12 reps per leg
- Leg press: 3 sets x 8-12 reps

### Improve Hip Mobility
- Leg swings: 3 sets x 12-15 reps
- Hip circles: dynamic movement
- Pigeon pose: 3 sets x 30-60 sec per leg

### Core Strengthening
- Planks: 3 sets x 30-60 sec
- Side planks: 3 sets x 30-60 sec per side
- Russian twists: 3 sets x 12-15 reps

### Compound Movements
- Squats: 3 sets x 8-12 reps
- Deadlifts: 3 sets x 8-12 reps
- Calf raises: 3 sets x 12-15 reps

**Key principles:** Start with lighter weights; progress gradually; focus on proper form; avoid plyometrics initially if experiencing pain.
