Three reliable knots for connecting lure to line:

**Improved Clinch Knot**: Most widely used, easy to tie, high breaking strength
1. Thread line through lure eye
2. Make small loop
3. Pass tag end through loop
4. Pass tag end through loop again (same side)
5. Moisten and pull tight
6. Trim excess

**Palomar Knot**: Strong and reliable
1. Thread line through lure eye
2. Make small loop
3. Pass tag end through loop
4. Pass tag end through loop again (opposite side)
5. Pass tag end through loop one more time (same side as first)
6. Moisten and pull tight
7. Trim excess

**Loop Knot (Perfection Loop)**: Creates secure loop at line end, won't slip
1. Make small loop
2. Pass tag end through loop
3. Pass tag end through loop again (same side)
4. Pass tag end through loop (opposite side)
5. Moisten and pull tight
6. Trim excess
7. Attach loop to lure eye

Tips: Always moisten before pulling tight; pull by tag end not main line; practice until quick.
