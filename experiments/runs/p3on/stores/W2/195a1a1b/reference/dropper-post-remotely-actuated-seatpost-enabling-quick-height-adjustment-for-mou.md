A **dropper post** is a hydraulic or cable-actuated seatpost that quickly lowers/raises saddle (typically 100-150mm range) via lever or button.

**Benefits**:
- Increases control on technical descents and tight terrain
- Provides clearance and balance on rough sections
- Enables more aggressive, confident riding downhill
- Maintains pedaling efficiency when raised for climbing
- Remote control allows on-the-fly adjustment without stopping

**Considerations**:
- Adds weight to bike
- Requires regular maintenance (cleaning, lubrication)
- Must be compatible with frame and seatpost diameter
- Can be added as future upgrade if not in initial budget
- Particularly helpful for building confidence as beginner
