Interested in developing AI-powered triage systems for remote/resource-constrained areas with limited medical professional access. Key focus: seamless integration with telemedicine platforms, ensuring accurate patient prioritization, and enabling remote diagnosis.

Technical priorities: API integration, data mapping, real-time data exchange, secure authentication. Data needs: EHRs, vital signs, lab results, clinical notes, appointment info. Challenges: data quality/privacy, algorithmic bias, clinical validation in remote settings. Considering implementation directions: triage automation, remote image analysis, patient support chatbots, clinical trials.
