Plank (hold 30-60 seconds), Bodyweight crunches (10-15 reps), Leg raises (10-15 reps), Russian twists (10-15 reps), Bicycle crunches (10-15 reps). Tips: start slow, listen to body, use props, practice 2-3 times weekly
