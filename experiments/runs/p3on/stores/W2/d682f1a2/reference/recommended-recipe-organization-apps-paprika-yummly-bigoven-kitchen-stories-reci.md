Apps for organizing and consolidating recipes:

**Top picks:**
- **Paprika Recipe Manager**: Organize, tag, search recipes; includes meal planning, grocery lists, nutritional analysis (iOS, Android, Windows)
- **Yummly**: Discover and save recipes from various sources; meal planning and grocery list features (iOS, Android)
- **BigOven**: 200,000+ recipe database; save/organize favorites, create digital cookbooks, generate grocery lists (iOS, Android)
- **Kitchen Stories**: Visually appealing; save/organize recipes, create cookbooks, watch cooking videos (iOS, Android)
- **Recipe Keeper**: Simple and intuitive; tagging, meal planning, grocery lists, nutritional analysis (iOS, Android)

**Alternative note-taking approaches:**
- **Evernote**: Note-taking app for organizing/tagging recipes (iOS, Android, Web)
- **OneNote**: Note-taking with meal planning and grocery list features (iOS, Android, Web)
- **Google Keep**: Simple note-taking for saving/organizing recipes (iOS, Android, Web)

Key features to consider: recipe importing, tagging/organization, meal planning, cookbook creation, offline access.
