Decided to use Google Sheets for content calendar with hybrid approach:
- Master sheet tracking: Date, Content Type, Platform, Content Title/Description, Hashtags, Keywords, Image/Video URL, Engagement metrics
- Separate sheets for each social media platform with platform-specific details
- Tracking metrics: Follower growth rate, engagement rate, hashtag performance
- Plans to use Instagram Insights and social media analytics tools for hashtag tracking
- Goal: post consistently across all platforms while optimizing posting times based on audience activity
