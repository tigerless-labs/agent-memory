Considering getting Rhode Island Red chickens. Will need to build a predator-proof chicken coop. Consulted on hardware cloth coverage, wire mesh size (1 inch or smaller), burying foundation 1-2 feet underground, secure doors/latches, roosting bars 2-3 feet high, electric fencing for deterrent, covering run to protect from flying predators.
