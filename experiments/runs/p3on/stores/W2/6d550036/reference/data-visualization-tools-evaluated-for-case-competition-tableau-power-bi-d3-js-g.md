Evaluated multiple data visualization platforms for case competition presentation. Tableau selected as primary tool for its ease of use and interactive dashboard capabilities. Other tools considered: Power BI (Microsoft business analytics), D3.js (JavaScript library for advanced visualizations), Google Data Studio (free web-based dashboards), Plotly (interactive web visualizations), Easel.ly (simple web tool), Sisense (cloud BI platform), QlikView (visual analytics platform), Matplotlib and Seaborn (Python libraries).
