Recommended canister filters for 20-gallon aquariums:

1. Eheim Classic 2211: Well-respected brand, excellent mechanical and biological filtration, quieter operation, price 100-150 USD

2. Fluval 206: Compact design, quiet operation, customizable media, price 100-150 USD, slightly louder than Hydor per some users

3. Hydor Professional 150: Italian brand, very quiet with silent pump, modular design, easy maintenance, built-in primer, price 150-200 USD

4. API SuperClean: Easy setup and maintenance, range of media options, price varies

Recommended flow rate for 20-gallon tank: 100-200 gallons per hour.
