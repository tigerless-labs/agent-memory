User collects and studies detailed Midjourney prompts and commissions prompt creation. Preferences:

- **Detailed descriptions** with rich, descriptive language
- **Professional photography specs**: camera model, lens, aperture, ISO, shutter speed  
- **Creative/whimsical concepts** (e.g., Shiba Inu dressed as grandma gangster at poker table)
- **Aspect ratio parameters** (16:9, 3:2, 4:5, etc.)
- Familiar with Midjourney parameters: --ar, --q, --v

Example: prefers 'Canon EOS R6 with RF 24-70mm f/2.8L IS USM, f/4, ISO 1600, 1/200 sec' style specificity over generic descriptions.
