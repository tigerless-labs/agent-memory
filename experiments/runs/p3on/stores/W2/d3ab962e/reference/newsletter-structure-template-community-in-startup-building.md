# Community in Startup Building Newsletter Structure

## Sections
1. **Why community matters** — feedback, idea validation, customer connection
2. **How to build community** — social media engagement, blogging, events; emphasize authenticity and transparency  
3. **Success stories** — Airbnb, Dropbox, Tesla examples of strong community building
4. **Leverage for growth** — product improvement via feedback, user-generated content, referral incentives
5. **Conclusion** — summary and call for subscriber participation

## Format
- Subject line with hook about startup success
- Opening: personalized greeting + value proposition
- Body: 5 key sections with examples and actionable tips
- Closing: CTA to join community and follow on social media
