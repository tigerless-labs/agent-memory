Planning gin infusions with different flavors. Cucumber-mint: infuse separately (1-2 cups per 1L gin, 2-5 days), then blend. Lavender: 1/4 cup dried lavender per 1L, 2-3 days. Grapefruit: 1-2 sliced fruits per 1L, 2-3 days. Store all in cool dark place, strain through cheesecloth before using.
