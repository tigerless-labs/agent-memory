**Beginner-friendly options:**
- **Sonic Pi** — Free, live-coding environment with simple syntax and real-time feedback
- **ChucK** — Free, music-specific with powerful audio synthesis tools
- **Python** — General-purpose, large community, extensive documentation

**More advanced:**
- **Max/MSP** — Visual programming, commercial but industry standard
- **Pure Data** — Similar to Max/MSP but free/open-source
- **SuperCollider** — Real-time audio synthesis, experimental music
- **Csound** — Software synthesis, 30+ year legacy, complex but powerful
