Learned about Lightroom Mobile (mobile version of desktop Lightroom). Uses it for quick on-the-go adjustments to exposure and color before sharing images on social media. Appreciates its non-destructive editing and syncing with desktop Lightroom catalog.

Key limitations vs desktop: narrower feature set (no Tone Curve, Split Toning, Lens Corrections), touch-optimized interface, DNG files only, limited local adjustments. Planned workflow: edit on desktop, refine on mobile.

Also aware of other mobile editing options: VSCO, Snapseed, Adobe Photoshop Express, TouchRetouch, PicsArt, Afterlight, Polarr.
