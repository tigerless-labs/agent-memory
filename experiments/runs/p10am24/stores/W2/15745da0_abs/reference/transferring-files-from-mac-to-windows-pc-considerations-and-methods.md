Key considerations when moving from Mac to Windows:
- **File system differences**: Mac uses APFS, Windows uses NTFS - may need conversion
- **File type compatibility**: Mac-specific formats (Pages, Numbers) may not open on Windows; export to compatible format (.doc, .xls) first
- **Transfer methods**:
  - Cloud services (Google Drive, OneDrive, Dropbox) for seamless transfer
  - External hard drive
  - Ethernet or Wi-Fi direct connection
- **Don't forget**: Passwords, bookmarks, browser settings
- **Backup first**: Always have recent backup using Time Machine or external drive
- **Check app compatibility**: Verify Windows versions available before transferring
