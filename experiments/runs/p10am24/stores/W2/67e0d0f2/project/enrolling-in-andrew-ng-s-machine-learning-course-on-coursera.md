### Course Details
- **Title:** Machine Learning
- **Instructor:** Andrew Ng
- **Platform:** Coursera
- **Duration:** 11 weeks (approximately 3-4 months)
- **Effort:** 2-3 hours/week
- **Level:** Beginner-friendly, but programming experience recommended

### Topics Covered
- Supervised and unsupervised learning
- Linear regression and gradient descent
- Logistic regression
- Neural networks and backpropagation
- Support Vector Machines (SVMs)
- Clustering (K-Means, hierarchical)
- Dimensionality reduction (PCA, t-SNE, autoencoders)
- Large scale machine learning

### Assignments
- 11 programming assignments and quizzes
- Implementations in Python, Octave, or MATLAB
- Real-world applications: housing price prediction, MNIST digit classification, email spam detection
- Optional certificate upon completion

### Prerequisites
- Programming experience (Python, R, or MATLAB)
- Basic understanding of linear algebra and calculus
