**Synology recommendations:**

**Budget 2-bay:**
- DS218j: ~$150, up to 16TB, user-friendly, good for beginners

**Mid-range 4-bay:**
- DS418j: ~$300, up to 32TB, snapshot replication, encryption
- DS418play: 4-bay, AES-256 encryption, 2FA, Surveillance Station, Media Server

**High-end 8-bay:**
- DS1819+: AES-256 encryption, 2FA, Advanced access control, Active Backup for Business, Hyper Backup, regular security updates

All Synology models include granular permissions and regular security updates.
